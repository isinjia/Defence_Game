# 결과별 시각 검토 기록

각 항목은 `통과 / 수정 필요 / 미확인 / 해당 없음`과 실제 관찰 근거를 적는다. 미확인은 통과가 아니다. 판단은 이미지를 직접 보고 하며 자동 수치 점수로 대신하지 않는다.

```markdown
결과 파일:
요청과 최신 수정:
실제로 확인하고 생성 호출에 첨부한 기준 이미지:
이번에 유지한 기존 승인 내용:

| 항목 | 판정 | 관찰 근거 / 조치 |
|---|---|---|
| 원화와 선 굵기·강약·얼굴 묘사가 맞는가 | | |
| 부드러운 명암과 큰 색면이 균형을 이루는가 | | |
| 배경·재질이 인물과 같은 그림체인가 | | |
| 실사 질감·3D 광택·균일한 건축 렌더 느낌이 없는가 | | |
| 헤어의 넓은 반사 띠·가닥별 밝고 어두운 반복을 없앴으며 은발 고유색은 유지했는가 | | |
| 실제 얼굴 합성에서 앞머리 눈 가림·귀나 피부 잔여 조각·원치 않은 모발색 변화가 없는가 | | |
| 고유색·강조색·어두운 부분의 가독성이 유지되는가 | | |
| 인물 특징·나이·체형·시기별 의상이 맞는가 | | |
| 눈코입·턱·목·헤어·의상이 자연스럽게 연결되는가 | | |
| 실제 턱선과 목 피부를 구분해 H2·H25의 목 옆 모발이 피부 모양으로 깎이지 않는가 | | |
| 안경·코트·직업복의 볼 옆을 확대했을 때 검은 헤어 조각이 직각·수평으로 끊기지 않는가 | | |
| 뒷머리·옷 윤곽에 결손·투명한 부분이 없는가 | | |
| 피부색 변경 시 눈 주변·얼굴·목·몸이 일치하는가 | | |
| 손가락은 손마다 다섯 개이고 손발·접촉 그림자가 자연스러운가 | | |
| 인물 크기·원근·배경 공간이 일관되는가 | | |
| 선로는 연속되며 승강장보다 낮고 벽·기둥이 열차 길을 막지 않는가 | | |
| 소품 수·숫자·지도 평면성과 개별 수정이 보존되는가 | | |
| 모바일 390×844에서 자막·줌·팬과 함께 읽히는가 | | |
| 모바일 320×900에서 자막·줌·팬과 함께 읽히는가 | | |

비교 미리보기 경로:
모바일 미리보기 경로:
재보정과 재검토 결과:
남은 문제:
```

사진 같은 손과 3D 배경이 섞인 경우 인물 얼굴만 맞아도 미달이다. 선로 구조를 고친 결과가 딱딱한 렌더처럼 변한 경우 구조는 통과, 화풍은 수정 필요로 기록한다. 화면 출력과 무관한 단독 파츠 작업의 모바일 항목은 해당 없음으로 기록할 수 있다.
