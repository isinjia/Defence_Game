# 생성·편집 프롬프트 틀

괄호를 현재 작업에 맞게 채운다. 참조 이미지 파일은 반드시 실제 도구 입력에 넣는다.

```text
작업: [신규 / 부분 수정 / 화풍 보정 / 구조를 설계해 전체 재작업]
첨부 역할: [수정 대상], [승인 원화], [승인 장면], [등장인물 외형].
화풍 참조의 인물·소품을 현재 장면에 새로 넣지 않는다.

승인 원화와 같은 섬세한 한국 웹툰풍으로 인물과 배경 모두를 그린다.
가늘고 절제되며 강약 있는 어두운 선, 자연스러운 얼굴과 인체,
차분한 고유색, 부드러운 피부 명암, 정돈된 옷 주름과 큰 그림자 면을 쓴다.
건축·바닥·물·금속 역시 그려진 선과 절제된 명암으로 표현한다.
사진 같은 미세 질감·반사, 3D 광택, 기계적으로 균일한 건축 선과 명암,
굵은 검은 테두리, 각진 두 단계 피부 그림자, 과한 머리 광택을 피한다.
장면의 어둠과 강조색은 유지하되 모바일에서 읽히는 중간 밝기를 남긴다.

장면·시대·고정 외형: [현대 헌터 판타지, 시기·갈래·인물 특징·의상]
카메라와 공간: [구도, 원근, 인물 크기, 바닥 접점, 선로 등 공간 구조]
이번 변경: [사용자의 최신 수정]
유지: [카메라·배치 또는 새로 설계할 범위, 승인된 변경, 소품 수 등]
모바일: [현재 렌더링과 자막에 맞춘 핵심 위치]
출력: [크기·투명 여부·텍스트 제한]
```

‘처음부터 다시’일 때 실패한 구도를 그대로 보존하라는 문장을 넣지 않는다. 새 구조를 명확히 설계하고 동일한 화풍 참조를 첨부한다.
