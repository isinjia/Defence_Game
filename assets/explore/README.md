# 탐색 장면 삽화

승인된 웹툰풍 재제작 삽화 23종. `js/explore_cutscene.js`의 기존 탐색 장면 번호와 연결하며, 본문·선택지·판정·다시 보기 흐름은 유지한다. 사건 공용 삽화 14종은 `assets/events/`에 있다.

- 기준: `docs/비주얼_스타일_기준.md`, 서윤·진서해 원화와 승인된 급식 천막 장면.
- 배포 형식: 1280×720 WebP. 참조·장면별 프롬프트는 `제작기록.json`에 기록한다.
- 구도: 실제 사건·탐색 UI의 390×844·320×900 표시를 검토했다.
- 내용: 선택하기 전 발견한 상황을 표현한다. 상자가 괴수인지 등 판정 결과를 그림에서 미리 드러내지 않는다. 무작위 인물의 얼굴은 식별되지 않게 한다.
- 광맥은 천장에서 아래로 자라는 결정으로 표현해 바닥의 결정 기둥 장면과 구분한다. 벽화 속 사람 모양은 벽에 그린 문양이며 실제 관찰자는 추가하지 않는다.
