# 각성 전야 삽화

내장 `image_gen` 도구로 제작한 프롤로그용 삽화 66종입니다. 2026-11-12 승인한 재제작본을 적용했습니다. [비주얼 스타일 기준](../../docs/비주얼_스타일_기준.md)에 따라 서윤·진서해 원화와 승인된 급식 천막 컷을 실제 참조해 얇은 선화·무광 고유색·절제된 명암으로 통일했습니다. 과한 재질 광택·바닥 반사·미세 질감·발광을 줄였습니다. 사람, 사람 실루엣, 손, 초상화 없이 장소·사물·괴수·각성의 흔적으로 내용을 표현합니다.

- 게임 연결: `js/prologue_cutscene.js`의 `sceneImages`, `imageFor`.
- 여섯 장소의 게이트 브레이크는 각 장소의 전용 그림을 사용합니다. 이후 장비·각성·첫 싸움에서도 해당 장소를 유지합니다.
- 생성 프롬프트와 이미지 크기: `제작기록.json`.
- 전체 검토: 로컬 서버에서 `assets/prologue/gallery.html`을 엽니다.
- 배포용 그림: WebP. 생성된 원본 PNG는 생성 도구의 원래 저장 위치에 보존합니다.

그림은 기존 프롤로그 카드의 정지 이미지로 표시됩니다. 본문·선택지·점수·난수·진행 방식은 바꾸지 않습니다. 모바일에서는 중앙부를 잘라 표시하므로 핵심 사물은 중앙 가로 영역 안에 배치했습니다.

390×844·320×900의 실제 프롤로그 CSS 크롭에서 검토했으며, 호랑이·뿔 괴수·낙하산에는 잘림을 피할 여백을 확보했습니다. 꿈의 빈 돌 제단(편지·오브 없음), 지하철의 넓은 게이트와 승강장·선로 분리를 유지합니다. 오프닝이 같은 프롤로그 파일을 참조하는 장면에는 같은 그림이 표시됩니다.

생성 결과를 다시 최적화할 때는 `python tools/refresh_prologue_art.py <manifest.json>`을 사용합니다. 입력 목록은 `id`, `source`(원본 PNG 경로), `prompt`를 갖는 객체 배열입니다. Pillow가 필요합니다.
