# 웹툰풍 이미지 파츠

얼굴·헤어·의상·종족 장신구 투명 WebP를 조합한다. 400×600 기준 좌표는 `manifest.json`에 있다. 큰 초상화는 상단 400×480을, 원형 아이콘은 얼굴 영역을 표시한다.

## 수량 (10~40대 초반)

성별마다 대략 기존 대비 5배 풀을 쓴다.

| 종류 | 성별당 | 비고 |
|------|--------|------|
| 얼굴 | 18 | 성인·청소년 15 + 유스(10~12세) 3 |
| 헤어 | 20 | 스타일×모발색 |
| 의상 | 30 | 6종 스타일×색 변형 |
| 기본 몸체 | 4 | 매우 마름·보통·근육질·통통, 성인 전용 |
| 특징 | 6 | 엘프 귀, 수인 귀, 용인 뿔, 오크 송곳니, 드워프 수염, 안경 |

초상 나이는 **10~42세**로 맞춘다. 그 밖 나이의 인물도 이 구간 파츠로 보인다(중년·노년 전용 얼굴은 쓰지 않음).

의상 스타일(인덱스 `% 6`): 코트, 현대 한복, 차이나 칼라, 전술복, 아동·평상복, 두꺼운 외투.

`js/portrait_parts.js`가 시드·성별·나이·종족·의상으로 파츠를 고른다. 기존 완성 초상화 목록에 등록한 그림은 우선 적용한다.

## 확장·재생성

```bash
# 색·톤 변형 + generated/ 신규 얼굴 반영
python3 tools/expand_portrait_parts.py

# 원본 아틀라스에서 기본 6종 추출(있을 때)
python3 tools/prepare_portrait_parts.py --source-dir /path/to/generated_images
```

`assets/portraits/parts/generated/face-{m|f}-{index}.png` 를 두면 해당 인덱스 얼굴을 덮어쓴다. 신규 얼굴은 검정 배경·민머리·목 포함 정면이 등록 좌표(144×250)에 맞게 잘린다.

얼굴 중앙축과 눈·턱·목선, 옷깃이 맞는지 확인한다. 긴 머리는 의상 위로 내려오므로 하단이 초상화 안에서 일자로 잘리지 않아야 한다. 게임 저장 형식은 유지하되, 외형 시드 해시 키는 풀 확장에 맞춰 `webtoon-parts-v2`를 쓴다.

## 등록 위치 보정

포니테일과 흰색 올림머리는 정면 얼굴을 기준으로 재제작한 400×600 전체 캔버스 파츠다. 투명 여백도 위치 정보이므로 자동으로 잘라내지 않는다. 목 피부는 옷깃 외곽을 벗어나지 않도록 전용 클립을 적용하며, 평상복은 넓은 목선을 별도로 사용한다. 안경·귀·송곳니·수염은 남녀의 실제 눈·입·귀 위치에 맞춰 `select`에서 좌표를 보정한다. 파츠 URL 캐시 버전은 `v=8`이다.

안경은 얇은 테의 별도 고해상도 파츠를 사용한다. 렌즈 내부는 완전 투명이며 5:1 비율을 유지한다. 성별뿐 아니라 얼굴 변형별 눈높이·폭으로 배치하고, 앞머리보다 먼저 그려 안경 다리가 머리카락 위로 올라오지 않게 한다.

검은 긴 머리와 은발은 정면 기준으로 새로 제작한 400×600 파츠이며, 하단 부분을 세로로 늘리지 않는다. 머리 끝은 가슴 위쪽에서 자연스럽게 끝난다. 도포의 열린 V 목선 아래는 해당 얼굴 파츠의 목 피부를 이어 넣어 빈 공간이 생기지 않게 한다.

옷깃의 앞뒤는 `svg` 합성 단계에서 분리한다. 뒤깃 → 얼굴·목 → 앞깃 → 턱을 포함한 머리 → 장신구·머리카락 순서로 표시하며, 턱 윤곽 클립은 얼굴 계열(성인 0~2·유스) 끝점을 따른다. 여성 전술복·외투의 검은 타원형 목구멍은 뒤쪽으로 보내고 앞쪽 옷깃은 목을 덮는다. 남성 머리와 머리카락·장신구는 함께 8px 아래로 배치해 목 노출을 줄인다. 코트는 뒤깃과 안쪽 칼라를 분리하며, 남성은 실제 안쪽 목선에 맞춰 28px 보정한다. 같은 의상의 색 변형에도 동일하게 적용한다. 여성 위치는 유지하며 원형 아이콘의 프레임도 같은 오프셋을 적용한다.

## 생성과 외형 선택

생성 화면은 상체만 담는 400×440 구도다. 남녀마다 매우 마름·보통·근육질·통통 네 체형의 통합 원화를 쓴다. 턱·목·어깨는 한 장으로 유지하고 얼굴의 눈·코·입 영역만 교체해 이음새가 턱에 생기지 않게 한다. 체형은 원화를 따로 그렸으며 몸을 가로나 세로로 늘리지 않는다.

피부색은 기본(얼굴 원화 기준)·밝은·중간·구릿빛·짙은 다섯 선택이다. 피부 마스크를 통해 피부에 색을 적용하며 흰자·윤곽선·속옷을 보존한다. 입술은 색감을 남기면서 밝기를 피부톤에 맞춘다. 코끝과 볼의 밝은 부분, 피부 음영, 반투명 가장자리도 피부 영역으로 포함한다. 엘프 귀도 피부색을 따른다. 체형과 피부색은 독립적이며 외형 시드와 성별을 바꿔도 선택이 유지된다.

`body-m`/`body-f` 배열은 보통·매우 마름·근육질·통통 순서다. 원본 1254×1254 이미지는 턱과 얼굴 폭을 기준으로 균일 배율로 등록한다. 피부 기준과 피부 마스크는 아래 도구로 갱신한다. 기본 파츠 준비·확장 도구는 체형 등록을 보존하고 피부 기준·마스크를 함께 갱신한다.

```bash
python3 tools/prepare_wardrobe_parts.py --source-dir /path/to/generated_images
python3 tools/calibrate_portrait_skin.py
```

`js/wardrobe.js`가 출신 생활복 → 직업복 → 방어구 외형을 결정한다. 옷을 입어도 동일한 체형의 얼굴·턱·목이 유지되고 옷의 폭은 체형에 맞춘다. 플레이어의 `bodyType`·`skinTone`은 저장되며 옛 저장은 보통·기본으로 채운다. NPC 체형은 저장값 또는 인물 시드로 고정한다. 체형·피부색은 능력치와 장비 효과를 바꾸지 않는다. 이미지 캐시 버전은 `v=8`이다.

## 피부색·체형 렌더링 보정

얼굴·헤어·장신구의 크기는 매우 마름 86%·보통 92%·근육질 96%·통통 100%다. 목 아래를 기준점으로 줄이고 목에서 어깨로 이어지는 구간은 연속 좌표 변환을 적용한다. 피부색과 몸의 비율을 캔버스에서 한 장의 PNG로 계산해 캐시하며, SVG 필터와 분할된 `use` 조각은 사용하지 않는다. 화면과 지도 얼굴 표식에 같은 계산 결과를 사용한다.

눈 보호 영역은 원본의 실제 눈 윤곽을 사용한다. 피부색 변형도 같은 원본의 눈 윤곽을 공유하고 피부 알파를 마스크에 중복 곱하지 않는다. 여성 헤어 4·10·15는 원본 크기에 맞춘 `[80,24,240,262]` 위치를 사용한다. 화풍이 다른 성인 얼굴 3·4·6·9·12는 해당 시드에서 기존 웹툰풍 얼굴로 대체하며, 나머지 조합은 유지한다.

여성 헤어는 동일 파츠를 앞·뒤 레이어로 나누어 합성한다. 아래 뺨과 턱에서는 통합 원화의 실제 윤곽을 따르며, 귀 주변은 앞머리가 덮고 긴 머리는 목 아래에서 다시 앞으로 이어진다. 앞·뒤 레이어의 알파를 나누므로 가장자리도 중복으로 진해지지 않는다. 얼굴 표정 파츠는 눈·코·입 안쪽으로 좁혀 원래 파츠의 다른 턱선이 겹치지 않게 한다.

남성 코트는 턱 위치를 28px 보정해 안쪽 칼라와의 간격을 줄이고, 목 피부를 실제 칼라 구멍에 맞춰 이어 준다. 닫힌 칼라의 기존 범위는 유지해 피부가 옷 바깥으로 나오지 않게 한다.
