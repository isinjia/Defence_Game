# 웹툰풍 이미지 파츠

얼굴 12장, 헤어 12장, 의상 12장, 종족·장신구 6장, 총 42장의 투명 WebP를 조합한다. 400×600 기준 좌표는 `manifest.json`에 있다. 큰 초상화는 상단 400×480을, 원형 아이콘은 얼굴 영역을 표시한다. 원본 생성 아틀라스는 생성 도구의 `generated_images` 경로에 보존한다.

- 얼굴: 성별마다 성인 3종, 중년·노년·아이 각 1종.
- 헤어: 성별마다 6종. 중년과 노년은 새치·흰머리를 적용한다.
- 의상: 코트, 현대 한복, 차이나 칼라, 전술복, 아동 평상복, 두꺼운 외투.
- 특징: 엘프 귀, 수인 귀, 용인 뿔, 오크 송곳니, 드워프 수염, 안경.

`js/portrait_parts.js`가 시드·성별·나이·종족·의상으로 파츠를 선택한다. 기존 완성 초상화 목록에 등록한 그림은 우선 적용한다. 파츠는 눈·얼굴을 코드로 다시 그리지 않으며, 배경·등급 테두리·오크 피부색만 SVG로 처리한다. 지도 마커는 외부 이미지 제한을 피하도록 파츠를 내장한 SVG로 변환한다.

새 파츠는 같은 기준 좌표에 등록한다. 생성 이미지 추출 도구는 Pillow, NumPy, SciPy가 필요하다.

```bash
python3 tools/prepare_portrait_parts.py --source-dir /path/to/generated_images
```

얼굴 중앙축과 눈·턱·목선, 옷깃이 맞는지 확인한다. 긴 머리는 의상 위로 내려오므로 하단이 초상화 안에서 일자로 잘리지 않아야 한다. 게임 저장 형식과 외형 시드 값은 바꾸지 않는다.

## 등록 위치 보정

포니테일과 흰색 올림머리는 정면 얼굴을 기준으로 재제작한 400×600 전체 캔버스 파츠다. 투명 여백도 위치 정보이므로 자동으로 잘라내지 않는다. 목 피부는 옷깃 외곽을 벗어나지 않도록 전용 클립을 적용하며, 평상복은 넓은 목선을 별도로 사용한다. 안경·귀·송곳니·수염은 남녀의 실제 눈·입·귀 위치에 맞춰 `select`에서 좌표를 보정한다. 파츠 URL의 버전 표시는 교체한 이미지가 이전 캐시로 보이지 않도록 갱신한다.

안경은 얇은 테의 별도 고해상도 파츠를 사용한다. 렌즈 내부는 완전 투명이며 5:1 비율을 유지한다. 성별뿐 아니라 얼굴 변형별 눈높이·폭으로 배치하고, 앞머리보다 먼저 그려 안경 다리가 머리카락 위로 올라오지 않게 한다. 안경 파츠 캐시 버전은 `v=3`이다.

검은 긴 머리와 은발은 정면 기준으로 새로 제작한 400×600 파츠이며, 하단 부분을 세로로 늘리지 않는다. 머리 끝은 가슴 위쪽에서 자연스럽게 끝난다. 두 긴 머리의 캐시 버전은 `v=3`이다. 도포의 열린 V 목선 아래는 해당 얼굴 파츠의 목 피부를 이어 넣어 빈 공간이 생기지 않게 한다.

옷깃의 앞뒤는 `svg` 합성 단계에서 분리한다. 뒤깃 → 얼굴·목 → 앞깃 → 턱을 포함한 머리 → 장신구·머리카락 순서로 표시하며, 턱 윤곽 클립은 얼굴별 끝점을 따른다. 여성 전술복·외투의 검은 타원형 목구멍은 뒤쪽으로 보내고 앞쪽 옷깃은 목을 덮는다. 남성 머리와 머리카락·장신구는 함께 8px 아래로 배치해 목 노출을 줄인다. 여성 위치는 유지하며 원형 아이콘의 프레임도 같은 오프셋을 적용한다.
