# 웹툰풍 이미지 파츠

얼굴·헤어·의상·종족 장신구 투명 WebP를 조합한다. 400×600 기준 좌표는 `manifest.json`에 있다. 큰 초상화는 상단 400×480을, 원형 아이콘은 얼굴 영역을 표시한다.

## 수량 (10~40대 초반)

성별마다 대략 기존 대비 5배 풀을 쓴다.

| 종류 | 성별당 | 비고 |
|------|--------|------|
| 얼굴 | 18 | 성인·청소년 15 + 유스(10~12세) 3 |
| 헤어 | 20 | 스타일×모발색 |
| 의상 | 30 | 6종 스타일×색 변형 |
| 기본 몸체 | 1 | 생성용 속옷 차림, 성인 전용 |
| 특징 | 6 | 엘프 귀, 수인 귀, 용인 뿔, 오크 송곳니, 드워프 수염, 안경 |

초상 나이는 **10~42세**로 맞춘다. 그 밖 나이의 인물도 이 구간 파츠로 보인다(중년·노년 전용 얼굴은 쓰지 않음).

의상 스타일(인덱스 `% 6`): 코트, 현대 한복, 차이나 칼라, 전술복, 아동·평상복, 두꺼운 외투.

`js/portrait_parts.js`가 시드·성별·나이·종족·의상으로 파츠를 고른다. 기존 완성 초상화 목록에 등록한 그림은 우선 적용한다.

## 확장·재생성

```bash
# 색·톤 변형 + generated/ 신규 얼굴 반영
python3 tools/expand_portrait_parts.py

# 원본 아틀라스에서 기본 6종 추출(있을 때)
python3 tools/prepare_portrait_parts.py --source-dir /path/to/generated_images
```

`assets/portraits/parts/generated/face-{m|f}-{index}.png` 를 두면 해당 인덱스 얼굴을 덮어쓴다. 신규 얼굴은 검정 배경·민머리·목 포함 정면이 등록 좌표(144×250)에 맞게 잘린다.

얼굴 중앙축과 눈·턱·목선, 옷깃이 맞는지 확인한다. 긴 머리는 의상 위로 내려오므로 하단이 초상화 안에서 일자로 잘리지 않아야 한다. 게임 저장 형식은 유지하되, 외형 시드 해시 키는 풀 확장에 맞춰 `webtoon-parts-v2`를 쓴다.

## 등록 위치 보정

포니테일과 흰색 올림머리는 정면 얼굴을 기준으로 재제작한 400×600 전체 캔버스 파츠다. 투명 여백도 위치 정보이므로 자동으로 잘라내지 않는다. 목 피부는 옷깃 외곽을 벗어나지 않도록 전용 클립을 적용하며, 평상복은 넓은 목선을 별도로 사용한다. 안경·귀·송곳니·수염은 남녀의 실제 눈·입·귀 위치에 맞춰 `select`에서 좌표를 보정한다. 파츠 URL 캐시 버전은 `v=4`이다.

안경은 얇은 테의 별도 고해상도 파츠를 사용한다. 렌즈 내부는 완전 투명이며 5:1 비율을 유지한다. 성별뿐 아니라 얼굴 변형별 눈높이·폭으로 배치하고, 앞머리보다 먼저 그려 안경 다리가 머리카락 위로 올라오지 않게 한다.

검은 긴 머리와 은발은 정면 기준으로 새로 제작한 400×600 파츠이며, 하단 부분을 세로로 늘리지 않는다. 머리 끝은 가슴 위쪽에서 자연스럽게 끝난다. 도포의 열린 V 목선 아래는 해당 얼굴 파츠의 목 피부를 이어 넣어 빈 공간이 생기지 않게 한다.

옷깃의 앞뒤는 `svg` 합성 단계에서 분리한다. 뒤깃 → 얼굴·목 → 앞깃 → 턱을 포함한 머리 → 장신구·머리카락 순서로 표시하며, 턱 윤곽 클립은 얼굴 계열(성인 0~2·유스) 끝점을 따른다. 여성 전술복·외투의 검은 타원형 목구멍은 뒤쪽으로 보내고 앞쪽 옷깃은 목을 덮는다. 남성 머리와 머리카락·장신구는 함께 8px 아래로 배치해 목 노출을 줄인다. 코트는 뒤깃과 안쪽 칼라를 분리하며, 남성은 실제 안쪽 목선에 맞춰 16px 보정한다. 같은 의상의 색 변형에도 동일하게 적용한다. 여성 위치는 유지하며 원형 아이콘의 프레임도 같은 오프셋을 적용한다.

## 생성부터 복장 갖추기

생성 화면은 성인 남녀 기본 몸체·속옷 파츠(`body-m.webp`, `body-f.webp`)를 쓴다. 얼굴·머리 시드는 그대로 유지하고 `outfit: 'underwear'`로 요청한다. 생성용 뷰포트는 400×800, 기본 몸체 원본 등록은 400×900이며 몸의 비율을 늘리지 않는다. 어린 인물은 기존 평상복 파츠를 유지한다. 몸체 목과 얼굴 목은 마스크로 부드럽게 이어 붙인다.

`js/wardrobe.js`가 생성 이후 복장을 결정한다. 프롤로그에서는 출신에 따른 생활복을 입고, 각성 후에는 직업 계열에 따른 복장을 입는다. 시작 방어구는 직업을 따르며 이후 교체한 방어구는 물건의 종류를 따른다. 방어구 해제 시에도 기본 직업복을 유지한다. 초상화·원형 아이콘·지도 마커 모두 같은 복장을 쓰며 옛 저장에는 기본 외형 필드를 채운다. 의상은 기존 스타일 파츠를 재사용하고 능력치·아이템 효과는 바꾸지 않는다.

```bash
python3 tools/prepare_wardrobe_parts.py --source /path/to/exec-632ae241-68ff-4f98-8738-00fa3cdd7435.png
```
