# 30대 인상 얼굴 보정본 — 미사용 보관

사용자 지시: “이전것과 보정한것을 둘다 푸시하는데 보정한것은 일단 사용안하고. 에셋에만 넣어둬”.

이 폴더의 남녀 각 5종은 보정본 보관 전용이다. 게임에서 읽는 `parts/manifest.json`과 `js/portrait_parts.js`에는 이 경로를 등록하지 않는다. 현재 외형 선택지에는 이전 시안을 사용한다.

- `face-{m|f}-33~37.webp`: 보정 얼굴, `-skin.webp`: 피부 마스크
- 같은 이름의 PNG: 파츠 원본, `faces-30s-*-sheet.png`: 생성 원본 시트
- 참조·제작: `.agents/skills/enforce-defence-visual-style/SKILL.md`, 한서윤·진서해 원화와 급식 천막 승인 장면을 실제 참조. 20대 같다는 지적 뒤 눈 밑·볼·입 주변을 보정한 버전.
- 파일 이름은 활성 파츠와 같지만 디렉터리가 다르다. 임의로 복사하거나 자동 등록하지 않는다.
