# 성인 얼굴 30대 중후반 버전 — 게임 미사용 보관

사용자 승인한 기존 0~2번의 36~39세 인상 시안을 기준으로 성인 얼굴 전체 대응본을 준비했다. 앞선 “보정본은 일단 사용하지 않고 에셋에만 보관” 지시를 유지한다. 이 폴더를 게임 외형 등록 목록이나 렌더러에 연결하지 않았다.

| 구분 | 대응 대상 | 고유 원화 | 피부색 변형 연결 |
|---|---:|---:|---:|
| 남성 | 28 | 21 | 7 |
| 여성 | 30 | 23 | 7 |
| 합계 | 58 | 44 | 14 |

- [원본과 비교](index.html), [대응·등록 좌표·검토 상태](manifest.json).
- `face-*.webp`: 고유 얼굴 원화 44장. `face-*-skin.webp`: 피부 마스크 44장. 144×250.
- `sources/`: 승인 기준 2장과 추가 생성 8묶음의 투명 PNG 원본.
- 피부색 변형 5·7·8·10·11·13·14번은 0~2번 원화를 참조한다. 원본 피부색은 `displaySkinRgb`로 보존하며 별도 신규 인물·원화로 중복 계산하지 않는다. 향후 사용하려면 피부 마스크로 해당 색을 적용해야 한다.
- 사용 제외 얼굴·아동 15~17번은 제외했다. 남성 19·23번의 현재 대체 규칙도 유지한다.

## 제작·확인

필수 스킬 `.agents/skills/enforce-defence-visual-style/SKILL.md`와 `docs/비주얼_스타일_기준.md`를 따랐다. 매 호출에 대상 원본 시트, 승인된 남녀 30대 중후반 시안, 한서윤·진서해 원화, 급식 천막 승인 장면을 실제 참조했다. 같은 사람의 눈·코·입·표정과 흉터·주근깨·점을 보존하면서 눈 밑·눈가·팔자·입가·볼의 나이 변화를 추가했다.

생성 원본과 동일 헤어·보통 체형·자연 피부색·전술복 조합의 58종 좌우 비교 10장을 직접 확인했다. 색상 변형도 원본 색상 정보를 적용해 비교했다. 합성 검토는 작업 임시 폴더에 보존했다. 모든 피부색·체형·안경·헤어 조합을 검증한 것은 아니며 체감 나이를 객관적으로 보장하지 않는다.

## 남은 보정

- 남성 31·33·34번, 여성 33·35·36번: 작은 초상화에서 승인 기준보다 나이 변화가 약해 추가 보정 권장.
- 전체 생성·합성 비교 후 해당 묶음에 추가 보정을 시도했지만 이미지 생성 도구의 `usage_limit_reached`로 실행되지 않았다. 현재 결과는 숨기거나 통과로 바꾸지 않고 보관했다.
- 원본별 세부 표정·구조 차이와 미세 알파 잡음이 남을 수 있다. 향후 게임 적용 전에 전체 조합과 외곽을 재확인해야 한다.

게임 자산의 기존 원본·현재 얼굴 선택 풀·탐색 화면은 바꾸지 않았다. 스모크 테스트는 사용자 지시가 없어 실행하지 않았다. 사용자 지시로 보관본을 푸시하고 GitHub Pages로 배포한다.
