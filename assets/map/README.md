# 웹툰풍 월드맵 타일

승인된 4열×3행 원화에서 지형 11종을 추출했다. 마지막 중립 칸은 게임에 사용하지 않는다. 타일은 362×362 PNG이며 작은 지도 칸에서는 기존 렌더러의 아틀라스로 축소해 사용한다.

지형 순서는 바다·황무지·산악·폐허·에테르·도시·해상 연결로·북부 봉쇄 구역·숲·들판·오염 지대다. 땅의 기본색을 통일하고 윤곽선과 단순한 명암으로 구분한다.

`overlays/`에는 가장자리 10종과 모서리 40종을 둔다. 투명 픽셀의 숨은 RGB만 제거해 용량을 줄였으며, 승인된 미리보기와 알파 및 표시 색상이 동일하다. 타일 이미지 URL은 `?v=webtoon-1`을 붙여 이전 그림 캐시를 갱신한다.

```bash
# 원화 시트로 타일과 연결 이미지를 모두 준비
python3 tools/prepare_webtoon_map_tiles.py --sheet /path/to/sheet.png

# 현재 등록된 타일로 연결 이미지만 다시 만들기
python3 tools/prepare_webtoon_map_tiles.py

# 320px·412px·1280px에서 좌표·안개·북부 변경·게임 상태 보존 확인
node tools/map_terrain_test.js
```

지도 좌표, 이동 비용, 지형 배치와 탐사 규칙은 바꾸지 않는다.
