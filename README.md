# 게이트 크로니클 : 각성 연대기

귀곡팔황(鬼谷八荒)의 자유 성장 구조를 한국형 SF 헌터물로 옮긴 브라우저 RPG입니다.

- 시작: 프롤로그(선택 8번) → 헌터 자격 시험 튜토리얼(임시 파티 전투·조작 안내) → 시험 파티 유지 또는 혼자 시작

## 바로 플레이

https://isinjia.github.io/Defence_Game/

GitHub Pages로 배포됩니다. 저장소의 Settings → Pages에서 Source를 "Deploy from a branch"로, 브랜치를 `claude/happy-turing-czlfa3`, 폴더를 `/ (root)`로 한 번 지정하면 이후 푸시마다 자동 갱신됩니다.

## 버전

현재 버전은 화면 오른쪽 아래와 타이틀에 표시됩니다. 업데이트할 때마다 0.01씩 올립니다.

```bash
python3 tools/bump_version.py
```

`js/data.js` 의 버전과 `index.html` 의 캐시 방지용 버전 표시가 함께 바뀝니다.

## 빌드

`index.html` 은 빌드된 `dist/game.js` 와 `dist/style.css` 만 불러옵니다. 소스(`js/`, `css/`)를 고친 뒤에는 빌드해야 반영됩니다.

```bash
bash tools/build.sh
```

빌드는 소스 스크립트를 하나로 합치고, 구형 휴대폰 브라우저(iOS 11, Chrome 61 이상)도 읽을 수 있는 문법으로 변환합니다. esbuild 를 npx 로 내려받아 씁니다.

## 로컬 실행

빌드 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. `index.html` 을 직접 열어도 됩니다.

## 세계관

2087년. 20년 전 제주에서 첫 게이트가 열린 "대붕괴" 이후 한반도 전역에 게이트가 출현했다.
에테르 오염으로 일반인의 평균 수명은 60세로 줄었지만, 각성자는 등급이 오를수록 더 오래 산다.
목표는 S급 이상만 들어갈 수 있는 제주 격리 섬에서 **원초의 게이트**를 닫는 것.

## 시작 방식

- **이야기로 각성** (추천): 이름과 성별만 정합니다. 출신은 무작위로 정해지고, 출신마다 10가지씩 모두 50가지 사연 중 하나로 시작합니다. 도입에서 고른 선택에 따라 각성 이야기가 13갈래로 갈립니다. 게이트 브레이크(장소 7곳), 병상, 유물, 꿈과 신병, 에테르 폭풍, 각성자 범죄, 불법 각성제, 결투, 조난, 게이트 체험 관광, 친구의 폭주, 정기 검진, 짐꾼 생존기 가운데 괴수가 나오는 이야기도 있고 사람이나 재난, 병과 싸우는 이야기도 있습니다. 마지막은 관리국 판정, 길드 면접, 미등록 브로커 중 하나로 끝납니다. 어느 경로든 선택은 8번 이하이고, 그 선택이 속성·직업·재능·특성을 정합니다. 이야기 속 소꿉친구는 게임에 실제 인물로 등장합니다.
- **직접 설정**: 출신, 속성, 직업 후보, 특성을 직접 고릅니다.
- 이름 옆 주사위로 무작위 이름을 뽑을 수 있고, 마지막에 쓴 이름이 다음 새 게임의 기본값이 됩니다.

## 직업과 파티

- **직업 37종**: 전투·수호·암살·사격·마법·소환·지원·초능력·동방(무당, 도사) 9계열 32종 + 히든 5종. 각성할 때 후보 3개가 판정되고 그중 하나를 고릅니다.
- **전직**: C급과 S급에서 전직 시험. 예) 검사 → 검귀 → 검성, 무당 → 대무당 → 만신.
- **히든 직업**: 흑염검사, 심연의 사도, 기계 교감자, 문지기, 대붕괴의 아이. 특정 기연을 끝까지 따라가야 얻습니다.
- **파티 최대 5명**: 관계 50 이상인 인물을 초대하거나 도시 용병 사무소에서 고용합니다. 혼자서도 갈 수 있고, 적의 규모는 인원에 맞춰 커집니다.
- **용병 모집**: 용병 사무소에서 할 일(게이트 공략, 괴수 토벌, 동행 이동, 장기 동행)과 등급, 보수를 적어 공고를 올리면 성격·실력·평판에 맞는 헌터만 응합니다. 선금 절반, 일을 해내면 잔금을 줍니다. 계약한 일을 미루면 따지다가 떠나고, 공고보다 위험한 곳에 끌고 가면 화를 내며, 잔금을 못 주면 소문이 납니다. 잘 끝나면 기뻐하고, 관계가 깊으면 계약이 끝나도 남습니다. 돈은 마음을 바꿉니다. 거절한 사람에게 웃돈을 제시하면 응하기도 하고(탐욕스러운 사람은 먼저 흥정을 걸어 옵니다), 따지는 용병은 수당을 쥐여 주거나 연장 수당으로 기한을 늘려 달랠 수 있습니다. 다만 의협심 있는 사람의 신념이나 온화한 사람의 목숨 문제는 돈으로 안 됩니다.
- **소속 파티**: 헌터넷 모집 게시판에서 지원하거나 리더의 초대를 받아 다른 헌터가 이끄는 파티에 정식 파티원으로 들어갈 수 있습니다. 리더가 매달 일정(게이트 공략, 토벌, 호위, 합동 훈련)을 잡아 제안하고, 참가하면 함께 이동해 바로 들어갑니다. 자주 빠지면 신뢰가 떨어져 밀려나고, 게이트 보상은 75%를 받습니다. 리더보다 두 등급 이상 강해지면 리더 자리를 넘겨받을 수 있습니다.
- **ATB 전투**: 모든 캐릭터의 행동 게이지가 속도에 비례해 실시간으로 찹니다. 가득 차면 행동하고, 내 게이지가 차면 커맨드를 입력할 때까지 시간이 멈춥니다. 1배속·2배속, 자동 전투 지원.
- **성격대로 싸우는 동료**: 호전은 강적에게 돌진, 온화는 일찍 치유, 의협은 위기의 동료를 감싸 대신 맞고, 탐욕은 막타를 노리다 위험하면 도망, 냉담은 상성 유리한 적만 노립니다.

## 종족과 나이

- **이계 종족 5종**: 오크, 엘프, 드워프, 수인, 용인. 대붕괴 뒤 게이트 너머에서 건너와 정착했습니다. 종족마다 외모, 능력치, 수명, 이름, 선호 직업이 다릅니다.
- **나이대**: 아기, 어린이, 청소년, 성인, 중년, 노인. 초상화가 나이에 맞게 바뀌고, 플레이어도 나이를 먹으면 흰머리와 주름이 생깁니다.
- 아이 NPC는 각성하기 전이라 말 걸기와 선물만 할 수 있고, 18세가 되면 각성자로 등록됩니다.

## 샌드박스 스토리

정해진 줄거리도, 정해진 목표도 없습니다. 어떻게 살지는 플레이어가 정합니다.

- **연계 기연 8종**: 균열교, 잃어버린 가족, 제주의 목소리, 피험자 7번, 포차 사장님, 고철 드론 누리, 부산 암시장, 백호 가문. 단계마다 선택이 갈리고 놓쳐도 세계는 흘러갑니다.
- **NPC가 먼저 찾아옴**: 도움 요청, 납품 부탁, 대련 신청, 고백, 청혼, 제자 지원, 스승 제안, 돈 부탁, 복수 의뢰.
- **원한의 연쇄**: 누군가를 죽이면 그 사람의 배우자, 자녀, 스승, 친구가 복수를 다짐하고 찾아옵니다.
- **세계 사건**: 게이트 브레이크, 전국 헌터 대회, 정기 경매.
- **계승**: 죽으면 성인이 된 자녀로 이어서 플레이할 수 있습니다.

## 파일 구조

- `js/data.js` : 등급·속성·특성·스킬·지역·길드·괴수·사건 데이터
- `js/data_classes.js` : 직업 37종과 직업 스킬
- `js/prologue.js` : 각성 전야 장면(출신별 도입 50 + 게이트 브레이크 7 + 공통 6)과 판정 규칙
- `js/game.js` : 시간 흐름, 성장, NPC 시뮬레이션, 지도 오브젝트, 상점, 길드, 저장
- `js/society.js` : 도시 시설, 의뢰, 돌파 재료와 유물, NPC 사회 시뮬레이션, 세계 사건
- `js/story.js` : 스토리 엔진과 NPC 부탁
- `js/story_events.js` : 단발 사건
- `js/story_chains.js` : 연계 기연과 특수 사건
- `js/world.js` : 한반도 타일맵 생성, 지형, 지역 구분, 길찾기
- `js/combat.js` : 파티 턴제 전투, 직업·성격별 AI, 연출용 이벤트 기록
- `js/fx.js` : 괴수·사건 삽화를 SVG로 생성, 타이틀·돌파 연출
- `js/portrait.js` : 웹툰풍 캐릭터 일러스트 생성, 그림 파일이 있으면 우선 사용
- `js/mapview.js` : 캔버스 월드맵 렌더러 (드래그, 확대, 미니맵)
- `js/ui.js` : HUD, 메뉴 창, 전투 화면
- `js/ui_town.js` : 도시 화면, 사건 창, 대회, 돌파, 계승
- `js/merc.js` : 용병 모집 공고, 성격별 응답, 계약 이행과 감정 반응
- `js/crew.js` : 소속 파티(모집 게시판, 리더의 일정 제안, 신뢰, 보상 분배)
- `js/ui_prologue.js` : 시작 방식 선택, 각성 전야 진행, 판정 결과
- `css/style.css` : SF 전술 HUD 스타일 (모바일 대응)

기본 그림은 모두 코드로 그립니다. 캐릭터 일러스트는 `assets/portraits/` 에 그림 파일을 넣으면 그 그림으로 바뀝니다. 방법과 생성 프롬프트는 `assets/portraits/README.md` 에 있습니다.

진행 상황은 매달 브라우저 localStorage에 자동 저장됩니다.
