# 게이트 크로니클 : 각성 연대기

귀곡팔황(鬼谷八荒)의 자유 성장 구조를 한국형 SF 헌터물로 옮긴 브라우저 RPG입니다.

## 실행

빌드 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. `index.html` 을 직접 열어도 됩니다.

## 세계관

2087년. 20년 전 제주에서 첫 게이트가 열린 "대붕괴" 이후 한반도 전역에 게이트가 출현했다.
에테르 오염으로 일반인의 평균 수명은 60세로 줄었지만, 각성자는 등급이 오를수록 더 오래 산다.
목표는 S급 이상만 들어갈 수 있는 제주 격리 섬에서 **원초의 게이트**를 닫는 것.

## 귀곡팔황 → 헌터물 대응표

| 귀곡팔황 | 게이트 크로니클 |
|---|---|
| 경지 (연기·축기·결정…) | 각성 등급 F → SS, 각 등급 초기·중기·후기 |
| 수위·돌파 | 에테르 축적 → 돌파 시도 (실패 시 내상·수명 손상) |
| 수명 | 기본 60세, 등급마다 증가. 다하면 사망 |
| 선천 특성·뽑기 | 16종 특성 중 3개 + 재능, 재측정 6회 |
| 오행 | 염·빙·뇌·강·영 5속성 상성 |
| 종문 | 5대 길드 (백호·관리국·청룡·현무·주작) |
| 살아있는 NPC | 50명 내외의 각성자가 각자 수련·돌파·이동·사망 |
| 도우·사제 관계 | 관계도 기반 가르침, 동료 영입, 기습, 생사결 |
| 기연·사건 | 랜덤 사건 8종, 선택지 분기 |
| 비경 | 지역별 등급 게이트, 3구역 + 보스 |

## 파일 구조

- `js/data.js` : 등급·속성·특성·스킬·지역·길드·괴수·사건 데이터
- `js/game.js` : 시간 흐름, 성장, NPC 시뮬레이션, 상점, 길드, 저장
- `js/combat.js` : 속도 기반 턴제 전투와 AI
- `js/ui.js` : 화면 렌더링과 입력 처리
- `css/style.css` : 스타일 (모바일 대응)

진행 상황은 매달 브라우저 localStorage에 자동 저장됩니다.
