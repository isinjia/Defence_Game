# 현대 헌터 직업복

승인한 의상 37계열 × 남녀 74벌을 `assets/portraits/outfits/`에 등록했다. 실제 실행 중에는 기본 37개 외에 성·암·목·염·탐색 계열 23개가 추가돼 총 60개 직업이 존재한다. 확장 23개도 역할에 맞는 승인 의상 계열로 연결했다. 전직 후에는 해당 직업의 계열을 유지한다. 신규 원화 60계열을 만들었다는 뜻은 아니다.

- `js/job_outfits.js`: 직업표, 기존 초상 위의 직업복 합성, 플레이어·NPC·임시 지원 헌터 연결.
- `assets/portraits/outfits/manifest.json`: 의상 37계열, 남녀 파일 74개, 목선 기준점과 실제 직업 60개의 연결표.
- 생성 시 속옷과 출신 생활복은 유지하고, 직업이 정해지면 해당 직업복을 입는다.
- 일반 능력치 방어구를 장착해도 직업복을 유지한다. 명시적인 `appearanceOutfit` 또는 코트·외투 등 외형을 나타내는 장비는 그 외형을 우선한다. 장비를 벗으면 직업복으로 돌아온다.
- 기존 저장의 직업 ID로 복장을 계산한다. 별도 저장 이전 필드는 없다.
- 옷깃 뒷판 → 원화의 머리·목 → 옷깃 앞판 → 원화의 턱·앞머리 순으로 합성한다. 피부는 기존 원화만 사용하고, 의상은 피부색 보정 대상에서 제외한다.
- 의상별 목 중심을 등록하고, 체형별 가로 폭을 맞춘다. 기존 머리·얼굴·긴 머리 앞뒤·원형 초상 이동 보정은 유지한다.

## 남성 흑염 코트 비율 보정

사용자가 확인한 시안에 맞춰 흑염검사 계열 남성 코트의 가로 폭을 기존 체형별 폭의 1.368배(첫 시안 14% 확대 후 추가 20%), 세로 축척을 0.82에서 0.94로 조정했다. 머리·얼굴 크기는 유지하며, 옷깃의 앞뒤판·목 마스크와 파츠 선택 좌표에도 같은 배율을 사용한다. 같은 의상을 쓰는 화염술사·발화능력자도 적용된다. 다른 의상과 여성 의상은 기존 비율을 유지한다.

## 검증

`tools/job_outfits_test.js`: 실제 직업 60개·남녀·체형 4개·기본/짙은 피부색의 카드 960건, 원형 초상 120건, NPC 연결 120건 통과. 턱의 원화 픽셀 보존, 목 피부 연결, 피부색에 따른 옷 색상 불변을 확인한다.

남성 흑염 코트 보정 후에도 위 직업복 카드·원형 초상·NPC·지원 헌터 검사가 모두 통과했다. 파츠 선택 좌표와 실제 의상 이미지 좌표의 일치도 함께 확인했다. 모바일 대화창 320×844·390×844에서 네 체형, 총 8건의 화면 가로 넘침이 없음을 확인했다.

전체 연기 검사: 65/66 통과. 초상 관련 검사는 모두 통과했고, 연합 레이드의 ‘소집 공문 창 없음’ 1건은 해당 영역 코드를 수정하지 않고 기록했다.

별도 튜토리얼 자동 검사는 첫 전투 도달 실패로 말풍선과 모바일 전투 화면 검사를 완료하지 못했다. 직업복 검사와 구분해 기록한다.
