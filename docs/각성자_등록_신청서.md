# 각성자 등록 신청서

사용자 승인: 2026-11-13, 미리보기 1안(밝은 종이색 관리국 신청서).

## 적용 범위

프롤로그 또는 직접 생성 이후 실기 시험 전에 뜨는 ‘내 상태 확인’ 창을 신청서 형식으로 표시한다. 정보 탭에서 다시 여는 상태 확인과 시험 후 판정 결과는 기존 표시를 유지한다.

- 상단: 국가 각성자 관리국, 각성자 등록 신청서, 등급 측정 대기.
- 신청인 정보: 기존 초상, 성명, 나이·성별, 거주 지역, 출신.
- 각성 현황: 직업·계열·희귀도·역할, 속성·상성, 직업 설명·전직 경로.
- 이어지는 항목: 보유 기술, 기초 능력 6종, 선천 특성, 소지품, 신청인 서명.
- 하단 고정 버튼: ‘신청서 제출 · 시험장으로’. 기존 `st-go` 처리로 시험을 시작한다.

등급은 실기 시험 후 측정되므로 미리 공개하지 않는다. 기술 상세 보기는 기존 `st-sk` 동작을 사용한다. 추가 입력·동의 절차나 별도 등록 수치는 만들지 않는다.

## 구현 위치

- `js/registration_form.js`: 시험 전 `statusHtml(true)`와 창 스타일 확장.
- `css/registration_form.css`: 종이색·녹색 선·문서 항목 배치, 본문 스크롤 및 고정 하단 버튼.
- `tools/registration_form_test.js`: 모바일·데스크톱 배치, 기술 상세, 긴 이름·빈 목록, 재열람, 시험 전환·저장 검증.
