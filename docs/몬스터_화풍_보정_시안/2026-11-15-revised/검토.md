# 몬스터 87종 재보정 검토

- 사용자 지시: 보정. 보정 후 사용자 “푸시” 지시로 시안 보관·푸시·배포 진행. 게임 괴수 교체는 미실행.
- 이번 70종 재보정, 기존 17종 유지. 후보 87종을 candidates에 통합.
- 기본 재생성 69종 + 여백 후속 편집 15회 = 이미지 도구 총 84회. 타락한 성기사는 반투명 여백 점검 후 추가 편집.
- 실제 참조: 대상 원본 또는 현재 시안 + 승인 인물 원화 seoyun-suit/jin-unmasked + cut-36-ridge + 승인 메카 파괴자.
- 가는 선택적 선, 큰 차분한 고유색면, 절제된 부드러운 명암. 작은 털·나뭇결·균열·금속반사 감소.
- 원본과 최신 시안을 어두운 배경에 나란히 배치한 15장 비교표 육안 검토. 표시 크기 비교를 위해 작업 임시 비교표에서만 알파경계 기준 크롭·축소했다. 실제 PNG 후보는 이미지 생성 도구 결과 그대로다.
- 보관한 index.html과 candidates는 최종 추가 편집까지 반영한 최신 후보다. 비교표는 작업 임시 폴더에만 유지한다.
- 87종 RGBA와 알파0 확인. 알파 ≥8과 ≥128 외곽 기준 사방12% 이상. 극미세 알파1~7 픽셀은 별도 manifest 수치에 기록하며 완전투명 여백과 혼동하지 않음.
- 미리보기 RGB 후광은 실제 어두운 배경 합성에서 제거됨을 비교표로 확인.
- 게임 적용·스모크 테스트 미실행. 시안 보관 후 빌드·커밋·푸시·배포는 후속 지시로 진행.
