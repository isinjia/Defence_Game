재개 시 필수 화풍 스킬과 실제 승인 원화·장면·메카 파괴자를 참조한다. 원본 종류·고유색·주요 소품·구도를 유지하고 투명 PNG 생성 후 실제 알파 합성으로 검토한다. 사용자 확인 후 별도 적용 지시를 받아 게임 자산을 갱신한다. 이번 푸시 승인을 후속 작업의 푸시·배포 승인으로 재사용하지 않는다. 스모크 테스트는 사용자 지시가 있을 때만 실행한다.
