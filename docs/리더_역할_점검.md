# 리더와 파티원의 역할 점검표 (영역 D)

원칙(사용자 결정): **내가 리더일 때 하는 행동은, NPC가 리더일 때 NPC가 똑같이 한다.** 그 입력을 플레이어에게 넘기지 않는다.
플레이어가 파티원이면 NPC 파티원이 하는 행동(의견·따르기·자기 전투·개인 물건·파티 나가기)만 할 수 있다. 화면 배치는 두 경우가 같다.

## 리더가 하는 행동

| 행동 | 내가 리더 | NPC가 리더 | 상태 | 코드 |
|---|---|---|---|---|
| 일정·목적지 정하기 | 지도에서 직접 고른다 | 리더가 이번 달 일정을 잡는다. 나는 참가·불참만 답한다 | 됨 | crew.js crewPlan |
| 월드맵 이동 | 직접 이동 | "리더와 같이 이동"이면 자동 이동. "집결지에서 만난다"는 내가 고른 개인 이동(늦으면 불이익) | 됨 | crew.js answerCrewPlan · leader_rule.js RALLY |
| 게이트 입장 | 게이트를 누른다 | 일정대로 리더가 입장. 게이트를 누르면 "제안"만 된다 | 됨 | leader_rule.js leadGateAsk |
| 층 지도 길 선택·이동 | 칸을 누른다 → 팀 상의 | 리더가 고른다 → 팀 상의 → 자동 이동. 길이 하나면 리더가 앞장선다 | 됨 (v0.344) | council.js · leader_rule.js |
| 사건 선택지 결정 | 직접 고른다 | 리더가 고른다. 나는 따르거나 반대 | 됨 (게이트·탐색 사건) | leader_rule.js leaderGate |
| 판정 담당자 지정 | 직접 고른다 | 리더가 맡길 사람을 고른다 | 됨 | check.js checkLeaderPick |
| 전투 오더 | 동료를 눌러 오더 | 리더만 오더를 낸다. 나는 낼 수 없다 | 됨 | orders.js |
| 철수·도주 결정 | 철수 버튼 | 리더가 정한다. 내 버튼은 "철수 제안"(층·전투마다 한 번). 내가 크게 다치면 리더가 먼저 철수를 정하기도 한다 | 됨 (이번) | leader_rule.js |
| 분배 | 계약대로 자동 | 계약대로 자동 | 입력 없음 | payroll.js · first_team.js share |
| 이동 중 이야기 사건 | 직접 고른다 | **아직 내가 고른다** | 남음 | story.js (개인 사건과 파티 사건이 섞여 있어 구분 필요) |
| 시험 게이트(임시 리더) | 해당 없음 | 길·사건 모두 리더가 정하고 이동 | 됨 (v0.344) | council_exam.js |

## 파티원이 하는 행동 (플레이어·NPC 공통)

| 행동 | NPC 파티원 | 플레이어가 파티원일 때 |
|---|---|---|
| 의견 내기 | councilOpinion (O/X 한마디) | 팀 상의 창의 [따른다]/[반대한다]. 가만히 있으면 따른다(5초) |
| 다른 길·다른 선택 제안 | 반대 표가 많으면 리더가 바꾸기도 한다 | 반대하면 리더 성격·관계에 따라 받아 주거나 밀어붙인다 |
| 막아서기 | gate_watch.js showBlock | 해당 없음(리더에게 반대 의견으로 대신) |
| 오더 따르기·무시 | orders.js obeys | 리더 오더는 안내로 뜨고, 내 행동은 내가 정한다 |
| 자기 전투 행동 | 전투 AI | 직접 조작 |
| 개인 물건 쓰기 | AI | 직접 |
| 파티 나가기 | council_quit 등 | 파티 화면에서 탈퇴 |

## 팀 거점과 합류 기한 (v0.355, js/crew_time.js · 사용자 확정)

사용자 요청: "파티원일 때 리더가 일을 계속 주는 형식으로. 기다리지 말고, 거점 도시에서 리더에게 말하면 리더가 바로 출발. 리더가 다 같이 이동하고 목표를 향해 알아서 움직임. 리더의 이동수단 적용. 튜토 끝나자마자 파티 소속이면 리더가 '언제까지 모여라' 연락. 기한 넘기면 불이익."

| 항목 | 규칙 | 코드 |
|---|---|---|
| 팀 거점 | 들어갈 때 있던 도시(리더가 머무는 도시). `crew.base` | crewJoin 감싸기 |
| 첫 연락 | 들어가자마자 리더가 "○일까지 ○○로 와라"(이동 거리에 맞춰 최소 5일). 튜토리얼 직후 첫 팀도 같다 | crewSetDue(true) · crewCall |
| 개인 시간 | 평소 `G.party()`에 팀원이 없다. 혼자 수련·휴식·개인 의뢰·솔로 게이트. 팀원 명단은 `G.crewMembers()`, 전원이 필요한 처리는 `G.withCrew()` | `crew.on` |
| 합류 | 퀘스트 목록 맨 위 "○○에서 리더와 합류 · ○일까지". 거점이 아니면 누르면 그쪽으로 이동, 거점이면 리더와 대화 | crew-talk |
| 일하러 간다 | 리더가 일을 고른다(게이트·토벌·호위·훈련, 편도 8일 넘는 일은 거점 근처 게이트로 바꿈). 팀원은 알아서 모이고 바로 출발. 기다리는 날짜 없음 | crewWork |
| 이동 | 지도 위에서 리더가 팀을 이끌고 목표까지 걷는다(경로는 리더, 지도를 눌러도 방향을 바꿀 수 없음). 이동수단은 리더 것: C급 이상 고속 이동망(역→역 2일, 그다음 걸어서), E·D급 파티 장갑차(하루에 두 배, 괴수 기습 없음), 그 아래 도보. 비용은 팀 경비. 길 사건·폐허·기습이 생기면 멈추고 리더가 결정한 뒤(나는 [따른다]/[반대한다]) 이어서 간다. 지나는 도시·게이트에서는 멈추지 않는다 | crewMarchStep · crewArrive |
| 일이 끝나면 | 거점으로 함께 돌아가 개인 시간. 다음 기한 7~12일(리더십 40 미만은 4~7일). 그 전에 와서 말 걸면 바로 다음 일 | crewJobDone |
| 기한을 넘기면 | 신뢰 −15, 리더 관계 −8, 팀원 −3, 명성 −2. 세 번이면 제명. 리더십 30 미만 리더는 35% 확률로 날짜를 헷갈림 → 불이익 없음 | crewMissDue |
| 게이트 제안 | 리더와 대화할 때 거점 근처 게이트(최대 3곳)에 [가자고 제안]. 게이트마다 한 번, 거절되면 다음 달까지(등급·관계 +10 이상이면 다시). 수락되면 그 게이트로 바로 출발 | crewProposeGate |
| 지도에서 게이트 | 개인 시간에는 [혼자 들어간다]만. 팀 제안은 거점에서 | leadGateAsk |
| 리더 교대 | 내가 리더보다 두 등급 높으면 말을 걸 때 리더 교대 제안 | crewTalk |

### 대칭: 내가 리더일 때 (v0.358)
| 항목 | 규칙 |
|---|---|
| 자유 시간 | 도시에서 파티 화면 [자유 시간을 준다] → 팀원은 그 도시(내 거점)에 남고 나는 혼자 움직인다. 기한 7일 |
| 소집 | 퀘스트 맨 위 "○○에서 팀 소집" → 거점에서 [팀을 모은다]면 다시 함께 |
| 팀원이 늦으면 | 기한이 지난 뒤 모을 때 팀원마다 지각 판정(기본 6%, 관계 20 미만 +12%, 게으른 성격 +15%). 늦은 팀원: 관계 −3, 명성 −2, 어긴 횟수 +1, 세 번이면 내보냄 |

없앤 것(v0.354): 월 일정 공지·집결일 대기·[집결일까지 보내기]·[일 좀 잡아 달라]·두 번째 일정 예고. 옛 저장의 집결 약속은 그대로 처리된다.
