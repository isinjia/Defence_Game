# 리더와 파티원의 역할 점검표 (영역 D)

원칙(사용자 결정): **내가 리더일 때 하는 행동은, NPC가 리더일 때 NPC가 똑같이 한다.** 그 입력을 플레이어에게 넘기지 않는다.
플레이어가 파티원이면 NPC 파티원이 하는 행동(의견·따르기·자기 전투·개인 물건·파티 나가기)만 할 수 있다. 화면 배치는 두 경우가 같다.

## 리더가 하는 행동

| 행동 | 내가 리더 | NPC가 리더 | 상태 | 코드 |
|---|---|---|---|---|
| 일정·목적지 정하기 | 지도에서 직접 고른다 | 리더가 이번 달 일정을 잡는다. 나는 참가·불참만 답한다 | 됨 | crew.js crewPlan |
| 월드맵 이동 | 직접 이동 | "리더와 같이 이동"이면 자동 이동. "집결지에서 만난다"는 내가 고른 개인 이동(늦으면 불이익) | 됨 | crew.js answerCrewPlan · leader_rule.js RALLY |
| 게이트 입장 | 게이트를 누른다 | 일정대로 리더가 입장. 게이트를 누르면 "제안"만 된다 | 됨 | leader_rule.js leadGateAsk |
| 층 지도 길 선택·이동 | 칸을 누른다 → 팀 상의 | 리더가 고른다 → 팀 상의 → 자동 이동. 길이 하나면 리더가 앞장선다 | 됨 (v0.344) | council.js · leader_rule.js |
| 사건 선택지 결정 | 직접 고른다 | 리더가 고른다. 나는 따르거나 반대 | 됨 (게이트·탐색 사건) | leader_rule.js leaderGate |
| 판정 담당자 지정 | 직접 고른다 | 리더가 맡길 사람을 고른다 | 됨 | check.js checkLeaderPick |
| 전투 오더 | 동료를 눌러 오더 | 리더만 오더를 낸다. 나는 낼 수 없다 | 됨 | orders.js |
| 철수·도주 결정 | 철수 버튼 | 리더가 정한다. 내 버튼은 "철수 제안"(층·전투마다 한 번). 내가 크게 다치면 리더가 먼저 철수를 정하기도 한다 | 됨 (이번) | leader_rule.js |
| 분배 | 계약대로 자동 | 계약대로 자동 | 입력 없음 | payroll.js · first_team.js share |
| 이동 중 이야기 사건 | 직접 고른다 | **아직 내가 고른다** | 남음 | story.js (개인 사건과 파티 사건이 섞여 있어 구분 필요) |
| 시험 게이트(임시 리더) | 해당 없음 | 길·사건 모두 리더가 정하고 이동 | 됨 (v0.344) | council_exam.js |

## 파티원이 하는 행동 (플레이어·NPC 공통)

| 행동 | NPC 파티원 | 플레이어가 파티원일 때 |
|---|---|---|
| 의견 내기 | councilOpinion (O/X 한마디) | 팀 상의 창의 [따른다]/[반대한다]. 가만히 있으면 따른다(5초) |
| 다른 길·다른 선택 제안 | 반대 표가 많으면 리더가 바꾸기도 한다 | 반대하면 리더 성격·관계에 따라 받아 주거나 밀어붙인다 |
| 막아서기 | gate_watch.js showBlock | 해당 없음(리더에게 반대 의견으로 대신) |
| 오더 따르기·무시 | orders.js obeys | 리더 오더는 안내로 뜨고, 내 행동은 내가 정한다 |
| 자기 전투 행동 | 전투 AI | 직접 조작 |
| 개인 물건 쓰기 | AI | 직접 |
| 파티 나가기 | council_quit 등 | 파티 화면에서 탈퇴 |

## 팀 일정과 개인 시간 (v0.352, js/crew_time.js)

사용자 불만: "내가 팀원인데 내가 움직이면 파티원이 다 같이 움직이고, 게이트 진입도 들어갔다 나갔다 하면서 설득을 계속하면 확률로 승인되고, 팀장이 언제 일 줄지 모르니까 답답함."

| 항목 | 규칙 | 코드 |
|---|---|---|
| 개인 시간 | NPC 리더 파티의 팀원이면 평소 `G.party()`에 팀원이 없다(지도에서 혼자 움직인다). 수련·휴식·개인 의뢰·솔로 게이트만 가능. 팀원 명단은 `G.crewMembers()`, 달마다 도는 처리는 `G.withCrew()`로 전원을 본다 | `crew.on`(팀 일정 중이면 true) |
| 팀이 모이는 때 | 집결일(`rallyGo`), 호위·합동 훈련 수락, 게이트 제안 수락. 일정이 끝나고 내가 다시 움직이면 흩어진다 | crewDayTick |
| 일정 수락 | 게이트·토벌은 수락하면 집결 약속이 된다. 집결일 전에는 같은 지역에 있어도 모이지 않는다 | answerCrewPlan · rallyCheck |
| 집결일까지 보내기 | 퀘스트 목록 버튼. 하루씩 넘기며 수련(에테르 = 한 달 수련의 일수 비율 × 0.8), 다쳤으면 휴식. 사건이 생기면 멈춘다. 집결일이 되면 집결지로 가서 팀과 들어간다 | crewSkipToRally |
| 게이트 제안 | 게이트마다 한 번. 거절 이유: 등급 높음 → 일정 참 → 내 부상 → 방침(관계에 따른 확률). 결과를 게이트 id·달·내 등급·관계로 저장. 다음 달, 내 등급 상승, 관계 +10 이상이면 다시 제안 가능. 수락된 게이트도 같은 달엔 다시 제안 불가 | crewProposeGate · crew.asked |
| 솔로 게이트 | 지도에서 게이트를 누르면 [혼자 들어간다] / [팀으로 가자고 제안] 중 고른다. 솔로 입장은 기존 입장 규칙(4-17) 그대로 | leadGateAsk · gate-solo |
| 일정 미리 보기 | 리더가 한 달에 두 번 일을 잡으면(50%) 두 번째는 "팀 예정 · ○일"로 미리 보이고, 첫 일정이 끝나면 답하게 된다 | crewSecondPlan · crew.next |
| 일 요청 | 잡힌 일정이 없으면 한 달에 한 번 "일 좀 잡아 달라" → 2~4일 안에 일정이 온다 | crew-askwork |
| 늦은 공지 | 리더십 50 미만 35%, 30 미만 60% 확률로 공지가 4~9일 늦는다. 날짜를 헷갈린 일정(plan.mixed)은 지각 불이익 없음(기존 규칙) | crewMonthly |
