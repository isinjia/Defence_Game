# 메인 「원초의 문」 컷신 이미지 목록 (제작 명세)

> **현재 화풍 기준:** [그림 톤·컨셉트·선화·명암 기준](비주얼_스타일_기준.md). 2026-11-12 승인한 전체 55컷 보정본을 따르며, 기존 반실사 표현보다 이 기준과 최신 사용자 수정 사항을 우선한다.

> **연결 완료 (v0.61):** 55장 모두 게임에 붙였다. 서술 줄의 `art: 'cut-…'` → `js/main_cut_art.js`가 대화창 뒤에 띄우고 그 장면이 끝나면 내린다. 엔딩 5종은 엔딩 화면 머리 그림. 같은 줄에 있던 인물 전신 삽화 5곳(9장 한서윤, 14장 진서해, 20장 아린, 37장 아린·젊은 진서해)은 컷신으로 바꿨고 37장 젊은 마도현 삽화는 뺐다(컷신에 함께 나옴). `cut-07-sea`는 7장과 20장 꿈 첫 줄에 쓴다.

> 영역 D 작성. 메인 시나리오(`js/main_part1~6.js`, `js/main_ending.js`)를 진행할 때 띄울 **장면 그림(컷신)** 목록과, 각 그림이 어떤 그림이어야 하는지 적은 문서다.
> 인물 생김새·의상은 `docs/메인_인물_외형.md`를, 이미 있는 인물 그림은 `assets/portraits/main/`(전신)·`bust/`(상반신)를 따른다.
> **적용 순서(사용자 결정):** 그림을 만들면 코드에 붙이기 전에 미리보기를 사용자에게 보여 주고 확인을 받는다(`CLAUDE.md`, 공통 규칙 11).

## 0. 공통 규격

| 항목 | 기준 |
|---|---|
| 크기 | **1536×1024**(3:2) 원본, 배포는 WebP. 프롤로그 삽화(`assets/prologue/`)와 같은 규격 |
| 안전 영역 | 모바일 대화창 위에서는 가운데를 잘라 보여 준다. **핵심 피사체는 가운데 가로 60%·세로 70% 안에** 둔다 |
| 글자 | 그림 안에 글자를 넣지 않는다(간판·화면·전단은 형태만, 읽히는 글자 없음). 화면 글자는 한글만이라는 규칙 때문이다 |
| 화풍 | 기존 캐릭터 원화에 맞춘 **가는 선화·부드럽고 절제된 명암의 한국 웹툰풍**. 인물과 배경 전체를 같은 방식으로 표현하고 장면별 강조색을 유지한다. 세부 기준은 `비주얼_스타일_기준.md` |
| 인물 | 장면 그림에서는 인물을 **작게·뒷모습·실루엣·옆모습** 위주로 둔다. 얼굴 정면 클로즈업은 인물 초상(`portraits/main`)이 맡는다. 고정 인물이 크게 나오면 외형 문서와 기존 전신 그림을 그대로 따른다 |
| 주인공 | 판마다 외형이 다르므로 **얼굴을 그리지 않는다**(뒷모습·손·그림자만) |
| 라이벌·리더·친구 | 판마다 다른 실제 NPC라 **얼굴 없이** 실루엣·소품으로만 표현한다 |
| 파일 위치·키 | `assets/main_cut/<키>.webp`, 키는 `cut-<장>-<이름>`(예: `cut-04-halfgate`). 갈래가 있으면 `-<갈래>` 접미사 |
| 연결 | 메인 대사 줄의 `art` 키로 띄운다(엔진은 v0.534부터 `art`를 대화 줄에 넘긴다). 서술 줄의 `art`면 대화창 위 삽화. B의 `js/main_cast_art.js`가 `cut-` 키를 `assets/main_cut/`에서 읽도록 확장하면 된다 |

우선순위: **★ 필수**(장의 정점·전환점, 먼저 만든다) · **☆ 있으면 좋음**.

## 2. 연결 방법 (코드)

- D: 위 표의 「장·장면」 서술 줄에 `art: 'cut-…'`를 단다(그림이 생긴 것만). 갈래 그림은 `art: (g, M) => …` 함수로 고른다.
- B: `js/main_cast_art.js`에서 `cut-` 키를 `assets/main_cut/<키>.webp`로 읽어 대화창 위 삽화로 띄운다(지금은 인물 키만 읽는다). 엔딩 화면은 `M.ending`으로 `cut-end-*`를 고른다.
- 그림을 만들면 붙이기 전에 사용자 확인(미리보기) → 확인된 것만 `art`를 단다.
