# 월드맵 내 위치 복귀

2026-11-13 사용자 요청: 내 캐릭터가 화면 밖에 있으면 화면 중앙에 ‘원점으로’를 표시하고, 화살표로 캐릭터 방향을 가리킨다.

- 캐릭터 표식이 월드맵 화면에서 완전히 벗어났을 때 중앙 원형 버튼을 표시한다. 일부라도 보이거나 다시 화면 안으로 들어오면 숨긴다.
- 버튼 바깥 화살표는 현재 화면 중심에서 캐릭터가 있는 방향으로 회전한다. 카메라 이동·확대/축소·화면 크기 변경에 반응한다.
- 왼쪽 캐릭터 초상을 누르면 캐릭터 정보 창이 열린다(사용자 요청). 상태 막대는 카드 접기·펼치기 동작을 유지한다.
- 버튼을 누르면 카메라만 캐릭터 위치로 복귀한다. 이동 중에는 현재 애니메이션 표식 위치를 사용한다. 캐릭터 좌표·날짜·체력·돈을 바꾸거나 목적지로 이동시키지 않는다.
- 모달·대화·전투 화면에서는 숨긴다. 키보드로도 누를 수 있고, 접근성 이름에 캐릭터 방향을 포함한다.
- `js/map_origin.js`, `css/map_origin.css`에서 기존 지도 그리기·종료와 UI 행동을 감싸 적용한다. 지도 종료 시 버튼도 제거한다.

`node tools/map_origin_test.js`: PC 1440px, 모바일 390px·320px에서 8방향, 중앙 배치, 실제 클릭·Enter, 화면 경계·줌, 이동 중 표식, 모달 숨김, 카메라 복귀 시 게임 상태 불변, 중복·종료 처리를 검사한다. 전용 검사 모두 통과, 페이지 오류 0건.

`ORIGIN_TEST_URL`로 배포 사이트를 검사하고, `ORIGIN_SCREENSHOTS`로 캡처 저장 위치를 지정한다.
