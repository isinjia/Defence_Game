## 추가 얼굴·헤어 적용 (v2.89)

추가 파츠 미리보기 후 사용자가 푸시를 요청하여 얼굴 남녀 각17종, 헤어 남녀 각17종을 게임 조합에 연결한다. 기존 것을 합쳐 남녀 얼굴 각각25종, 남성 헤어25종·여성 헤어20종이며 기본 복장 각3종·체형 보통1종을 유지한다. 추가102파일은 `assets/portraits/player-modular-extra/`의 얼굴34개와 앞·뒤 헤어68개이다. 파일 출처·등록 좌표는 manifest에 기록한다.

모든 신규 얼굴은 각 성별 공통 원본 등록에 맞추며, 머리와 복장을 바꾸어도 얼굴 등록은 동일하다. 여성 긴 생머리와 남성 묶음머리는 앞머리에서 뒤쪽 긴 모발을 제거해 이중으로 겹치지 않게 했다. 배경 알파 잔상과 귀 아래 떨어진 모발 조각을 정리했다. 목·어깨 위치 재조정 후보는 이 변경에 포함하지 않는다. NPC 렌더러는 기존 함수로 위임한다.

전용 조합 검사: 기본·직업복45,000조합에서 명시한 얼굴/헤어 선택, 고정 등록, 기본3,375조합 추첨 도달, 직업 별칭, 피부 필터와 NPC 위임, 모든 원본 파일 존재를 검사한다. 이 검사는 모든 조합의 미적·해부학적 적합성을 자동 보장하지 않는다. 스모크와 밸런스 시뮬레이션은 실행하지 않는다.

## 이전 적용: 독립 파츠 조합 (v2.88)

사용자가 완성 이미지 사용을 바로잡고 파츠 조합 미리보기 후 적용·푸시를 요청했다. `js/player_modular_art.js`가 기존 외형 모듈 다음에 주인공 큰 초상·아바타를 처리한다. 신규 얼굴 남녀 각5종을 얼굴+목 파츠로 분리했으며 기존3종을 합쳐 성별마다 얼굴8종이다. 남성 헤어8종·여성 헤어3종·기본 복장 각3종을 독립 선택한다. 체형은 보통1종이다.

새 파츠22개는 `assets/portraits/player-modular/`의 무손실 WebP이다. 여성은 앞머리·뒷머리를 별도 레이어로 그린다. 얼굴과 목은 연결된 한 파츠이며 각 원본의 고정 등비 배율·좌표만 사용한다. 복장·직업에 따른 얼굴 이동이나 턱·목 절단 마스크는 없다. 피부색 필터는 얼굴·목에만 적용한다.

직업복은 기존 의상 전용 `assets/portraits/outfits/`의 남녀 각37종을 재사용한다. 직업복을 바꿔도 선택된 얼굴·헤어가 유지된다. NPC 렌더러와 저장된 외형 시드는 유지한다. 예전 완성 초상 파일은 보관하며 새 주인공 표시에는 사용하지 않는다.

검증: `node tools/player_modular_art_test.js`로 기본/직업복3,520조합의 얼굴·헤어 고정, 기본264조합 추첨 도달, 직업 별칭, 피부 필터 범위와 NPC 위임을 검사한다. 남녀 조합·모든 얼굴·직업복 목선 미리보기를 검토했다. 스모크와 밸런스 시뮬레이션은 실행하지 않는다.

2026-11-22 사용자가 더 주인공스럽고 예쁜 남녀 얼굴 각5종을 요청하고, 10종 비교 미리보기 후 푸시를 요청했다.

- 승인된 정면 얼굴 원본10종을 `assets/portraits/player-hero/face-{m,f}-01..05.webp`에 무손실 보관한다.
