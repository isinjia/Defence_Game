사용자가 완성 이미지 사용을 바로잡고 파츠 조합 미리보기 후 적용·푸시를 요청했다. `js/player_modular_art.js`가 기존 외형 모듈 다음에 주인공 큰 초상·아바타를 처리한다. 신규 얼굴 남녀 각5종을 얼굴+목 파츠로 분리했으며 기존3종을 합쳐 성별마다 얼굴8종이다. 남성 헤어8종·여성 헤어3종·기본 복장 각3종을 독립 선택한다. 체형은 보통1종이다.

새 파츠22개는 `assets/portraits/player-modular/`의 무손실 WebP이다. 여성은 앞머리·뒷머리를 별도 레이어로 그린다. 얼굴과 목은 연결된 한 파츠이며 각 원본의 고정 등비 배율·좌표만 사용한다. 복장·직업에 따른 얼굴 이동이나 턱·목 절단 마스크는 없다. 피부색 필터는 얼굴·목에만 적용한다.

직업복은 기존 의상 전용 `assets/portraits/outfits/`의 남녀 각37종을 재사용한다. 직업복을 바꿔도 선택된 얼굴·헤어가 유지된다. NPC 렌더러와 저장된 외형 시드는 유지한다. 예전 완성 초상 파일은 보관하며 새 주인공 표시에는 사용하지 않는다.

## 이전 완성 초상 적용 기록 (2026-11-22)

2026-11-22 사용자가 더 주인공스럽고 예쁜 남녀 얼굴 각5종을 요청하고, 10종 비교 미리보기 후 푸시를 요청했다.

- 승인된 정면 얼굴 원본10종을 `assets/portraits/player-hero/face-{m,f}-01..05.webp`에 무손실 보관한다.
- 기존 몸·옷에 연결한 완성 초상10종은 `portrait-{m,f}-01..05.webp`이다. 머리·턱·목을 코드로 잘라 합성하거나 개별 비율을 변형하지 않는다. 파츠로 분리하는 대신 얼굴 시안을 몸 기준 원화에 연결해 재제작했으므로 작은 주름/포즈/선 차이가 있으며 원본 얼굴과 픽셀 단위로 같은 합성은 아니다.
- `js/player_hero_faces.js`: 남녀 주인공·생성 중인 주인공에만 적용. 시드/성별 해시로 새 완성형5종 또는 기존 외형을 고른다(각50%). 같은 저장 시드는 같은 결과를 유지하고 외형 바꾸기는 기존처럼 새 시드를 받는다. NPC는 기존 렌더러에 위임한다.
