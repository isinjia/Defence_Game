# 여성 주인공 기본 외형

## 현재 적용: 독립 파츠 조합 (2026-11-23)

사용자 요청에 따라 완성 초상 선택을 파츠 조합으로 교체했다. `js/player_modular_art.js`가 기존 모듈 다음에 여성 주인공·생성 상태만 처리한다. 기존 얼굴3종과 새 얼굴5종, 헤어3종, 기본 복장3종을 독립적으로 고른다. 체형은 보통1종이다. 저장된 외형 시드는 지우지 않는다.

`assets/portraits/player-modular/`에 여성 얼굴+목8개, 앞머리3개, 뒷머리3개, 복장3개를 둔다. 뒷머리 → 의상 안감 → 얼굴·목 → 의상 앞면 → 앞머리 순서로 표시해 귀 옆 구멍과 목 둘레를 맞춘다. 복장이 달라져도 얼굴·헤어의 고정 배율과 위치는 변하지 않는다. 전투복 사선 끈과 주머니 위 배치를 유지한다.

직업복은 완성 초상37장 대신 기존 의상 전용 `assets/portraits/outfits/outfit-f-*.webp`37벌과 앞깃 윤곽을 사용한다. 최근 완성 초상의 옷을 추출한 것은 아니므로 옷 세부 선화에는 차이가 있다. 직업복에서도 선택된 얼굴·헤어를 그대로 유지하며 NPC는 기존 경로로 위임한다.

미리보기 후 사용자가 푸시를 요청해 적용했다. 이전 완성 초상은 보관용이며 아래 내용은 제작 당시의 기록이다. 현재 경로와 검사 내용은 `docs/주인공_신규_얼굴_10종.md`를 따른다.

## 이전 완성 초상 제작·적용 기록

2026-11-21 승인한 단발·전투복·보통 체형의 완성 초상 1종을 기본 외형으로 적용하고 푸시·배포한다.

- `assets/portraits/player-female/default-01.webp`: 승인 PNG를 픽셀 수정 없이 투명 무손실 WebP로 변환.
- `js/player_female_art.js`: 여성 주인공·여성 생성 상태의 시드만 새 원화로 연결한다. NPC·남성은 기존 렌더러에 위임한다.
- 큰 초상과 아바타, 기존 버스트·지도 래스터·이미지 준비 경로를 함께 사용한다. 얼굴·목·헤어·복장에 별도 배율·이동·색 필터를 추가하지 않는다.
- 현재 외형은 1종이며 외형 재추첨·직업·장비·나이·체형·피부색에 따라 달라지지 않는다. 생성 화면은 기본 외형으로 표시하고 적용되지 않는 체형·피부색 선택은 표시하지 않는다. 저장된 해당 값은 지우지 않는다.
- 실제 생성 참조: 한서윤 정장, 젊은 진서해, 급식 천막, 승인 남성 외형 비교. 목과 옷깃 연결 및 390×844·320×900 미리보기를 확인했다.
- 스모크 테스트·밸런스 시뮬레이션은 실행하지 않는다.

사선 끈이 왼쪽 허리에서 끊기는 문제를 고친 수정본을 적용한다. 끈이 재킷 위를 가로질러 왼팔 뒤로 이어진다.

## 추가 외형 6종 (2026-11-21)

기존1종에 얼굴 변경2종·헤어 변경2종·복장 변경2종을 더한 총7개의 승인 완성 초상을 적용한다. 외형 시드별로 고정 추첨하고 외형 바꾸기에서 새 시드를 받는다. 저장 시드는 유지하므로 재접속해도 같은 그림이다.

현재는 각 항목만 바꿔 제작한 완성 이미지7종이다. 얼굴3×헤어3×복장3의 독립27조합 시스템은 아니다. 얼굴·목을 잘라 재합성하거나 코드로 비율을 바꾸지 않고 승인된 초상을 그대로 표시한다. NPC·남성 경로는 유지한다.

추가: 차분한 얼굴, 부드러운 얼굴, 낮은 포니테일, 긴 생머리, 올리브 재킷, 남색 롱코트. 원본 PNG와 생성 참조는 에셋 manifest에 기록한다.

## 여성 직업복 37종 (2026-11-22)

사용자가 전체 시안과 기본 얼굴·단발 기준임을 확인하고 적용을 승인했다. `assets/portraits/player-female/jobs/job-*.webp`에 완성 초상37종을 두고, `HunterOutfits.get(opts.outfit,'F').familyId`로 기존37계열·확장23직업을 연결한다. 이 경로는 여성 주인공·생성 중인 여성에만 적용한다. NPC와 남성은 기존 경로를 유지한다.

직업복을 입으면 현재 승인한 기본 얼굴·단발이 표시된다. 추가 얼굴·헤어와 직업복의 독립 교차 조합은 아직 없다. 의상을 따로 분리해 목을 다시 합성하거나 얼굴·몸 배율을 바꾸지 않는다. `hunter:` 복장이 없는 생성·일반 복장에서는 기존 여성 외형7종을 유지한다. 명시적인 일반 복장 장비도 기존 경로를 따른다.

각 이미지의 옛 여성용 직업복 원본, 생성 참조와 시안별 출처는 jobs/manifest.json에 기록했다. 원본37벌·결과37벌·목둘레 확대를 검토했고 투명 RGBA PNG를 픽셀 수정 없이 무손실 WebP로 변환했다. 스모크 테스트와 밸런스 시뮬레이션은 실행하지 않았다. 푸시·배포는 별도 승인 대상이다.
