# 구현 대기 목록 (작업 분담표)

> 조사 세션이 낸 제안 중 **사용자가 구현하기로 결정한 것**을 한곳에 모았다. 여러 세션이 나눠서 구현한다.
> 근거 문서는 모두 `docs/` 안에 있다. 각 항목의 자세한 설계는 괄호 속 문서를 읽는다.
> 작성 기준: `claude/happy-turing-czlfa3` v0.26.

## 0. 모든 세션 공통 규칙

1. **브랜치**: 모두 `claude/happy-turing-czlfa3`에 올린다(GitHub Pages가 이 브랜치를 배포한다).
2. **올리기 직전에** `git pull --rebase origin claude/happy-turing-czlfa3`. 충돌이 나면:
   - `dist/game.js`, `dist/style.css`, `index.html`, `js/data.js`의 버전 줄은 상대 것을 받고 → `bash tools/build.sh` → `python3 tools/bump_version.py`로 다시 만든다.
   - `tools/build.sh`의 파일 목록은 양쪽 파일을 모두 남긴다.
   - 남의 기능 코드는 지우거나 되돌리지 않는다. 겹치면 둘 다 살리는 쪽으로 합친다.
3. **새 시스템은 새 파일로**: 가능하면 `js/` 아래 새 파일을 만들고 `tools/build.sh`의 `SRC` 목록에 추가한다. 기존 함수는 `Game.prototype`/`UI` 감싸기(wrap)로 확장한다(`js/hunter.js`, `js/crew.js`, `js/situation.js`가 이 방식). 공용 큰 함수를 통째로 다시 쓰지 않는다.
4. **작게, 자주**: 항목 하나(또는 작은 묶음)마다 빌드 → 확인 → 버전 올림 → 커밋 → 푸시. 커밋 제목은 `vX.YY: [영역] 내용`.
5. **확인**: 푸시 직전 `bash tools/build.sh && node tools/smoke_test.js`(연기 시험, 실패 시 종료 코드 1). 새 화면·흐름을 만들었으면 smoke_test.js에 단계를 더한다. 남의 기능이 실패하면 고치지 말고 보고에 적는다(`docs/병렬_개발_품질.md`). 밸런스에 닿는 변경은 `node tools/balance_sim.js 4 70`으로 전후 비교.
6. **옛 저장 호환**: 새 필드는 불러올 때 `??=`로 채운다(`initSandbox` 감싸기).
7. **모바일 우선**: 화면 추가는 좁은 화면(320px)과 동작 줄이기 설정에서 확인한다(`docs/모바일_조작_점검.md`).
8. **사용자 결정 존중**: 아래 "넣지 않음" 항목은 만들지 않는다.

## 1. 작업 영역과 담당

| 영역 | 담당 | 주로 만지는 파일 |
|---|---|---|
| A. 전투·괴수 | 기존 구현 세션("한국 SF 헌터물 창작") | `combat.js`, `data.js`의 `MONSTERS`, `ui.js` 전투 부분 |
| B. 화면·연출·소리 | 새 세션 | `fx.js`, `css/style.css`, 새 `sfx.js`, `ui.js`의 HUD·시트·모달 |
| C. 세계·NPC 시뮬레이션·밸런스 | 새 세션 | `game.js`의 `simulateNpcs`·`spawnMonthly`, `society.js`, 새 `npc_ai.js` |
| D. 이야기·관계·첫 해 | 새 세션 | `story*.js`, `debut.js`, `tutorial.js`, `prologue.js`, `ui_prologue.js` |
| E. 성장·경제·아이템 | 새 세션 | `hunter.js`, `society.js`의 시설·제작·상점, `data.js`의 장비·소모품, 새 파일 |
| F. 지도·탐험 | 새 세션 | `world.js`, `mapview.js`, 새 `explore.js` |

영역끼리 겹치는 곳(예: 전투 화면 배치는 A와 B, 게이트 결과 처리는 A·C·E)은 **먼저 올린 쪽을 받고 그 위에 얹는다.**

## 3. 넣지 않음 / 나중에

- **넣지 않음**: 테이밍, 헌터 아카데미, 해외 원정, 스탯 포인트 분배 (`헌터물_제안2.md` 후순위 결정).
- **보류**: 일본·중국 지도 확장(한반도·북부를 채운 뒤 결정, `지도_탐험_제안.md` 5).
- **게임 완성 뒤**: 저장 내보내기·가져오기, 저장 실패 알림·백업, 홈 화면 앱, 저장 형식 버전 (`저장_소리_점검.md`).
- **4차 제안 결정**: 공무원 경로·괴수 도감·가게 경영·광고·예능만 구현(위 각 영역에 배정). **폐기**: 규칙 괴담 게이트, 자녀 교육, 시청자 미션, 대붕괴 생존 모드.
