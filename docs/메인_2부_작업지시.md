## 2. 1부 수정 (작게, 전량 리라이트 금지)

### 2-1. 필수: `pause` 문구와 대기 일수 맞추기

지금: 토스트/서술은 「다음 목요일」「보름까지 열흘」인데, 엔진은 `pendingDay = mainToday() + 1`(다음날)만 기다린다. 퀘스트도 「내일 이어짐」.

**고칠 것**

- `main_story.js`: 장면 `pause`가 숫자·객체일 수 있게.
  - 예: `pause: 1` / `pause: { days: 7 }` / `pause: '문자열'`(문자열만 있으면 기본 1일 + 그 문구)
  - 또는 `pauseDays` 필드를 두고 문구는 `pause` 문자열 유지
- `main_part1.js`에서 의미에 맞게 일수 지정:
  - 1장 점심 뒤: 1일 (지금과 동일, 문구 「오늘은 여기까지…」)
  - 2장 연희 대화 뒤·3장 미룸: **다음 목요일까지** → 대략 7일(또는 요일 계산이 있으면 그걸 사용). 문구와 퀘스트 표시를 「목요일에 이어짐」등으로 일치
  - 4장 보름 전: **약 10일**. 문구 「보름 밤까지」와 퀘스트 표시 일치
- 퀘스트 HUD: 무조건 「내일」이 아니라 남은 대기에 맞는 짧은 말(「N일 뒤」「목요일」).

### 2-2. 권장(작으면 같이, 크면 ② 이후)

- 문서 §10의 장면 수 표기(2:9·3:10·4:13)와 실구현이 조금 어긋남 → **문서 숫자를 실측에 맞추거나**, 이동/잔향 장면 1~2개만 보강. 기존 명장면(아이·연희·무명 연설)은 건드리지 말 것.
- 6~8장이 의도적으로 짧음은 유지 가능. 여운 한 줄 추가 정도는 OK.

### 2-3. 하지 말 것

- 1~8장 전체 다시 쓰기
- 엔딩 5종·감춰진 진실 전제 변경
- 방송·함께하기·테이밍 등 「넣지 않음」

## 3. 2부 「보름의 의식」집필 (9~14장)

### 3-1. 파일

- 새 파일 `js/main_part2.js` — 장면 데이터만 (`MAIN.ch(9…14, …)`).
- `tools/build.sh`의 `SRC`에 `js/main_part1.js` **다음**에 `js/main_part2.js` 추가.
- 엔진 확장은 `main_story.js`에만(필요 최소). `combat.js` 등 타 영역 핵심 로직 직접 수정 금지. 재앙·voice 연동은 기존 API 감싸기.

### 3-2. 설계표 (반드시 이 골격)

`docs/메인_시나리오.md` §3 2부:

| 장 | 제목 | 조건·무대 | 핵심 |
|---|---|---|---|
| 9 | 감시자 | D급 · 거주 도시 | 한서윤. "당신, 꿈을 꾸죠?" → 협조 / 거절 / 역캐묻기 |
| 10 | 친구의 선택 | 9장 뒤 · 친구의 도시 | 비각성 친구의 균열교. 설득 / 동행 / 강제 (관계·생사) |
| 11 | 대전 기록 보관소 | D 중기 · 대전 | 공명 실험·진서해 이름 (voice 1 흡수). 복사 / 정식 / 서윤에게 |
| 12 | 둥지 | 재앙 「강북 지하철 둥지」 | ★ 재앙 보스·calamity 연결. 직접 / 다른 팀 먼저 |
| 13 | 피의 보름 | D 후기 | 동시다발 의식, 친구 위치는 10장 결과. 구한다 / 늦는다 |
| 14 | 가면을 벗다 | 13장 뒤 | 무명=진서해 영상. 듣는다 / 끊는다 |

문체: 1부와 동일(짧은 현재형 서술 + 구어). 화면 글자 **한글만**.

### 3-3. 1부 후과를 2부에서 소비 (필수)

1부 플래그가 9장부터 **대사·분기·관계**로 돌아와야 한다. 최소:

| 1부 플래그 | 2부에서 |
|---|---|
| `dream` record·search·ignore / `dreamDebt` | 9장 서윤 첫 마디·증거 유무. ignore면 꿈이 더 선명해지며 서윤이 늦게 오거나 다른 단서 |
| `c4` stop·raid·join·save·missed | 9장 서윤의 태도(감시 강도), 12장 둥지 잔해 설명, 14장 무명의 호칭 |
| `cultist` / `badge7` / `kamaWatch` | join·raid 루트 전용 대사·선택 잠금/해금 |
| `rivalPath` kama·cult·solo·alone | 11·14장 라이벌 등장 여부·대사. 없으면 alt |
| `doyun` / `yeonhee` / `kwon`·하은 | 10·13장에 얼굴 있는 한 줄(사망·실종이면 빈자리) |
| `c1_friend`·`c1_call`·`friendNear` | 10장 설득 난이도·관계 시작점 |
| `part1` (`M.part1`, 8장 done) | 있으면 요약용으로 읽기 |

새 2부 플래그도 **같은 장 또는 다음 장 첫 줄**에 반드시 소비. 플래그만 쌓고 끝내지 말 것. `rel` / `changeRel` / `lifeEvent` / `rumor` 중 하나 이상.

### 3-4. 장별 출구가 다음 장 첫 줄을 가를 것

1부 4→5장처럼, 특히:

- **9장** 협조/거절/역캐묻기 → 10·11장 서윤 동행 여부·정보량
- **10장** 설득/동행/강제 → **13장** 친구 위치·생사·관계 크게. 세계 시계 만료 시 친구가 의식에 휘말린 결과 명시
- **11장** 복사/정식/서윤 → 14장·3부에서 쓸 `jinSeohaeKnown` 등. `voice` 체인 이전(`flags.chains.voice`)
- **12장** 직접 클리어 vs 다른 팀 먼저 → 지역 상처·명성·서윤 반응. calamity 기존 규칙과 충돌 없이 감싸기
- **13장** 구함/늦음 → 친구 생존 플래그(엔딩 「다리」조건·26장 선불). 늦으면 각성/사망/실종 중 설계에 맞게 하나로 고정하고 후일담에 남김
- **14장** 듣는다/끊는다 → `mumyeong` 얼굴 공개 플래그, 3부 진입 톤

### 3-5. 장면 밀도·pause·역할 대칭

- 장당 대략 6~10장면. 2부는 훅+중반이라 **1부보다 조금 길어도 됨**. 단 한 자리에 몰아 읽지 말고 `pause`로 날짜/장소 컷.
- 플레이어가 팀원이면 위험 장(10·12·13) 진입 전 리더 반응 1회(동행/말림/묵인) — 1부 패턴 재사용.
- ★·⚔는 설계대로. 메인 전용/재앙은 일반 게이트보다 빡셀 수 있음(사용자 확정).
- 동적 who: `leader`·`friend`·`rival` + alt. 고정: `seoyun`(한서윤), `mumyeong`→14장에서 진서해 이름 공개.

### 3-6. 세계 시계

각 장 `expire`에 **얼굴 있는 상태**를 `M.flags`로 남길 것(토스트만 금지).

예:

- 10 만료 → 친구가 균열교에 깊이 들어감 / 관계↓ / 13장 시작이 「늦음」에 가깝게
- 12 만료 → 다른 팀이 둥지를 건드리거나 방치 → 지역 상처·뉴스
- 13 만료 → 친구 생사 확정 + 추모/각성 루머

### 3-7. 기존 시스템 연결

- `voice` 1단계 → 11장 (무작위 연작은 이미 main absorbed). 옛 저장 `chains.voice` 이전은 1부 7장 패턴 참고.
- `cult` 잔여 → 14장.
- 재앙 `calamity` 강북 지하철 둥지 → 12장. 메인이 발생을 앞당기거나, 이미 떠 있으면 그 장으로 연결.
- 한서윤이 없으면 `mainWho('seoyun')`이 이름표 객체로라도 나오게(1부 마도현 방식). 필요하면 `main_story.js`에만 보강.

### 3-8. 연기 시험 (`tools/smoke_test.js`)

기존 1부 검사 유지 + 추가:

1. 9장이 D급·조건에서 열린다 / 퀘스트 메인 줄
2. 9장 분기 후 10장 첫 줄(또는 서윤 동행 플래그)이 갈린다
3. 10장 분기에 따라 13장 친구 상태가 다르다(최소 두 갈래 스모크)
4. 12장 expire 또는 클리어가 플래그를 남긴다
5. 14장 완료 후 `M.ch === 15` 또는 2부 로그·`mumyeong` 공개 플래그
6. 한자 화면 글자 검사(공통) 통과

자동 재생 루프는 1부 검사처럼 `pause`/`pendingDay`를 건너뛸 수 있게.
