# 메인 「원초의 문」 고정 인물 외형 (생김새·의상)

> 톤·컨셉트·선화·명암은 [비주얼 스타일 기준](비주얼_스타일_기준.md)과 연결된 승인 원화를 함께 따른다.

> 영역 D. 메인 시나리오(`js/main_part*.js`)에 이름으로 나오는 고정 인물의 외형 기준이다. 초상·컷신·원화를 만들 때 이 문서를 따른다.
> 대사·서술에 이미 나온 특징(굵게 표시)은 바꾸지 않는다. 화면 글자는 한글만.
> 라이벌·첫 팀 리더·소꿉친구는 게임이 고른 **실제 NPC**라 외형이 판마다 다르다(초상 파츠 생성). 여기에는 넣지 않는다.

시대 배경: 2087년 전후, 대붕괴(2067) 20년 뒤의 한국. 근미래지만 생활감 있는 옷(작업복·정장·교복·트레이닝복). 판타지 갑옷 일색은 피한다.

## 1. 진서해 (무명) — 균열교 교주, 전 청룡 연구소 수석 연구원

| 항목 | 내용 |
|---|---|
| 나이 | 40대 후반 (대붕괴 때 20대 후반) |
| 체격 | **키가 크고 마름.** 어깨가 좁고 목이 길다. **걸음에 군더더기가 없다.** |
| 얼굴 | **마른 얼굴**, 광대가 도드라진다. 눈매는 처져 있고 다정해 보인다. 입가에 늘 옅은 미소. 눈 밑이 어둡다. |
| 머리 | 검은 머리를 뒤로 넘겨 묶은 짧은 꽁지. 관자놀이에 흰머리. |
| 피부·특징 | 창백하다. 3부 이후 **기침, 손바닥에 피**(폐에 바닷물이 찼다). 손끝이 늘 젖어 있는 것처럼 차갑다. |
| 의상 (1~2부) | **흰 가면**(눈구멍만 뚫린 매끈한 반가면, 이마에 갈라진 원 각인) + 바닥까지 끌리는 흰 로브. 소매가 넓다. |
| 의상 (2부 14장 이후) | 가면을 벗는다. 흰 셔츠 위에 회색 니트 카디건, 낡은 면바지. 강연(23장)에서는 단상 없이 바닥에 맨발로 선다. |
| 의상 (5부 해협) | 흰 로브, **소매가 바닷물에 젖어 있다.** 맨발. |
| 젊은 시절 (37장 기억·29장 신문 사진) | 흰 연구 가운, 헤드셋, 안경 없음. 웃고 있다. 마도현과 어깨동무. |
| 색 | 흰색·회색·바다 초록(소품) |

## 2. 아린 — 저편의 파수인, 꿈속 목소리

| 항목 | 내용 |
|---|---|
| 나이 | **열일곱쯤**으로 보인다(이십 년째 그대로) |
| 체격 | 작고 가늘다. 실체로 나타날수록(31·37장) 꿈보다 **작고 지쳐 보인다.** |
| 얼굴 | 동그란 눈, **눈동자가 주인공과 같은 색.** 표정은 담담하다가 웃을 때 아이 같다. |
| 머리 | 어깨 아래까지 오는 머리, **물속처럼 흔들린다**(바람이 없어도 떠 있다). 색은 짙은 청록에 끝이 옅어진다. |
| 피부·특징 | 반투명한 기운. 발밑에 그림자가 없다가 31장에서 처음 **그림자가 생긴다.** 손에 **반쪽 원**(쇠도 돌도 아닌 재질, 따뜻함). |
| 의상 | 저편의 옷: 무릎까지 오는 소매 없는 원피스형 겉옷, 천이 물에 젖은 것처럼 몸에 붙는다. 맨발. 허리에 가는 끈. 장식 없음. |
| 색 | 회색 바탕 + 초록빛(저편의 강·에테르) |
| 연출 | 꿈: 검은 바다 위, 허리까지 물. 실체(37장): 문틈의 빛이 사람 모양으로 선다. |

## 3. 마도현 — 관리국 국장, 공명 실험 공동 책임자

| 항목 | 내용 |
|---|---|
| 나이 | 50대 초반 |
| 체격 | 보통 키, 단단한 체형. 자세가 곧다. |
| 얼굴 | 각진 턱, 얇은 입술. 표정 변화가 거의 없다. **목소리를 높이지 않는다**(얼굴도 그렇게). 눈가 주름. |
| 머리 | 짧게 친 반백 머리, 단정하게 빗어 넘김. |
| 의상 | **깔끔한 정장**(짙은 남색 쓰리피스), 넥타이 단정, 관리국 배지. 국장실에서는 찻잔. |
| 갈래별 | 체포(18장): 수갑, 정장 그대로, 고개를 숙이지 않는다. 구치소: 회색 수의. 동맹: 정장 그대로. |
| 젊은 시절 | 연구소 점퍼, 손목시계를 자주 본다. |
| 색 | 남색·회색·은색 |

## 4. 한서윤 — 관리국 특수조사관

## 13. 흰 가면 사제·사도 (균열교 무리)

| 항목 | 내용 |
|---|---|
| 사제 | 진서해와 같은 흰 가면이지만 이마 각인이 **반쪽 원**(진서해는 갈라진 원). 흰 로브, 손에 초. |
| 사도 | 흰 가면 + 흰 전투복, 팔에 갈라진 원 완장. 일곱 명(사도 일곱, 쇠 배지 7). |
| 신도 | 대부분 비각성자. 평상복 위에 흰 로브. 작업복·앞치마·교복이 로브 아래로 보인다. |

## 14. 심연의 군주 — 원초의 게이트 문지기 (인물 아닌 존재, 참고)

| 항목 | 내용 |
|---|---|
| 모습 | **산만 한 크기**. 문을 등지고 웅크린다. 숨 쉴 때마다 문이 흔들린다. |
| 재질 | 저편의 마지막 에테르가 뭉친 것. 회색 몸에 초록 빛줄기, 쓰러지면 **초록 모래**로 흩어진다. |
| 눈 | 저편의 회색 하늘이 비친다. |
| 갈래별 | 관측소 회로를 끊으면 숨이 얕고 목소리가 갈라진다. 해협 의식이 끝났으면 등에서 노래가 흘러나온다. |

## 공통 상징

| 상징 | 모양 |
|---|---|
| 갈라진 원 | 균열교 상징. 원 한가운데가 위아래로 갈라짐. 전단지(검은 바탕 흰 선), 가면 이마, 제단 |
| 반쪽 원 | 아린과 고재석의 유물. 쇠도 돌도 아닌 재질, 따뜻하고 은은한 초록빛. 두 개를 맞대면 온전한 원 |
| 쇠 배지 7 | 균열교 일곱 번째 형제 표식. 둥근 쇠, 숫자 7 |
| 저편 | 회색 하늘, 갈라진 땅, 빛나는 모래가 말라붙은 강바닥 |
| 초록 바다 | 대붕괴 이전 제주 바다 색. 아이들 그림, 저편의 강, 초록 물고기 |
