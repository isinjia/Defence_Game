# 화면 연출 손맛(게임 필) 제안

> 전투가 게임에서 가장 많이 반복되므로, 같은 전투라도 "때리는 맛"이 있으면 오래 할 수 있다. 지금 연출을 정리하고 더할 것을 골랐다.
> 효과음 제안(`저장_소리_점검.md` 4번)과 한 묶음이다. 화면 연출과 소리가 같은 순간에 함께 터져야 손맛이 난다.
> 기준 코드: `claude/happy-turing-czlfa3` v0.24. 조사 문서이며 코드는 고치지 않았다.

## 1. 참고한 원칙

- **잠깐 멈춤(히트스톱)**: 맞는 순간 아주 짧게 멈춘다(실시간 게임 기준 3~5프레임). 때린 쪽과 맞은 쪽이 **함께** 멈춰야 한다. 맞은 쪽만 멈추면 딸꾹질처럼 보인다.
- **흔들림은 중요도에 비례**: 모든 타격에 흔들면 3분이면 무뎌진다. 짧게, 중요할수록 크게, 일상적인 행동엔 쓰지 않는다.
- **번쩍임**: 일반 타격은 아주 짧은 흰 번쩍임, 치명타는 더 길게 + 살짝 커짐, 저항당하면 색이 다른 번쩍임.
- **겹쳐 쌓기**: 만족스러운 타격 한 번은 약 0.1초 안에 함께 터지는 작은 반응 5~8개로 이루어진다. 두세 개로 시작해 "읽힐 때까지만" 더한다.
- **"Juice it or lose it"(2012 GDC)**: 밋밋한 벽돌깨기에 번쩍임·흔들림·파편·소리를 하나씩 더해 전혀 다른 게임으로 만든 발표.
- 이 원칙들은 실시간 게임 기준이다. ATB 전투는 이미 연출 사이에 기다림이 있어서(`applyEvent`가 연출마다 대기 시간을 돌려줌) 멈춤을 넣기 쉽다.

## 2. 지금 있는 연출 (`ui.js` `applyEvent`, `fx.js`, `css/style.css`)

| 순간 | 지금 |
|---|---|
| 스킬 사용 | 시전자가 앞으로 튀어나감(lunge), 스킬 이름 떠오름 |
| 타격 | 맞은 쪽 흔들림, 속성색 번쩍임, 피해 숫자 떠오름, 속성색 파편 9개 |
| 치명타 | 파편 16개, 무대 전체 흔들림, "치명" 글자 |
| 전체 공격 | 무대 전체 속성색 번쩍임 |
| 회복·버프 | 초록 빛남, 숫자 |
| 쓰러짐 | 흐려짐(`dead` 클래스) |
| 돌파 | 전용 연출(`FX.breakthrough`) |
| 동작 줄이기 설정 | 대응됨(`FX.reduced`) |

**평가**: 기본 재료는 다 있다. 부족한 건 **강약 구분**이다. 약한 타격과 큰 타격, 잡몹 처치와 보스 처치의 연출이 거의 같다. 그리고 "결과를 확인하는 순간"(처치, 보상, 등급 상승)이 짧게 지나간다.

## 3. 제안 (우선순위 순)

### 1. 체력 막대 "잔상" — 난이도 하
- 맞으면 체력 막대가 즉시 줄고, 뒤에 흰(또는 붉은) 잔상 막대가 0.4초 뒤 따라 줄어든다. 얼마나 깎였는지 한눈에 보인다.
- 회복은 반대로 초록 잔상이 먼저 차오른다.
- 비용이 가장 낮고 효과가 가장 확실하다.

### 2. 피해 크기에 따른 강약 — 난이도 하
- 피해 숫자 크기를 대상 최대 체력 대비 비율로 키운다(5% 미만 작게, 30% 이상 크게).
- 대상 흔들림 세기도 같은 비율로. 지금은 모든 타격이 같은 세기(`shake .42s`)다.
- 무대 전체 흔들림은 치명타·보스 큰 기술·처치에만. 일반 타격엔 넣지 않는다(지금처럼).

### 3. 처치와 큰 타격의 잠깐 멈춤 — 난이도 하
- 치명타, 적 처치, 보스 큰 기술 명중 때 연출 사이에 60~120ms 정지(모든 유닛 애니메이션 일시 정지 + 번쩍임 유지). `applyEvent`가 돌려주는 대기 시간에 더하면 된다.
- 마지막 적을 쓰러뜨리는 일격은 조금 더 길게(200ms) + 확대 → "전투 승리" 글자.

### 4. 쓰러짐 연출 — 난이도 하
- 지금은 흐려지기만 한다. 괴수는 속성색으로 흩어지며 사라지고(파편 + 투명), 보스는 짧은 폭발 + 화면 번쩍임.
- 아군이 쓰러지면 카드가 기울며 회색으로, 이름 위에 짧게 "전투 불능".
- 코어가 떨어지는 장면을 넣으면 보상과 연결된다: 쓰러진 자리에서 작은 결정이 튀어 오른다(보스는 크게).

### 5. 적 행동 예고의 몸짓 — 난이도 하
- 전투 제안 1번(행동 예고)과 짝: 큰 기술을 준비하는 적은 몸이 웅크리거나 빛을 모으는 반복 애니메이션. 실행 직전 한 번 크게 번쩍.
- 예고가 있어도 몸짓이 없으면 아이콘만 보고 지나친다. 몸짓이 "읽게" 만든다.

### 6. 보상 확인의 순간 — 난이도 중
- 게이트 클리어 결과 창이 지금은 문장 목록이다. 보상을 하나씩 튀어나오게(크레딧 숫자가 올라가고, 코어·장비·유물이 차례로 카드로). 희귀도가 높을수록 빛과 소리.
- 감정·저주 유물(3차 제안)과 합치면 "열어 보는 순간"이 된다.

### 7. 등장 연출 — 난이도 하~중
- 게이트 진입: 화면이 균열 모양으로 갈라지며 전투 화면으로(0.6초).
- 보스 구역: 보스 이름이 화면 가운데에 크게 나왔다 줄어 이름표로 자리 잡는다. 레드 게이트는 붉은 테두리가 계속 맥박친다.
- 네임드 괴수(3차 제안)는 이름과 흉터 설명이 함께.

### 8. 성장의 순간 — 난이도 하
- 단계 상승(초기 → 중기)은 지금 연대기 한 줄뿐이다. 캐릭터 카드가 한 번 빛나고 짧은 문구("중기 진입")를 띄운다.
- 스킬 숙련 상승·각성, 칭호 획득도 같은 문법의 작은 알림으로 통일(가운데 위에서 내려왔다 사라지는 띠).

### 9. 지도의 손맛 — 난이도 하
- 이동 경로 끝에 도착하면 발밑에 작은 파문. 게이트 칸 근처를 지나면 게이트 아이콘이 반응해 꿈틀.
- 속보(브레이크)가 나면 해당 도시가 붉게 깜빡이고 지도 가장자리에 방향 표시.

## 4. 지킬 것

- **동작 줄이기 설정**에서는 흔들림·확대·정지를 끄고 번쩍임과 숫자만 남긴다(지금 `FX.reduced` 구조 유지).
- **자동 전투·2배속**에서는 멈춤과 흔들림을 절반 이하로. 빠르게 돌리는 사람에게 연출은 방해다.
- 효과음과 같은 이벤트에서 함께 터지도록, 연출 함수와 소리 함수를 같은 자리(`applyEvent`의 각 경우)에서 부른다.

## 5. 추천 순서

1(체력 잔상) → 2(강약) → 3(멈춤) → 4(쓰러짐) → 8(성장 알림) → 5(예고 몸짓, 전투 제안 1번과 함께) → 7(등장) → 6(보상 확인) → 9(지도)

1~4는 CSS 몇 줄과 `applyEvent` 수정 정도로 전투 체감이 크게 바뀐다. 효과음과 같이 넣으면 효과가 배가된다.
