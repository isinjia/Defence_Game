# 직업복 목선 맞춤 (턱·목을 옷깃에 맞춰 자르는 법)

직업복(`assets/portraits/outfits/`, `js/job_outfits.js`)에서 목이 떠 보이거나, 턱 밑에 살색 네모가 생기거나, 같은 옷인데 체형마다 목 위치가 다를 때 이 순서로 고친다. **그림을 새로 그리기 전에 코드로 먼저 맞춘다**(사용자 결정).

## 원리

- 목은 **옷의 앞깃 윗선**까지만 보여야 한다. 앞깃은 목 앞을 덮고, 뒷깃(목 뒤로 돌아가는 면)은 목 뒤에 있다.
- 옷 그림에서 **목 구멍(어두운 안쪽 면)의 아래 테두리**가 앞깃 윗선이다. 위 테두리(뒷깃 안쪽)가 아니다.
- 코드의 `IN_PROF`(보통·마름) / `IN_PROF_OLD`(근육질·통통)에 옷마다 이 선을 넣는다. 형식: 성별 → 옷 → 23개 깊이. 가운데에서 -44..44(4px 간격) 위치의 깊이이고, 기준은 뒷깃 테두리 `manifest.json`의 `neck[1]`이며 단위는 옷 그림 px다.
- 옛 값은 여러 옷에서 뒷깃 안쪽을 따라가고 있었다. v2.15에서 74벌을 다시 쟀다.

## 1. 앞깃 윗선 재기

자동 검출은 믿을 수 없다. 목 구멍과 안에 받친 검은 옷의 색이 거의 같아서, 74벌 중 24벌이 어긋났다. 그래서 **눈으로 읽어 표로 넣는다**.

```bash
python3 tools/outfit_neck_line.py sheet m /tmp/neck   # 남자 37벌, 12벌씩 4장
python3 tools/outfit_neck_line.py sheet f /tmp/neck
```

- 시트는 옷마다 목 구멍을 3배로 키워서 보여 준다. 하늘색 가로줄은 깊이 눈금(0~60px)이고, 노란 선은 지금 코드의 선이다.
- 노란 선이 어두운 목 구멍의 **아래 테두리**에 붙어 있지 않은 옷만 고른다. 그 옷의 `[양끝 깊이, 가운데 깊이]`를 눈금으로 읽는다.
  - 안에 검은 폴라·셔츠가 있으면, 목은 그 폴라의 앞 테두리로 들어간다.
  - 후드는 후드 고리가 아니라 안쪽 폴라의 앞 테두리를 잰다.
- 읽은 값은 표(JSON)로 만든다. 예: `{"m":{"assassin":[15,29]},"f":{"necromancer":[32,41]}}`
- 같은 명령에 표를 넘기면 그 값으로 선을 그려 다시 보여 준다(`sheet m /tmp/neck table.json`). 맞으면 아래처럼 넣는다.

```bash
python3 tools/outfit_neck_line.py apply table.json    # IN_PROF·IN_PROF_OLD 둘 다 갱신
```

## 2. 체형마다 같게 (턱과 깃의 관계 고정)

- 옷 높이는 기본적으로 체형별 어깨 높이(`SHOULDER`·`SHOULDER_OLD`)에 맞춘다. 그래서 같은 옷이어도 체형마다 턱과 깃 사이가 달라질 수 있다.
- 깃이 목을 덮는 옷(높은 깃·후드)은 `FRONT_AT`에 넣는다. 그러면 체형과 상관없이 **앞깃 가운데 윗선 = 턱끝 + FRONT_AT(px)**가 되도록 옷 높이를 정한다(`lockBack`). 지금은 암살자·강령술사에 3px로 넣었다.
- `NECK_SINK`에 같은 옷을 넣으면 그 옷은 목 자리를 옷에서 파내지 않는다. 깃이 목을 덮고 턱만 깃 앞에 그려진다.

## 3. 자주 나온 버그와 위치

| 증상 | 원인 | 고친 곳 |
|---|---|---|
| 여자 턱 밑 살색 네모 | 머리 영역의 '목 기둥' 사각형이 옷보다 위에 그려짐 | `render`: 여자 `jaw` 사각형을 턱끝 곡선으로 교체 |
| 남자 턱 밑 살색 네모(높은 깃) | 턱을 깃 앞에 그리는 영역(`jawn`)에 여자용 사각형이 섞임 | `jawn`에는 여자만 사각형을 넣음 |
| 근육질·통통 턱 밑 네모 | `renderOld`의 턱 보호층이 목 띠까지 그림 | `FRONT_AT` 옷은 턱선 모양 경로로 자름 |
| 같은 옷, 체형마다 목 위치 다름 | 어깨 높이 기준 배치 | `FRONT_AT`/`lockBack` |

## 확인

- 화면 확인은 빌드 뒤에 한다(`bash tools/build.sh`, `index.html`이 `dist/`를 읽는다).
- 같은 옷을 남녀 × 4체형(thin·normal·strong·heavy)으로 띄워 **목 부분을 크게 확대해서** 본다. 썸네일로는 네모나 띠가 안 보인다.
- 렌더 캐시가 시드+옵션 기준이다. 값을 바꿔 가며 비교할 때는 시드를 바꾼다.
- 미리보기를 사용자에게 보여 주고 확인받은 뒤 커밋한다.
