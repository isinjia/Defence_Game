# 저장 안정성 · 소리 · 성능 점검

> 아직 아무도 보지 않은 바닥 영역을 점검했다: 진행이 사라질 위험, 소리, 무게.
> 기준 코드: `claude/happy-turing-czlfa3` v0.22. 조사 문서이며 코드는 고치지 않았다.

## 1. 지금 상태 (측정)

| 항목 | 결과 |
|---|---|
| 저장 방식 | 브라우저 `localStorage` 한 칸(`gate_chronicle_save_v2`). 매 이동·월 진행마다 자동 저장 |
| 저장 크기 | 10년 진행 후 약 72KB(NPC 55KB, 소문 5KB, 안개 2KB 등). 수십 년이 지나도 수백 KB 수준으로 여유 있음 |
| 저장 실패 처리 | `try { setItem } catch { /* 저장 실패 무시 */ }` — **실패해도 플레이어에게 알리지 않는다** |
| 백업·내보내기 | 없음. 다른 기기로 옮길 방법도 없음 |
| 사망 시 | 저장을 지운다(의도된 한 생 구조). 회귀 기록만 따로 남음 |
| 홈 화면 앱(PWA) | 매니페스트·아이콘·서비스 워커 없음 |
| 소리 | **전혀 없음**(효과음·배경음·진동 모두 0) |
| 화면 연출 | 있음: 타격 흔들림, 숫자 떠오르기, 파편, 돌파 연출(`fx.js`), 동작 줄이기 설정 대응 |
| 무게 | `dist/game.js` 827KB, gzip 약 240KB(GitHub Pages는 압축 전송). 압축(minify)해도 크기가 거의 줄지 않음(한글 문장 비중이 큼) |
| 속도 | 첫 화면 약 1.2초(로컬), 한 달 진행 약 1.3ms, 저장 약 0.3ms. **성능 문제는 없음** |

## 2. 문제

### 상1. 아이폰 사파리에서 진행이 통째로 지워질 수 있다
- 사파리는 사용자가 **사파리를 쓰는 날 기준 7일 동안 그 사이트와 상호작용하지 않으면** 스크립트가 쓴 저장소(localStorage 포함)를 지운다(2020년 도입된 추적 방지 정책). 사파리를 안 연 날은 세지 않는다.
- 이 게임은 저장이 localStorage 한 칸뿐이라, 아이폰으로 하다가 일주일 쉬면 **수십 년짜리 인생이 사라질 수 있다.** 회귀 기록도 같이 사라진다.
- **홈 화면에 추가한 웹앱은 이 제한에서 빠진다**(애플 설명, WebKit 이슈 트래커 기준). 다만 보고된 동작이 일관되지 않은 사례도 있어, 홈 화면 추가만 믿기보다 내보내기를 함께 두는 게 안전하다.
- `navigator.storage.persist()`(지속 저장 요청)는 사파리에서 홈 화면 추가 같은 조건이 없으면 거절된다는 보고가 있으나 공식 확인은 못 했다.

### 상2. 저장이 실패해도 모른다
- 사생활 보호 모드, 저장 공간 부족, 브라우저 설정으로 저장이 실패하면 아무 표시 없이 넘어간다. 다음에 들어오면 "저장 데이터 없음"이다.

### 중1. 소리가 없다
- 모바일 게임에서 소리는 손맛의 큰 부분이다. 타격·치명타·돌파·속보 같은 순간에 아무 소리가 없다.
- 화면 연출은 이미 잘 되어 있어서, 소리만 얹으면 체감이 크게 오른다.

### 하1. 저장 형식에 버전 표시가 없다
- 옛 저장은 `player.x`가 없으면 불러오기를 거부하고, 새 필드는 `initSandbox`·`hunterInit`에서 `??=`로 채운다. 지금까진 이걸로 버텼지만, 필드 이름이 바뀌거나 구조가 바뀌면 조용히 깨질 수 있다.

## 3. 추천

### 1. 내보내기·가져오기 — 최우선, 난이도 하
- 타이틀과 설정에 "저장 내보내기 / 가져오기". 저장 JSON을 압축해 **텍스트 코드**(복사·붙여넣기)와 **파일 다운로드** 두 가지로. 회귀 기록도 함께.
- 다른 기기로 옮기기, 사파리 삭제 대비, 버그 제보 첨부까지 한 번에 해결된다.

### 2. 홈 화면 앱으로 만들기 — 난이도 하
- 웹앱 매니페스트(`manifest.webmanifest`: 이름, 아이콘, 세로 고정, 전체 화면), 아이폰용 아이콘(`apple-touch-icon`), 간단한 서비스 워커(오프라인 캐시).
- 첫 실행이나 첫 돌파 때 "홈 화면에 추가하면 저장이 더 안전하고 전체 화면으로 즐길 수 있습니다" 안내를 한 번.
- 홈 화면에서 실행 중인지 확인해(`display-mode: standalone`) 안내를 숨긴다.
- 가로 화면 문제(모바일 점검 상3)도 매니페스트의 세로 고정으로 함께 해결된다.

### 3. 저장 실패 알림과 백업 칸 — 난이도 하
- 저장이 실패하면 화면 위에 한 번 경고("저장되지 않았습니다. 사생활 보호 모드인지 확인하세요 / 내보내기로 백업하세요").
- 저장 칸을 둘로: 현재 + 매년 1월의 자동 백업. 불러오기가 실패하면 백업으로.
- 지속 저장 요청(`navigator.storage.persist()`)을 첫 저장 때 한 번 호출. 거절돼도 손해는 없다.

### 4. 절차적 효과음 — 난이도 중
- 파일 없이 Web Audio로 짧은 소리를 합성한다(용량 0). 첫 탭 때 소리 장치를 깨운다(모바일 브라우저는 사용자 동작 안에서 `resume()`해야 소리가 난다. 비동기 뒤에 호출하면 무시될 수 있다).
- 처음엔 12개 정도면 충분하다.

| 순간 | 소리 |
|---|---|
| 버튼, 선택지 | 짧은 클릭 |
| 지도 한 칸 이동 | 낮고 짧은 발소리 |
| 게이트 진입 | 낮게 웅웅대다 올라가는 소리 |
| 타격 | 속성별 음색(화: 거친 잡음, 빙: 높은 쨍, 뇌: 지직, 강: 금속, 영: 울림) |
| 치명타·효과적 | 타격음 + 높은 겹소리 |
| 회복·버프 | 올라가는 화음 |
| 쓰러짐 | 낮게 꺼지는 소리 |
| 내 차례 | 맑은 알림 하나(ATB 대기 알림, 소리만으로 차례를 알 수 있게) |
| 돌파 성공 / 실패 | 상승 화음 / 갈라지는 소리 |
| 칭호·월드 퍼스트 | 짧은 팡파르 |
| 속보(브레이크 등) | 경보음 두 번 |
| 사망 | 길게 사라지는 소리 |

- 설정에 효과음 켜기/끄기와 음량. 기본값은 켜짐, 첫 실행에 음소거 상태면 존중.
- 진동은 안드로이드만 된다(`navigator.vibrate`, 아이폰 사파리는 지원하지 않음). 치명타·돌파·속보에만 아주 짧게, 설정으로 끌 수 있게.
- 배경음은 나중에. 넣는다면 지도·도시·전투·게이트 브레이크 4곡이면 충분하다.

### 5. 저장 형식 버전 — 난이도 하
- 저장에 `saveVersion` 숫자를 넣고, 불러올 때 버전별 변환 함수를 차례로 적용한다. 지금의 `??=` 보정을 이 변환 안으로 모은다.

### 6. 무게는 지금 손댈 필요 없음
- gzip 240KB, 한 달 진행 1.3ms로 충분히 가볍다. 다만 빌드에 `--minify`를 붙여도 크기가 줄지 않는다는 점(한글 문장이 대부분)만 알아 두면 된다. 나중에 사건 글이 크게 늘면 사건 데이터를 별도 파일로 나눠 늦게 불러오는 방법이 있다.

## 4. 추천 순서 (사용자 결정 반영)

- **지금 구현**: 4(효과음).
- **게임을 다 만든 뒤 구현**: 1(내보내기·가져오기) → 3(실패 알림·백업) → 2(홈 화면 앱) → 5(저장 버전). 저장 구조가 계속 바뀌는 개발 중에는 미뤄 두고, 기능이 굳은 뒤 한 번에 넣는다. 그때까지 아이폰 사파리 7일 삭제 위험은 남아 있다는 점만 기억해 둔다.
