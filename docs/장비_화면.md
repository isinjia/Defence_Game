# 장비 화면

장비 탭은 `js/gear_layout.js`에서 기존 시트 함수를 감싸 구성한다. 장비 생성·능력치·장착 규칙은 바꾸지 않는다. 스타일은 `css/gear_layout.css`에 둔다.

- 모바일: 장착 슬롯 3열 × 3행 아래에 인벤토리를 배치한다. 빈 칸을 큰 목록 행으로 늘어놓지 않는다.
- PC: 왼쪽은 장착 슬롯, 오른쪽은 인벤토리다. 목록을 내려도 장착부를 확인할 수 있다.
- 기본 9칸은 무기, 방어구 5칸, 장신구 3칸이다. 보조 칸이 열리면 별도 줄로 보인다.
- 슬롯을 누르면 해당 장비의 전체 이름·능력치·해제 버튼이 나타나고 인벤토리를 같은 종류로 좁힌다.
- 장신구 칸을 선택한 상태에서는 가방의 장착 버튼이 해당 칸에 장착한다. 나머지는 기존 장착 규칙을 따른다.
- 인벤토리는 장비와 소모품으로 나누고, 장비는 전체·무기·방어구·장신구 필터를 제공한다. 이름·아이콘을 누르면 기존 아이템 상세 창을 연다.
- 세트 효과·도감·감정·성장형 장비 등 부가 구역은 아래 접기 영역에 보존한다.

선택 슬롯과 필터는 화면 상태이며 저장 데이터에 추가하지 않는다. 320px·390px·PC에서 슬롯 표시, 분류 전환, 지정 칸 장착·해제, 소모품 사용과 가로 넘침을 확인한다.
