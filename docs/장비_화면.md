# 장비 화면

장비 탭은 `js/gear_layout.js`, 인벤토리 탭은 `js/inventory.js`에서 기존 시트 함수를 감싸 구성한다. 장비 생성·능력치·장착 규칙은 바꾸지 않는다. 스타일은 `css/gear_layout.css`에 둔다.

- 장비와 인벤토리는 독립된 상위 탭이다.
- 모바일 장비 탭: 장착 슬롯 3열 × 3행 아래에 선택 부위의 교체 목록을 배치한다. PC는 슬롯과 교체 목록을 좌우로 배치한다.
- 기본 9칸은 무기, 방어구 5칸, 장신구 3칸이다. 보조 칸이 열리면 별도 줄로 보인다.
- 슬롯을 누르면 해당 장비의 전체 이름·능력치·해제 버튼과 그 칸에 장착할 수 있는 장비 목록이 나타난다.
- 장신구·보조 칸을 선택한 상태에서는 교체 목록의 장착 버튼이 해당 칸에 장착한다.
- 인벤토리는 전체·장비·소모품·재료 필터를 제공한다. 장비는 장착, 소모품은 사용, 재료는 수량·용도를 확인할 수 있다. 코어·약초·부산물·각성 촉매·유물을 포함한다.
- 인벤토리에서 장비를 장착하면 기존 자동 배치 규칙을 따른다. 도시에서는 기존 가격(가치의 40%)으로 장비를 판매할 수 있으며 판매 전에 확인 창을 띄운다.
- 세트 효과·도감·감정·성장형 장비 등 부가 구역은 아래 접기 영역에 보존한다.

선택 슬롯과 필터는 화면 상태이며 저장 데이터에 추가하지 않는다.

사용자 지시(2026-11-14)에 따라 스모크 테스트는 별도로 지시받았을 때만 실행한다. 푸시·배포도 작업별 명시 지시가 필요하다.
