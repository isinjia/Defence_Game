# 동료 대사·잡담 점검과 제안

> 헌터물에서 파티는 함께 싸우는 사람들이고, 재미의 절반은 그들의 말이다(공략 중 투덜거림, 라이벌끼리 신경전, 위기 때 한마디). 지금 동료들이 무엇을 말하는지 쟀다.
> 기준 코드: `claude/happy-turing-czlfa3` s2 v0.13 무렵. 조사 문서이며 코드는 고치지 않았다.

## 0. 함께 확인한 것 (문제 없음)
- **저장 크기**: 새 게임 53KB → 10년 161KB → 20년 146KB(NPC 120~160명). 휴대폰 저장 한도(약 5MB)의 3% 수준이라 걱정 없다. 한 달 진행 2~3ms.
- **이야기 연결 구조**: 프롤로그 장면의 다음 장면 누락 0, 연계 기연 단계 빠짐 0, 이야기 id 중복 0, 대기열이 부르는 사건 누락 0. 국밥집 요원 같은 끊김은 구조가 아니라 **내용상** 끊김이었다(4-8에서 연결 문장으로 보완 중).
- 덧붙여: 저장 실패(용량 초과 등)는 지금 조용히 무시된다(`game.js save`). 게임 완성 뒤 할 "저장 실패 알림"에 포함.

## 1. 지금 동료 대사 (`combat.js BARKS`)
- 성격 5종 × 5줄 = **25줄이 전부**. 전투 중 행동할 때 16% 확률로 무작위 한 줄.
- **상황과 무관**하다: 체력이 바닥일 때도, 보스를 잡았을 때도, 동료가 쓰러졌을 때도 "덤벼!"·"괜찮아?" 중 아무거나.
- 누구에게 하는 말인지 없다(동료끼리 관계·라이벌·연인·사제 관계가 대사에 안 나온다).
- 전투 밖(층 지도 탐색, 이동, 휴식, 마을)에서는 동료가 말하지 않는다. 팀 상의(4-3)와 막아서기 대사가 처음으로 전투 밖 대사가 된다.
- 직업·출신·속성·인물 유형(`archetypes.js`)이 대사에 반영되지 않는다.

## 2. 제안 (우선순위 순)

### 1. 상황 대사 — 난이도 하(데이터)
- 대사를 **상황 키 × 성격**으로 나눈다. 상황마다 성격별 3~5줄.

| 상황 | 예 (just / kind / warlike / greedy / cold) |
|---|---|
| 전투 시작(보스) | "여기서 끝낸다." / "다들 살아서 나가요." / "드디어 큰 놈이다!" / "저거 코어 얼마짜리지?" / "패턴부터 본다." |
| 내 체력 30% 아래 | "아직이다…!" / "저, 저 괜찮아요…" / "이제 좀 재밌네." / "위험수당 청구한다." / "…후퇴 각." |
| 동료가 쓰러짐 | "{npc}! 일어나!" / "안 돼, {npc}!" / "{npc} 몫까지 부숴 주마!" / "…{npc} 몫 보상은?" / "{npc} 이탈. 진형 다시." |
| 약점 적중(4-6) | "통했다!" / "됐어요!" / "바로 그거야!" / "깔끔하네." / "예상대로." |
| 저항됨 | "안 먹힌다, 바꿔!" / "어, 안 들어가요…" / "단단하네!" / "탄약 아깝다." / "속성 불리. 교체." |
| 치명타·막타 | 성격별 자랑/칭찬 |
| 리더 오더를 받음/거절(4-1) | "알겠다." / "네!" / "내 방식대로 간다!" / "그거 추가 수당이지?" / "비효율적이다." |
| 승리 | 성격별 + 다친 동료 챙기기 |
| 도주 | 성격별 원망·안도 |

- 지금 16% 무작위를 **상황이 생길 때 우선**(쓰러짐·보스·약점은 높은 확률, 평타는 낮은 확률)으로. 같은 전투에서 같은 줄 반복 금지.
- 말풍선은 기존 오더 말풍선(4-1) 자리를 같이 쓴다.

### 2. 관계 대사 — 난이도 중
- 대사에 **상대가 있다**: 관계 수치·관계 종류(라이벌·연인·사제·소꿉친구·원수)를 보고 대상에게 말한다.
  - 라이벌: "{npc}보다 먼저 잡는다." / 연인: "{npc}, 뒤!" / 사제: "스승님, 보세요!" / 사이 나쁨: "{npc}, 또 늦었냐."
- 플레이어에게 하는 말도 관계에 따라: 관계 높음 "역시 {name}", 낮음 "{name}, 발 걸리적거린다."
- 팀 상의(4-3)에서 무시당한 동료는 다음 전투에서 비꼬는 대사(기억 `npc_memory.js` 연결).

### 3. 탐색·이동 잡담 — 난이도 중
- **층 지도에서 칸을 옮길 때·휴식 칸·층 사이**에 가끔(20%) 동료 둘이 주고받는 짧은 대화(2~4줄). 오버레이 말풍선이 순서대로 떴다 사라진다(조작을 막지 않음).
- 주제: 게이트 속성·괴수 감상, 최근 뉴스(C 영역 뉴스·음모와 연결: "들었어? 백호 길드 그거"), 서로의 과거(출신·각성 갈래), 돈, 연애, 플레이어 이야기.
- 대화가 관계를 조금 바꾼다(맞장구 +, 시비 −). 같은 대화는 한 번만, 관계 단계마다 새 대화가 열린다(Dragon Age식 파티 잡담).
- 시작 분량: 성격 조합 10쌍 × 3대화 + 관계 종류 5 × 3대화 ≈ 45대화.

### 4. 직업·출신·속성 맛 — 난이도 하
- 상황 대사 일부를 직업·출신으로 덮어쓴다: 사제 "신의 가호를!", 암흑기사 "피가 더 필요해", 저격수 "조준 중. 말 걸지 마", 군인 출신 "엄호한다!", 재벌 출신 "이거 끝나면 내가 쏜다", 생활형 각성(백수 출신) "아 출근하기 싫다…".
- 무당(성) "대감님 오신다!", 무당(암) "원귀야, 가라." 같은 장르 맛.

### 5. 마을·생활 대사 — 난이도 하
- 동료를 마을에서 만나면(동행·숙소) 그날 상태 한 줄: 다쳤으면 투덜, 승급 직후 들뜸, 연애 중이면 자랑. 지금 마을의 동료 화면에 한 줄 칸.

## 3. 추천 순서
1(상황 대사) → 4(직업·출신 맛) → 2(관계 대사) → 3(탐색 잡담) → 5(마을)
- 1·4는 데이터만으로 큰 체감. 2·3은 관계 깊이(`관계_깊이_제안.md`)·팀 상의(4-3)와 맞물린다.

## 참고
- 장르 근거: 헌터물 일반 문법(파티원 간 대화, 라이벌 신경전). 게임 근거: 상황 대사(Darkest Dungeon의 바크), 동료 간 잡담이 관계를 바꾸는 구조(Dragon Age 파티 잡담), 반복 금지·관계 단계별 해금(Hades식 대사 큐).

## 4. 추가: 성격이 5종뿐인 문제 (사용자 지적)

### 측정
- **성격**(`data.js PERSONALITIES`)은 지금도 5종: 온화·호전·탐욕·의협·냉담. 전투 AI(치유 시점 `HEAL_AT`, 탐욕 도주)와 대사(`BARKS`)가 이 5종만 본다.
- 앞서 만든 것은 **인물 유형 16종**(`archetypes.js`: 라이벌 동기·괴물 신인·몰락한 천재·대기만성형·길드 2세·생계형 가장·복수귀·은퇴한 전설·짐꾼 출신·정보상·원칙주의 감독관·방송 헌터·빌런 헌터·혹사당하는 힐러·이방인·또 다른 회귀자). "누구인가(사연)"이고 NPC의 약 40%만 가진다. 유형마다 대화 2~3줄이 있지만 **전투 대사에는 연결되지 않았다**(제안 문서에 있었지만 미구현).
- 그래서 실제 플레이에서 동료 말투는 여전히 5가지로 들린다.

### 제안: 성격(말투·기질)을 장르 클리셰로 20종 안팎 — 사연(유형)과 따로
- 성격 = **어떻게 말하고 반응하나**, 유형 = **어떤 사연인가**. 둘을 겹쳐 "츤데레 생계형 가장", "허세 괴물 신인" 같은 조합이 나오게.
- 각 성격은 전투 AI용 **기본 기질**(기존 5종 중 하나)을 가진다 → AI 코드는 그대로 두고 대사·관계·상의 반응만 늘린다.

- 성격마다: 상황 대사(2절 1번 표의 상황 9개 × 2~3줄), 팀 상의 O/X 경향(4-3), 막아서기 확률, 관계 상승 속도(`relGain`), 잡담 빈도.
