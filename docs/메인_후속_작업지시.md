## 1. 정합 패치 (먼저, 작게)

### 1-1. `voice` / `cult` 체인 단계 (설계 §5와 맞출 것)

| 장 | 올바른 동작 |
|---|---|
| 7장 | `chains.voice = max(…, 1)` (이미) |
| 11장 | `voice = max(…, 2)` — 기록에서 진서해 이름 |
| 14장 | **voice를 3으로 올리지 말 것.** `cult = max(…, 4)` 만 (가면 벗기 = cult 마무리) |
| 17장 | `voice = max(…, 2)` 유지 또는 문서상 voice2면 여기. **done에 명시** |
| 19장 | `voice = max(…, 3)` |
| 20장 | `arinName`만. **`voice = 4` 금지** (voice4 = 37장 문 앞) |
| 37장 | `voice = max(…, 4)` + `voiceEnd` 엔딩 조건 |

지금 14가 voice3·20이 voice4면 **내려 고치고** 옛 저장은 `??=`/`Math.min` 없이, 이미 过高면 다음 장 done에서 올바른 값으로만 맞춤(파괴적 리셋 금지 — `Math.max`로 목표 단계만 보장하되 20장의 4 설정 코드는 삭제).

### 1-2. 재앙 ★ 정책 — 하나로 고정

**확정 정책(이 지시 기준):**

- 메인 장 12·15·21·27·32는 샌드박스 `calamity`와 **상태를 공유**한다.
- 장이 열릴 때 해당 재앙이 없으면 **약하게 발생시키거나** 관측 상태만 세운다(기존 `NEST`/`CAL_OF` 확장).
- 플레이어가 메인에서 클리어하면 calamity 쪽도 해소·상처 감소로 감싸기.
- 다른 팀이 먼저면(세계 시계/미룸) 지역 상처·뉴스 — 지금 expire와 맞물릴 것.
- 전투는 이야기 전투(⚔/★) 유지 가능하되, **보스 멘트·클리어 플래그가 calamity id와 동일 키**로 남게.

문서 `메인_시나리오.md` §12 「상태만 읽는다」문구를 위 정책으로 **고쳐 쓴다**.

### 1-3. 세계 시계 FOMO

- 퀘스트 메인 줄에 **「만료까지 N개월」**(해당 장 `expire.months` − 경과) 표시.
- **구멍 수정:** `started`만 찍히고 방치하면 만료가 안 도는 문제 →  
  - (A) 시작 후에도 장면 미완·장 미완이면 expire 적용, 또는  
  - (B) `started`여도 `done` 전이고 열린 지 N개월이면 만료  
  → **B 권장.** `main_story.js`의 expire 조건을 `!M.done[n]` 기준으로.
- 부 단위 시계(§4, 예: 2부 18개월): ⑦에서. ①에서는 장별 FOMO UI+구멍만.

### 1-4. 리더 말투·leadScene

- 2~4부 `leadScene` / 25장 리더 대사에 1부와 같이 `mainReg`용 `{ haera, haeyo, short }` (핵심 대사).
- 장마다 **같은 복붙 금지** — with/stop/let마다 맥락 한 줄 변주(제목·위험만 바꾼 복붙 제거).
- 리더 없으면 alt(친구·서술) — 4부 22·25 수준을 2·3 위험 장에도.

### 1-5. `tone3:heard` → 15장

끊기(`deaf`)만큼 **듣기**도 15장 입구 1~2줄(진서해 잔향·개인 교신 여운).

## 2. 3·4부 밀도 보강 (리라이트 말고 덧붙이기)

목표: 장당 **최소 5장면**, 이상적으로 6~8. 기존 명장면은 유지하고 **이동·잔향·인물 단독·pause**만 끼운다.

### 2-1. pause 배치

| 부 | 지금 | 넣을 곳(예) |
|---|---|---|
| 3부 | 16만 | 15(대구 이동), 17(서버 전), 19(강릉→제주 항해), 20 전 |
| 4부 | 23만 | 21(강릉), 24(서울 이동), 25 후→26, 27 전 |

### 2-2. 캐릭터 보강 (평가 Top)

1. **지우/각성 친구 갈래** — 비각성 친구 밀도에 맞출 전용 대사(10·13·26). 동생·구조·옥상 분기.
2. **아린** — 20장 이후(21·23·26)에 **부탁 한 번**: 닫기/열기/다리 중 하나를 꿈에서 직접 요구 → `endSeed`와 교차.
3. **서윤 watch(거절)** — 완전 퇴장 금지. 18·21·24에 **거리 둔 감시자** 대사라도 남길 것.
4. **라이벌** — `RIVAL_LINE` 복붙 줄이기. 장마다 경로별 **새 정보 한 줄**.

### 2-3. smoke

- 3·4부: pause 대기일 존중, 15 heard 첫 줄, 아린 부탁 플래그, 리더 말투 객체 존재(선택), calamity 키 공유 한 경로.
