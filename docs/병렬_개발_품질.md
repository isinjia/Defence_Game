# 병렬 개발 중 품질 지키기

> 구현 세션 6개(A~F)가 같은 브랜치 `claude/happy-turing-czlfa3`에 동시에 올린다. 한 세션의 변경이 다른 기능을 조용히 망가뜨리지 않게 하는 방법을 조사했다.
> 기준: v0.32. 이 문서와 함께 `tools/smoke_test.js`(연기 시험)를 저장소에 넣었다.

## 1. 지금 상황 (측정)

- **버전 번호 겹침**: 같은 번호가 두 번 올라간 버전이 3개(v0.11, v0.16, v0.31). 30분 사이에도 v0.27~v0.32가 다섯 세션에서 올라왔다. 겹침 자체는 다음 푸시가 정리하지만, 캐시 갱신(`?v=`)이 같은 번호로 두 번 나가면 휴대폰이 옛 파일을 계속 쓸 수 있다(v0.17이 이 문제로 따로 나간 적 있음).
- **버전 단위·푸시 (2026-11-12 확정)**: 올림은 **0.01**. 푸시 전 원격 `GAME_VERSION`을 확인한 뒤 bump한다. 번호가 겹치거나 푸시가 거절되면, 뒤에 푸시하는 세션이 원격 버전을 받고 **다시 +0.01** 해서 올린다(`docs/구현_대기목록.md` §0-3, `tools/bump_version.py`).
- **충돌이 몰리는 파일**: 빌드 결과물 `dist/game.js`(모든 커밋이 바꿈), `index.html`·`js/data.js`의 버전 줄, `tools/build.sh`의 파일 목록. 기능 코드보다 이 네 곳에서 충돌이 훨씬 자주 난다.
- **연기 시험 결과(v0.32)**: 새 게임 → 프롤로그 → 시험 → 지도 → 시트 탭 8개 → 도시·시설 → 걷기 → 게이트 층 지도 끝까지 → 3년 진행 → 저장·이어하기 → 20년 진행. **17개 단계 모두 통과, 페이지 오류 0건.**
- 도구를 만드는 동안 실패처럼 보인 2건은 도구 쪽 문제였다(프롤로그가 판정 화면 없이 바로 시험으로 넘어가는 바뀐 흐름, 게이트가 층 지도부터 시작하는 v0.25 흐름). 화면 흐름이 계속 바뀌므로 **도구도 함께 고쳐 가야 한다.**

## 2. 추천

### 1. 올리기 전 연기 시험 — 바로 적용
- **연기 시험(`node tools/smoke_test.js`)은 사용자가 따로 하라고 할 때까지 돌리지 않는다**(사용자 결정, 2026-11-14). 평소 확인은 `bash tools/build.sh`(빌드 성공)까지. 사용자가 하라고 하면 `bash tools/build.sh && node tools/smoke_test.js`를 돌린다(실패하면 종료 코드 1).
- 자기 영역의 새 화면·흐름을 만들었으면 `tools/smoke_test.js`에 단계 하나를 더한다(각 단계는 독립적으로 시도하고 실패를 모아 보고하는 구조).
- 남의 기능이 실패하면 고치지 말고 커밋 메시지·보고에 적는다(그 영역 세션이 고친다).

### 2. 빌드 결과물을 저장소에서 빼고 배포 때 빌드 — **적용 완료 (v0.49 이후)**
- 충돌의 대부분은 `dist/` 때문이다. GitHub Actions로 푸시할 때마다 빌드해서 Pages에 배포하면, 세션들은 `js/`·`css/`만 올리면 된다.
- 필요한 것: `.github/workflows/pages.yml`(빌드 → Pages 배포) 추가, 저장소 설정에서 Pages 소스를 "GitHub Actions"로 바꾸기(사용자가 GitHub 화면에서 해야 함), `dist/`를 `.gitignore`.
- 효과: `dist/game.js` 충돌이 사라지고, 버전 줄 충돌만 남는다. 원하면 버전도 빌드 때 커밋 수로 자동 생성할 수 있다.
- 지금 구조를 바꾸면 모든 세션이 동시에 바뀐 규칙을 따라야 하므로, 한 번에 공지하고 바꾸는 게 좋다.

### 3. 영역 표시와 작은 커밋 — 이미 잘 되고 있음
- 커밋 제목 `vX.YYY: [영역] 내용` 규칙이 지켜지고 있다. 문제가 생겼을 때 어느 세션 변경인지 바로 찾을 수 있다.

### 4. 밸런스 회귀 확인
- C·E 영역은 수치를 바꾸므로 `node tools/balance_sim.js 4 70` 결과(등급 도달 나이, 수명 손상, NPC S급 비율)를 커밋 메시지나 보고에 한 줄 남기면, 다른 영역 변경이 밸런스를 흔들었을 때 비교할 기준이 생긴다.
