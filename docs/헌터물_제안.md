# 한국 헌터물 장르 요소 → 게이트 크로니클 적용 제안

> 조사 범위: 한국 웹소설·웹툰 헌터물(현대 판타지·게이트물·탑 등반물·회귀물) 공통 문법.
> 특정 작품의 고유 이름·캐릭터·설정은 쓰지 않고 장르 공통 요소만 다룬다.
> 기준 코드: 브랜치 `claude/happy-turing-czlfa3` v0.10.

## 1. 장르 공통 요소와 현재 반영 여부

| 요소 | 장르에서 흔한 모습 | 게임 현황 (코드 근거) |
|---|---|---|
| 각성 | 게이트 출현 뒤 일반인이 능력을 얻음 | **있음** – `prologue.js` 각성 프롤로그, 관리국 판정 |
| 재각성 | 최하급이 2차 각성으로 등급이 뒤집힘 | **없음** – 등급은 돌파로만 오름 |
| 등급 측정·재측정 | 측정기 수치, 재측정 때 "측정 불가" 연출 | **절반** – 첫 판정만 있음, 재측정 없음 |
| 상태창·시스템 메시지 | 주인공만 보이는 게임식 창, 일일 퀘스트·패널티 | **없음** (UI 스탯 창은 있으나 '시스템' 서사 없음) |
| 퀘스트·업적·칭호 | 업적 달성 → 칭호 → 소소한 보정치 | **없음** – `record` 집계만 있음 |
| 던전 브레이크 | 방치된 게이트가 넘쳐 도시 습격 | **있음** – 브레이크 사건 다수 |
| 레드 게이트 | 들어가면 못 나오는 고립 던전 | **절반** – `story_events.js` 1회성 사건뿐, 맵 게이트 종류 아님 |
| 이중 던전·숨은 방 | 클리어 뒤 숨겨진 2층·보스 | **없음** – `gateRooms()`는 고정 3~4방 |
| 길드 정치 | 대형 길드 간 게이트 독점·견제 | **절반** – 길드 가입·승급은 있음, 길드끼리 경쟁 없음 |
| 협회·국가 | 관리국, 국가 소집령, 청문회 | **있음** – KAMA, 소집·청문회 사건 |
| 해외 S급·국가 간 경쟁 | 해외 길드 영입, 국제 공동 토벌 | **약함** – 영입 제안 사건 1개 |
| 회귀·환생 | 죽음 뒤 과거로, 기억 들고 재시작 | **없음** – `gameOver()`가 세이브를 지움 |
| 숨겨진 직업 | 조건 충족 시 히든 클래스 | **있음** – `data_classes.js` 히든 직업, 기연 연쇄 |
| 아이템 등급 | 일반~전설~신화, 세트·고유 효과 | **절반** – 4등급 배율만, 고유 효과 없음 |
| 스킬 각성·숙련 | 많이 쓴 스킬이 진화 | **없음** – 스킬은 사서 쓰고 성장 없음 |
| 그림자 군단류 소환 | 쓰러뜨린 적을 부하로 영구 보유 | **약함** – 소환은 전투 중 임시 소환수뿐 |
| 탑 등반 | 층마다 시험, 층수가 곧 랭킹 | **없음** |
| 성좌·후원자 | 초월 존재가 지켜보며 후원·간섭 | **없음** (`voice` 연쇄가 비슷한 결) |
| 방송·평판 | 공략 중계, 여론, 인기 헌터 | **절반** – 명성 수치·인터뷰 사건만 |
| 마석 경제 | 마석·코어가 에너지 자원, 시세 변동 | **절반** – 괴수 코어·크레딧·경매장, 시세 없음 |
| 랭킹 | 국내·세계 헌터 랭킹 | **약함** – 소문 문구 1줄 |

## 2. 우선순위 제안 (상위 10개)

### 1. 칭호·업적 시스템 — 난이도 하
- **장르**: 특정 행동 누적 시 "〇〇 학살자" 같은 칭호, 장착하면 소소한 보정.
- **방식**: `data.js`에 `TITLES` 표(조건은 `player.record`·플래그 검사). `game.js`의 월 정산/전투 종료에서 판정, 칭호 1개 장착 → `recalc()`의 `mod()`에 합산. NPC 대사·소문에 칭호 노출.
- **재미**: 샌드박스에 목표 거리를 깔아 줌. 이미 쌓는 `record`(gates·kills·fails 등)를 그대로 재사용.

### 2. 등급 재측정과 재각성 — 난이도 중
- **장르**: 최하급 판정자가 재측정에서 판정이 뒤집히거나 "측정 불가"가 뜨는 명장면.
- **방식**: 관리국(`board` 또는 KAMA 지역)에서 유료 재측정. 실제 전투력(`rankIdx`·stage·유물)과 '공식 등급'을 분리해 `player.officialRank` 추가. 낮게 등록된 채 숨기면 의뢰 보상↓·기습 확률↑, 재측정하면 명성 급등. 낮은 확률의 재각성 사건(`story_events.js`)으로 재능·속성 재판정.
- **재미**: "공식 등급 vs 진짜 실력" 갭이 주는 통쾌함. 숨길지 드러낼지 선택이 생김.

### 3. 게이트 변이: 레드 게이트·이중 던전 — 난이도 중
- **장르**: 입장 후 탈출 불가(레드), 보스 처치 뒤 숨은 층(이중 던전), 등급 오판 게이트.
- **방식**: `spawnMonthly()`에서 게이트에 `variant` 부여(`red`/`double`/`misrank`). `gateRooms()`에서 레드는 도주 불가·방 수 증가, 이중은 클리어 뒤 확률로 숨은 방 추가, 오판은 표기 tier보다 +1~2. 지도 아이콘 색만 바꾸면 UI 부담 작음.
- **재미**: 반복 게이트에 긴장감과 변수. ATB 파티 운영(자원 관리)이 중요해짐.

### 4. 마석 시세와 경제 — 난이도 중
- **장르**: 괴수 코어가 발전 연료·산업 자원, 등급별 시세가 오르내림.
- **방식**: 기존 괴수 코어에 등급별 시세표를 두고 `advanceMonth()`에서 변동(브레이크 다발 → 공급↑ 가격↓, 정전 사건 → 가격↑). `market`에서 판매 시 시세 반영. 길드에 납품 계약 의뢰.
- **재미**: 전투 외 수익 판단(지금 팔까 쟁일까), 세계 사건과 경제 연결.

### 5. 스킬 숙련과 스킬 각성 — 난이도 중
- **장르**: 반복 사용한 스킬이 레벨업하다 상위 스킬로 진화.
- **방식**: `combat.js`에서 스킬 사용 횟수 집계 → `player.skillXp[id]`. 단계마다 위력·MP 효율 상승, 최종 단계에서 직업별 변형(전체화·추가 효과). `grantClassSkills()` 옆에 진화 표.
- **재미**: 내가 자주 쓰는 스킬이 나만의 기술로 자라는 손맛. 전투가 곧 성장.

### 6. 회귀(뉴 게임+) — 난이도 중
- **장르**: 죽거나 세계가 멸망한 뒤 과거로 돌아가 기억과 일부 능력을 들고 재시작.
- **방식**: `gameOver()`에서 세이브를 지우기 전에 '회귀 데이터'(최고 등급, 본 사건 id, 칭호 일부)를 별도 키로 보관. 새 게임에서 "회귀자" 배경 선택 시 미래 사건 예고(소문 미리보기), 히든 기연 힌트, 작은 스탯 보너스. 회귀 횟수에 따라 세계가 미묘하게 변화.
- **재미**: 귀곡팔황식 반복 플레이의 이유. 이전 생 지식으로 기연을 선점하는 쾌감.

### 7. 길드 세력 경쟁·게이트 입찰 — 난이도 중~상
- **장르**: 대형 길드가 고등급 게이트 공략권을 경매·독점, 중소 길드와 마찰.
- **방식**: `society.js`에 길드 세력치(인원·S급 수·자금)를 두고 월마다 고등급 게이트를 각 길드가 입찰. 플레이어 길드는 입찰 참여·방해·하청. 세력 순위 변동을 뉴스 전광판(`arrive_news`)에 노출.
- **재미**: 협회·길드 설정이 살아 움직임. 소속 길드의 흥망이 내 이야기가 됨.

### 8. 헌터 랭킹과 방송·여론 — 난이도 하~중
- **장르**: 국내·세계 랭킹, 공략 중계와 인기, 악플·논란.
- **방식**: NPC·플레이어 점수로 월간 랭킹 화면(`ui_town.js` 의뢰소 탭). 게이트 입장 전 '중계 허용' 토글 → 성공 시 명성·후원금 증가, 실패·도주 시 여론 악화. 기존 인터뷰·다큐 사건을 랭킹과 연동.
- **재미**: 수치 성장이 사회적 위상으로 보임. NPC 라이벌과 순위 다툼.

### 9. 후원자(이계 존재의 계약) — 난이도 중
- **장르**: 초월적 존재가 헌터를 지켜보며 행동에 반응해 보상·시련을 줌.
- **방식**: 새 연쇄(`story_chains.js`)로 이계 종족(`RACES`) 출신 후원자 3~4종 중 하나와 계약. 후원자별 취향(잔혹함·자비·탐험 등)에 맞는 행동을 하면 호감 → 축복(스탯·전용 스킬), 거스르면 시련 사건. 기존 '목소리' 연쇄와 세계관 결이 맞음.
- **재미**: 같은 행동에도 반응하는 관객이 생겨 선택에 무게. 연출만으로도 장르 맛이 큼.

### 10. 탑(층계 도전 게이트) — 난이도 중
- **장르**: 층마다 다른 시험, 몇 층까지 올랐는지가 곧 실력 증명.
- **방식**: 특정 지역에 상설 '탑' 오브젝트. 층마다 `gateRooms()` 변형(제한 인원·속성 고정·보스 연전), 10층 단위 보상(유물·촉매). 도달 층은 랭킹(8번)·칭호(1번)와 연결.
- **재미**: 샌드박스에 끝없는 수직 목표. 파티 구성 실험의 무대.

## 3. 후순위 아이디어
- **영구 소환 부하**: 강령술사·조련사가 처치한 보스를 영구 부하로 등록(`combat.js` 소환수 확장). 재미는 크나 밸런스 부담 → 상.
- **아이템 고유 효과·세트**: `RARITY`에 '신화' 추가, 전설 이상에 고유 패시브. 난이도 중.
- **국제 공동 토벌**: 해외 S급 NPC가 등장하는 대형 레이드 사건. 난이도 중.
- **일일 수련 퀘스트(패널티 포함)**: 상태창식 매일 과제. 모바일 접속 동기 부여에 좋지만 샌드박스 시간 흐름과 충돌 가능 → 월 단위 과제로 변형 권장.

## 4. 추천 구현 순서
1. 칭호·업적 (하) → 2. 게이트 변이 (중) → 3. 재측정·공식 등급 (중) → 4. 랭킹·방송 (하~중)
→ 5. 스킬 숙련 → 6. 마석 시세 → 7. 회귀 → 8. 탑 → 9. 후원자 → 10. 길드 경쟁

앞 4개는 기존 데이터(`record`, 명성, 게이트 생성, 관리국 판정)를 재사용해 비용 대비 체감이 가장 크다.
