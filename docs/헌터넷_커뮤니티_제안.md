# 헌터넷 커뮤니티: 게시글·댓글 반응 제안

> 한국 헌터물의 단골 장면: 주인공이 뭔가 해내면 다음 회차에 **커뮤니티 반응**이 나온다(헌터 갤러리 글, "ㄹㅇ 미쳤다", "주작 아님?", 닉네임 공방, 추천수 폭발, 짤). 독자는 이걸로 세상이 주인공을 어떻게 보는지 체감한다.
> 기준 코드: s2 v0.16x 무렵. 조사 문서이며 코드는 고치지 않았다.

## 1. 지금
- 소문(`rumor`)이 뉴스 편집(`news.js`)을 거쳐 **속보 1건 · 헤드라인 3~5건 · "헌터 커뮤니티 소문" 목록**으로 나온다. 모두 **한 줄 서술문**("○○ 파티가 귀환석으로 생환했다")이다.
- 댓글·커뮤니티 표현은 사건 안 문장에 흩어져 있다(`"쫄았네 ㅋㅋ" 댓글이 달렸다`, `짤이 온 커뮤니티를…`). 플레이어가 **글과 댓글을 직접 보는 화면은 없다.**
- 여론 수치(`public_order.js`), 여론 수치는 있으나 "사람들이 뭐라고 하는지"는 보이지 않는다.

## 2. 제안: 헌터넷 화면 (휴대폰 앱처럼) — 영역 C

### 1. 게시판 화면 — 난이도 중
- 지도 화면의 휴대폰 아이콘 → **헌터넷** 앱. 탭: 실시간 인기 / 헌터 갤러리(잡담) / 공략·정보 / 길드 / 사건사고.
- 게시글 = 제목 + 닉네임 + 시간 + 추천·댓글 수, 누르면 본문과 **댓글 5~10개**.
- 글은 매달 소문·뉴스에서 자동 생성: 중요 소문 하나가 글 하나(+ 반응 댓글). 플레이어가 언급된 글은 맨 위 고정·강조.

### 2. 댓글 반응 생성 — 난이도 중(데이터)
- 댓글은 **반응 유형 × 사건 종류** 템플릿 조합: 감탄("ㄹㅇ 미쳤다"), 의심("주작 아님? 영상 원본 내놔"), 시기("F급 출신이 운빨이지"), 정보("그 게이트 3층 함정 있음"), 드립("이 정도면 게이트가 쫄아서 닫힌 듯"), 팬("○○ 헌터님 결혼해 주세요"), 안티, 길드 신도("현무 형님들은 이 정도 기본임"), 관리국 비판, 아재("우리 땐 말이야"), 질문.
- 반응 비율은 **여론·명성·등급·소속**으로 정한다: 명성·여론이 좋으면 감탄·팬 ↑, 최근 논란 사건(강행·동료 희생·비리)이 있으면 의심·안티 ↑, 낮은 등급이 큰일을 하면 의심·시기 ↑("측정 오류 아님?") — 등급 오측정(misrank)·재측정과 연결.
- 닉네임 생성기(헌터넷 말투: "게이트청소부", "D급인생", "백호빠", "관리국9급", "ㅇㅇ(118.xxx)" 익명).
- 추천·비추 수, 베스트 댓글(추천 1위), 댓글끼리 싸움(대댓글 2~3단).

### 3. 플레이어 참여 — 난이도 중
- **글쓰기(선택지형)**: 해명·자랑·공략 공개·모집·저격. 결과로 여론·이미지·명성 변화, 저격은 라이벌 관계·고소 사건.
- **공략 정보 판매**(3차 후순위, `origin.js`)를 공략 게시판 글로: 유료 글 조회수 = 수입.
- **신고·고소**: 악플이 심하면 관리국 신고·고소 → 합의금 사건(돈·명성).
- 익명 부계정으로 몰래 쓰기(들키면 큰 논란 뉴스).

### 4. NPC와 세계 연결 — 난이도 하
- NPC 헌터도 글을 쓴다(성격 50종·인물 유형 맞춤: 방송 헌터는 홍보 글, 빌런 헌터는 도발 글, 정보상은 떡밥 글, 라이벌 동기는 플레이어 저격 글).
- 음모·음해(`conspiracy.js`)가 커뮤니티 여론 조작으로 보인다: 갑자기 같은 말투 댓글이 몰림 → 단서. 
- 브레이크·재앙 때 **실시간 글**(현장 목격 글, "지금 ○○역 근처 사람 있음?") → 속보보다 먼저 정보를 얻는 길.

### 5. 회차 끝 반응 연출 — 난이도 하
- 게이트 클리어·승급·대회 우승·판정 결과 뒤 **"헌터넷 반응" 카드**(인기 글 1개 + 베스트 댓글 3개)를 짧게 띄운다. 헌터물의 "커뮤니티 반응 회차" 맛. 설정에서 끌 수 있게.

## 3. 추천 순서
5(반응 카드) → 2(댓글 생성) → 1(게시판 화면) → 4(NPC 글·음모) → 3(플레이어 글쓰기)
- 5와 2만으로도 "세상이 나를 본다"는 체감이 바로 생긴다.

> 주의(사용자 결정): 방송·광고·예능 콘텐츠는 삭제됨(넣지 않음). 헌터넷은 방송 기능 없이 글·댓글만. 플레이어 방송·후원·광고 연동 넣지 말 것.
