# 전투 화면 점검 2: "버그처럼 보이는" 순간들

> 사용자가 연달아 지적한 유형(1프레임 만에 튀는 표시, 겹치는 말풍선·태그)을 직접 찾았다. Pixel 7 크기에서 4인 파티 vs 적 5마리 자동 전투를 0.25초 간격으로 기록하고 화면을 캡처했다.
> 기준: s2 v0.310. 조사 문서이며 코드는 고치지 않았다. 페이지 오류 0건, 화면 넘침 4px.

## 찾은 것 (눈에 띄는 순)

1. **명령 버튼 위에 상태 알약이 겹친다**: "차례 대기 중 · 행동 게이지가 차면 내 차례", "자동 전투 중" 알약이 공격·스킬·아이템·방어 버튼 한가운데를 가로질러 글자를 가린다. → 알약은 버튼 영역 위쪽 경계선에 붙이거나, 대기 중엔 버튼 자체를 흐리게 하고 알약은 전장 하단 가장자리에.
2. **피해·상태 숫자가 한 자리에 겹쳐 읽을 수 없다**: 같은 대상에 "74"(흐림) 위에 "20" + 입자, 내 카드에 "치명 20" 큰 글자 위에 "4"와 상태 배지 "화", 회복 때 "MP"와 "11"이 겹침. → 떠오르는 글자는 대상별로 **차례로 쌓기**(직전 글자가 있으면 위로 밀어 올리거나 0.15초 늦춰 옆으로), "MP +11"처럼 한 덩어리로, 동시 최대 3개.
3. **흐린 큰 글자가 전장에 남는다**: "약자 사냥", "급소 추적"(패시브·특성 발동 이름)과 "치명 20"이 반투명 큰 글자로 전장·아군 줄 위에 떠 있어 배경 얼룩처럼 보인다. 누구의 무엇인지 알 수 없다. → 발동한 유닛 머리 위 작은 태그로, 0.8초 뒤 사라지게.
4. **적 줄 맞춤이 어긋난다**: 적 크기가 달라(큰 원·작은 원) 체력 막대·이름 높이가 제각각(이름 기준선이 최대 20px 차이). 한 마리만 윗줄에 덩그러니 있고 아래 줄에 넷. → 줄마다 아래 기준선 정렬(원 크기가 달라도 막대·이름은 같은 높이), 5마리면 2+3 또는 3+2로.
5. **죽은 적의 유령이 자리를 차지한다**: 쓰러진 적이 흐린 실루엣과 빈 막대로 끝까지 남아, 마지막 한 마리가 구석에 치우쳐 있다. → 쓰러지고 1초 뒤 사라지고 남은 적이 부드럽게 가운데로 모이게(재배치는 4-? 분열 연출의 이동 방식과 같이).
6. **적 위 표시가 서로 겹친다**: 행동 예고 알약(화살표+대상 초상)이 약점 태그("흡")와 괴수 그림 윗부분을 덮는다. "낙" 같은 상태 배지는 그림 왼쪽 아래에 따로. → 적 카드의 표시 자리 규칙: 왼쪽 위 = 유형/약점, 오른쪽 위 = 행동 예고, 아래 = 상태 이상 줄, 점선 끝 = 오더 태그.
7. **상태 태그가 생길 때 줄이 밀린다**: "방↓" 태그가 이름 아래에 새 줄로 끼어들어 그 순간 화면이 밀린다(레이아웃 이동 측정에서 원인 요소로 잡힘). → 태그 자리를 미리 확보(빈 줄 고정 높이)하거나 그림 위에 겹쳐 표시.
8. **"전투 개시" 띠가 적 줄 한가운데를 가린다**: 가운데 두 마리가 띠에 가려 처음에 적 구성이 안 보인다. → 띠는 전장 위쪽 빈 곳에, 또는 적 등장 연출 뒤 0.6초만.
9. **아군 줄이 왼쪽으로 쏠린다**: 전열 2·후열 2가 왼쪽~가운데에 있고 오른쪽 절반이 비어 있다. → 가운데 정렬.

## 확인된 정상
- 전투 중 페이지 오류 없음, 전투 한 화면 유지(넘침 4px), 승리 도장은 이번 전투(소환물 없음)에서는 결과와 일치.

## 제안
- 1·2·3·5·7을 먼저(가장 "버그처럼" 보임). 영역 B.
- smoke_test에 전투 캡처 자동 점검을 조금 더: "떠오르는 글자 영역이 서로 겹치면 경고", "명령 버튼과 겹치는 고정 요소가 있으면 실패".
