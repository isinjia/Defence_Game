# 월드맵 퀘스트 안내 경로

2026-11-13 사용자 요청: 메인 퀘스트나 추적 중인 퀘스트의 목적지까지 참고 화면처럼 노란 경로를 표시한다.

## 사용

- 진행 가능한 메인 퀘스트의 목적지를 기본으로 안내한다. 월드맵을 누르거나 마우스를 올려두지 않아도 노란 선과 목적지 테두리가 유지된다.
- 현재 퀘스트 목록 또는 의뢰 탭의 **추적** 버튼으로 안내 대상을 바꾼다. 추적 중인 의뢰가 메인보다 우선한다. 추적 중 버튼을 다시 누르면 메인 안내로 돌아간다.
- 이동하면 현재 위치에서 남은 경로를 갱신한다. 추적 대상을 바꿔도 현재 이동을 중단하거나 다른 곳으로 이동시키지 않는다.
- 추적 대상은 의뢰의 고유 ID로 저장한다. 의뢰 순서가 바뀌거나 저장을 불러와도 같은 의뢰를 안내한다.
- 완료 후 보고해야 하는 의뢰는 보고 장소로 경로가 바뀐다. 보고·만료 등으로 의뢰가 없어지면 메인 안내로 돌아간다. 끝난 메인 퀘스트의 경로는 지운다.
- 작은 모바일 화면에서는 HUD의 기존 표시·접기 규칙을 유지하고, 의뢰 탭에서도 모든 의뢰를 추적할 수 있다.

## 목적지와 표시

메인은 기존 메인 퀘스트의 실제 위치 조건을 사용한다. ‘아무 도시’는 육로로 갈 수 있는 가까운 도시를 안내한다. 현재 자리에서 진행 가능하거나 목적지가 없는 장면, 아직 대기 중인 장면에 임의의 목적지를 만들지 않는다.

운송·납품·보고는 해당 도시, 위치가 알려진 인물은 그 인물의 월드맵 위치를 안내한다. 토벌·게이트 의뢰는 발견한 적격 대상 중 가까운 곳을 안내한다. 해당 지역에서 아직 대상을 발견하지 못했다면 탐색 안내를 표시한다. 발견하지 않은 적의 좌표를 드러내지 않는다. 육로가 없거나 출입 자격이 부족하면 경로 대신 안내 문구를 표시한다.

노란 선은 지형·통행 자격을 지키는 기존 길찾기를 사용한다. 목적지에 노란 사각 테두리와 퀘스트 이름·예상 이동 시간을 표시한다. 시간은 도보 SPD·최소 7분 규칙과 차량 보정을 사용하는 기존 이동 계산과 같다. 경로는 위치나 대상이 바뀔 때 갱신하며 프레임마다 다시 길을 찾지 않는다.

## 구현·검증

- `js/quest_route.js`: 기존 함수 감싸기로 추적 UI·저장·목적지 선택·지도 안내를 확장한다. 안내 표시는 이동이나 퀘스트 진행을 실행하지 않는다.
- `css/quest_route.css`: 추적 버튼, 선택 상태와 모바일 목록 표시.
- `tools/quest_route_test.js`: PC 1280px, 모바일 390px·320px에서 실제 추적 버튼, 기본 메인 안내, 노란 선, 마우스 없는 지속 표시, 저장·불러오기, 완료 후 보고·메인 복귀, 출입 제한·미발견 대상, 이동 중 추적 변경과 경로 갱신을 검사한다.
- 명령: `bash tools/build.sh`, `node tools/quest_route_test.js`. 배포 검사는 `QUEST_ROUTE_TEST_URL`, 캡처 저장은 `QUEST_ROUTE_SCREENSHOTS` 환경 변수로 지정한다.

전용 검사: 1280px·390px·320px 모두 통과, 페이지 오류 0건. 전체 회귀 검사는 65/67이며 인물 정보 탭의 내용 길이 검사와 기존 게이트 자동 완주(`xr-map` 반복)가 미통과했다. 이 두 검사를 통과한 것으로 기록하지 않는다.
