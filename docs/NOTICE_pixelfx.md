# pixelfx 연출 고지

전투 스킬 연출의 일부는 [patch-gg/pixelfx](https://github.com/patch-gg/pixelfx) (MIT) 코어와
이펙트 모듈을 `js/vendor_pixelfx.js` 로 묶어 쓴다.

- 원작: Patch / pixelfx
- 일부 이펙트는 Hugo Duprez (Sprite Fusion) MIT 코드를 원저장소가 각색한 것
- 자세한 고지: 원저장소 `NOTICE.md`, `LICENSE`

재묶음: `node tools/bundle_pixelfx.mjs` (`PIXELFX_ROOT` 로 원본 경로 지정 가능)
