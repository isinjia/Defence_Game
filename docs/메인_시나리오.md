# 메인 시나리오 설계: 「원초의 문」 (영역 D)

사용자 결정: 메인 시나리오는 **장편소설 한 권 분량**으로 쓴다. 한 번 플레이에서 읽는 양은 약 25만 자(소설책 350~400쪽), 분기를 합친 전체는 35만~40만 자, 장면 500개 안팎이다.
이 문서는 줄거리, 장 목록, 엔딩, 구현 방식을 정한다. **줄거리와 결말 방향을 사용자가 확인한 뒤** 1장부터 쓴다.

---

## 0. 원칙

1. **등급이 곧 진도다.** 장은 등급과 최소 경과 개월로 열린다. 무작위로 뜨지 않는다. 열리면 퀘스트 목록 맨 위에 `메인 · ○장 「제목」 — 다음 할 일 · 장소`가 고정된다.
2. **샌드박스를 막지 않는다.** 메인은 언제든 미뤄 둘 수 있다. 미루면 세계가 먼저 움직인다(다른 헌터가 먼저 해결하거나, 재앙이 커지거나). 끝까지 안 하면 그것도 하나의 결말이 된다.
3. **이미 있는 것을 본편으로 끌어온다.** 균열교·제주의 목소리·피험자·북방 관측소·재앙 게이트 5종·히든 피스·라이벌·첫 팀·소꿉친구를 버리지 않고 메인 줄기에 엮는다. 무작위 연작이던 `cult`·`voice`는 메인으로 옮기고 무작위 목록에서 뺀다.
4. **사람이 남는다.** 각 장에는 중심 인물이 있고, 그 인물의 생사·관계·소속이 뒤의 장 대사를 바꾼다(죽은 동료는 다시 나오지 않고, 그 자리에 다른 말이 들어간다).
5. **역할 대칭을 지킨다.** 내가 팀원이면 메인 일정도 리더를 통해 간다(리더에게 "이건 우리 일이다"라고 제안 → 리더가 판단). 내가 리더면 내가 팀을 호출해 간다.
6. **한 장면 = 대화창 한 번.** 서술 3~6줄, 말하는 사람 2~4명, 선택지 2~3개. 한 장은 장면 8~10개, 그중 1~2개가 전투(이야기 전투 또는 메인 게이트).

## 1. 감춰진 진실 (플레이어가 단계적으로 알게 되는 것)

- **2067년, 대붕괴.** 20년 전 제주에서 관리국 산하 연구팀이 '공명 실험'을 했다. 목적은 에테르 신호 너머의 무언가와 '대화'하는 것. 실험 책임자는 수석 연구원 **진서해**(훗날의 '무명').
- **문은 우리가 열었다.** 실험은 성공했다. 반대편에도 사람이 있었다. 그런데 열린 틈으로 에테르가 쏟아졌고, 그 에테르가 한반도 곳곳에 작은 게이트들을 찢어 냈다. 그게 대붕괴다. 각성자는 그 에테르에 적응한 사람들이다.
- **반대편 '저편'.** 저편은 에테르가 바닥나 죽어 가는 세계다. 저편의 '파수인' **아린**은 문을 처음 연 순간 건너와 "닫아 달라"고 울었던 사람이다(목소리 연작의 노인이 본 사람). 아린은 지금도 문 안쪽에 갇혀 꿈으로 각성자들에게 말을 건다.
- **심연의 군주.** 원초의 게이트를 지키는 최종 보스는 괴수가 아니라, 저편이 마지막 에테르를 모아 만든 '문지기 장치'가 괴수화한 것이다. 문을 붙잡고 있는 건 그것이다. 북방 관측소는 북쪽 봉쇄선으로 흘러드는 에테르가 군주를 먹여 살린다는 걸 알아냈다.
- **관리국의 은폐.** 국장 **마도현**은 실험의 공동 책임자였다. 진실이 알려지면 정부가 무너진다고 보고 '자연재해'로 덮었다. 피험자 실험(강제 각성)도 '문을 닫을 열쇠'를 만들려는 관리국의 비밀 계획이었다.
- **무명의 목적.** 진서해는 실험이 낳은 죽음을 속죄하려다 결론을 뒤집었다. 각성하지 못한 사람들(대다수)은 게이트 시대에 버려졌다. 문을 **완전히 열면** 모두가 각성할 수 있다고 믿는다. 균열교는 그 믿음을 비각성자들에게 판다. 그 대가로 한반도가 저편처럼 될 수 있다는 건 말하지 않는다.
- **주인공이 '열쇠'인 이유.** 주인공은 대붕괴 날 제주의 에테르가 처음 닿은 세대이고, 각성할 때 그 공명이 남았다(프롤로그의 각성 장면이 그 흔적). 아린의 목소리가 들리는 건 그래서다. 출신에 따라 이유가 하나 더 붙는다(피험자 출신: 관리국의 성공작 / 고아원 출신: 실험 연구원의 아이 / 재벌가: 실험 자금을 댄 집안 등).

## 4. 세계가 먼저 움직이는 규칙 (미뤄 둘 때)

- 각 부에는 **세계 시계**가 있다. 플레이어가 그 부를 열고 나서 일정 기간(예: 2부 18개월) 안에 끝내지 않으면, 그 부의 사건을 다른 헌터가 처리한다.
- 결과는 남는다. 예: 13장을 넘기면 친구는 균열교 의식에서 각성하거나 죽는다. 32장을 넘기면 진서해가 해협 의식을 성공시켜 원초의 게이트가 더 강해진다(최종 보스 강화).
- 재앙 게이트는 기존 calamity 규칙(6개월 지속, 실패 시 지역 상처)을 그대로 쓰되, 메인 장과 맞물리면 대사가 붙는다.

## 6. 구현 방식

- **새 파일**
  - `js/main_story.js`: 장 정의, 진행, 퀘스트 줄, 세계 시계, 엔딩 판정.
  - `js/main_ch1.js` … : 부마다 한 파일. 장면 데이터만 둔다.
- **장 데이터 형식**
  ```js
  MAIN.ch(5, { part: 1, title: '남은 사람들', rank: 1, after: { ch: 4, months: 0 }, where: 'gangbuk',
    goal: '강북 폐구의 생존자 쉼터에 간다',
    scenes: [ { lines: [ { narr }, { who: 'leader', text }, ... ], choices: [ { text, flag, go: 'next' | sceneId, fight? } ] }, ... ],
    done: (g) => {...} })
  ```
  - `who`에는 `'leader' | 'friend' | 'rival' | 'mumyeong' | 'arin' | 'seoyun' | NPC id`를 쓴다. 실제 NPC로 풀고, 죽었으면 `alt` 줄을 쓴다.
  - 대사는 대화창(`UI.talk`)으로 나온다. 서술, 말하는 사람, 선택지, 무리 대사를 쓴다.
- **진행 규칙**
  - 장은 조건(등급·앞 장·개월)을 채우면 열린다.
  - 열린 장은 장소에 가면 시작한다. 장소가 '어디서나'면 다음 날 바로 시작한다.
  - 장 하나는 한 번에 끝까지 가지 않아도 된다. 장면 사이에 "○○로 가라"가 있으면 이동한다.
- **저장**: `G.flags.main = { ch, scene, done: {}, flags: {}, clock: {} }`.
- **화면**
  - 퀘스트 목록 맨 위 메인 줄, 누르면 장소로 이동한다.
  - 정보 탭에 '메인 이야기' 기록(지나온 장 제목과 내 선택 한 줄)을 둔다.

### 장면 밀도

- **오늘은 여기까지**: 장면에 `pause`를 두면 정해진 날수만큼 멈춘다. `pause: '문구'`면 1일, `pause: { days, label, text }`면 그 날수. 퀘스트 줄에 "내일 이어짐 / N일 뒤 · 목요일 이어짐"처럼 남은 대기가 뜬다. 1부: 1장 점심 뒤 1일 · 2장 연희 대화 뒤 7일(목요일) · 3장 미룸 7일(목요일) · 4장 보름 전 10일(보름 밤).
  - 1장: 점심 뒤에 멈춘다.
  - 2장: 연희와 대화한 뒤 다음 목요일까지 멈춘다.
  - 3장: 미룬 경우 다음 목요일까지 멈춘다.
  - 4장: 보름 전 열흘 뒤에 멈춘다.
- **역할 대칭**: NPC 리더 팀의 팀원이면 2·3장에 들어가기 전에 리더 반응 장면이 한 번 있다(동행·말림·묵인). 3장은 리더 말을 듣고 한 주 미룰 수도 있다.
- **장면 수(실측)**: 1장 7(한 번에 6~7) · 2장 8(팀원이 아니면 7) · 3장 9(팀원·미룸이 아니면 6~7) · 4장 10(출구 갈래 포함, 한 번에 6~7) · 5장 7(한 번에 3) · 6장 3 · 7장 2 · 8장 3.
