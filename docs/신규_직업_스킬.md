# 신규 직업·스킬 데이터 (4-10, 사용자 요청 "스킬은 다 만들어 놓자")

> 속성 키는 4-9 기준: fire(염) · bolt(뇌) · water(수) · wood(목) · holy(성) · dark(암).
> 형식은 `js/data_classes.js` 그대로: 스킬 `[이름, 종류, 위력, 정신력, 설명, 속성]`. 6번째 칸 `elem`은 이미 SKILLS 등록 코드가 읽는다(`s[5]`). 직업에는 `elem`(친화 속성)을 새로 단다.
> 스킬 종류는 지금 전투가 아는 것만 썼다: dmg·aoe·pierce·multi·crit·stun·dot·drain·debuff·buff·buff_all·shield·shield_all·heal·heal_ally·heal_all·revive·summon·taunt·evade.
> 위력·정신력은 같은 희귀도의 기존 직업과 비슷한 범위(1번 10~18 / 2번 20~30 / 3번 45~60)로 맞췄다. 밸런스는 G가 balance_sim으로 확인.
> 담당: G가 `CLASSES`에 붙여 넣고 elem 처리. D는 프롤로그에서 이 id를 쓴다.

## 2. 기존 직업 친화 속성과 스킬 속성

4속성마다 친화 직업 4개 이상이 되게 배정했다. 스킬 속성은 기존 스킬의 6번째 칸에 넣는다(없는 스킬은 그대로 무속성 = 무기 속성).

| 직업 | elem | 스킬 속성(1·2·3번) | 이유 |
|---|---|---|---|
| 검사 | 없음(각성 속성 따름) | — | 표준 |
| 광전사 | fire | fire·—·fire | 분노 |
| 창술사 | bolt | bolt·—·bolt | 찌르기·관통 |
| 무도가 | 없음(각성 속성 따름) | — | 기공 |
| 쌍검사 | bolt | bolt·bolt·— | 속도 |
| 방패 기사 | 없음 | — | |
| 성기사 | holy | holy·holy·holy | 빛 |
| 거인화 능력자 | wood | —·—·wood | 대지·거목 |
| 암살자 | dark | dark·—·dark | 그림자 |
| 도적 | 없음 | — | |
| 독술사 | wood | wood·wood·wood | 독초 |
| 궁수 | wood | —·wood·— | 숲의 사냥꾼 |
| 저격수 | water | —·—·water | 냉정 |
| 총잡이 | bolt | bolt·—·bolt | 전기 탄 |
| 원소술사 | 각성 속성(염·뇌·수·목 중) | self·self·self | 원소 |
| 흑마법사 | dark | dark·dark·dark | |

| 사령술사 | dark | dark·dark·dark | 이름 유지(사용자 결정) |

| 도사 | water | water·—·fire | 부적과 물 |

**4속성 친화 직업 수**: 염 3(광전사·검무사·원소술사) + 각성 따름 직업들, 뇌 5(창술사·쌍검사·총잡이·순간이동자·원소술사), 수 5(저격수·결계사·음유시인·도사·원소술사), 목 8(신규 4 + 거인화·독술사·궁수·조련사·연금술사). 염이 적으므로 G가 검사·무도가의 기본 elem을 fire로 두거나, 새 염 직업(예: 화염 투사)을 하나 더 넣을지 판단.

## 3. 각성 비율 확인 기준
- 각성 결과 직업의 성 친화 10~15%, 암 친화 10~15%(4-10).
- 새 직업의 희귀도: r0 4개(승려·수도사·저주술사·주술사), r1 6개, r2 2개(성녀·수목 수호자). 기존 비율(70/25/5)에 맞는 수준.
