# 탐색 UI 개선안과 화면 용어

작성: 2026-11-13. **용어 정의는 사용자 확정**, 아래 UI 개선 내용은 제안 단계다. 문서 등록은 구현 승인이나 게임 적용 완료를 뜻하지 않는다.

## 화면 용어 — 사용자 확정

| 용어 | 정의 | 범위 |
|---|---|---|
| 탐색 | 게이트에 들어간 뒤 길을 선택하는 화면 | 현재 위치, 경로 분기, 전투·사건·휴식·보물·보스 지점, 경로 선택 |
| 월드맵 | 현재의 타일 기반 이동 화면 | 타일 지형, 도시·게이트 위치, 월드 이동 |

앞으로 대화·기획 문서에서 두 화면을 구분한다. 게이트 경로 화면을 월드맵이라고 부르지 않는다. 기존 코드의 `map`, `explore` 같은 식별자를 일괄 변경한다는 뜻은 아니다.

## 탐색 개선 목적

사용자 의견: 아이콘·캐릭터·UI가 너무 작고 레이아웃도 좋지 않다.

현재 코드 기준 시험 탐색의 캐릭터 초상은 26px, 일반 지점은 기본 42px·낮은 화면에서 36px, 내부 아이콘은 22px다. 현재 위치와 다음 선택 지점이 먼저 읽히도록 크기와 정보 배치를 조정하는 방향을 제안한다. 아래 수치는 CSS 픽셀 기준의 시안 목표이며 실제 화면에서 검토 후 확정한다.

## 탐색 개선 제안 — 미구현

| 요소 | 제안 |
|---|---|
| 캐릭터 | 지도 위 초상을 48~56px로 확대하고 현재 위치에 이름과 진행 방향 표시 |
| 탐색 지점 | 일반 60~64px, 보스 76~80px, 내부 아이콘 30~36px |
| 경로 배치 | 현재 위치와 다음 갈림길을 크게 표시하고 전체 경로는 축소 보기로 확인 |
| 상단 정보 | 장소·층수 한 줄, 체력·정신력 게이지 한 줄로 정리 |
| 파티 상태 | 하단에 동료 초상을 배치하고 누르면 상태 확인 |
| 하단 조작 | 선택한 장소의 설명·위험·예상 보상·행동 버튼을 고정 배치 |
| 글자·버튼 | 본문 15~16px, 지점 이름 13~14px, 주요 버튼 높이 52px 이상 |
| 상태 구분 | 선택 가능한 경로는 굵고 밝게, 지나온 길은 흐리게 표시. 색·기호·문구를 함께 사용 |

### 화면 배치 초안

```text
[ 장소 · 층수                         메뉴 ]
[ 체력 게이지             정신력 게이지 ]

           다음 탐색 지점
        [전투]         [사건]
             ╲       ╱
             현재 캐릭터
               [초상]

                         [전체 경로 보기]

[ 동료 초상    동료 초상    동료 초상 ]
[ 선택한 장소 · 설명 · 위험 · 예상 보상 ]
[            상황에 맞는 행동 버튼       ]
```

지점을 선택하면 하단에서 정보를 확인한 뒤 실행한다. 시험처럼 리더를 따르는 상황은 기존 역할을 유지하고 ‘리더 선택’·‘의견 내기’로 표시한다. 이 개선으로 리더 권한이나 경로 결정 규칙을 바꾸지 않는다.

## 월드맵과의 구분

위 경로·지점 확대 및 선택 정보 배치는 **탐색 개선 제안**이다. 월드맵의 타일 배치·확대율·이동 UI는 별도 안건으로 다룬다. 앞서 언급한 월드맵의 현재 위치 주변 확대와 선택 시 하단 상세 정보 표시도 검토 아이디어이며 확정 사항이 아니다.

## 후속 검토

1. 탐색 화면 시안을 먼저 제작해 크기·구도 확인.
2. 320px·390px 너비 및 낮은 화면에서 지점 겹침, 이름 가독성, 하단 버튼 접근성 확인.
3. 사용자 시안 확인 후 구현·적용. 월드맵 개선은 별도로 검토.

관련 코드: `js/tutorial_map.js`, `js/gate_run.js`, `css/explore_view.css`, `css/style.css`.
