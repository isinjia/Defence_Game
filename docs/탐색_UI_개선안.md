# 탐색 UI 개선 — 2안

사용자가 2026-11-13 모바일·PC 시안과 갈림길 3개 배치를 확인한 뒤 **2안으로 전체 수정**을 승인했다. 화면 용어는 [용어집](용어집.md)을 따른다. 대상은 게이트 내부의 길 선택인 **탐색**이며, 타일 기반 월드맵과 구분한다.

## 확정 구성

- PC: 왼쪽 전체 경로·현재 위치, 가운데 큰 목적지 카드, 오른쪽 장소 상세·이동 버튼의 3열.
- 모바일: 현재 위치와 정찰 안내 아래에 큰 썸네일·이름·설명을 묶은 세로 목록. 하단 이동 버튼 고정.
- 작은 PC·태블릿: 경로는 ‘전체 경로 보기’로 열고 목적지와 상세 영역을 확보한다.
- 선택지 1~3개는 PC에서 가로 배치, 4개는 2×2. 모바일은 개수와 관계없이 세로 목록이며 본문만 스크롤한다.
- 전체 경로는 기존 지도·연결선·추격대·다른 파티 표식을 유지한다. 경로 유형의 이름을 항상 표시하고 현재 위치·선택 지점을 강조한다.
- 모바일 전체 경로는 닫기 버튼과 Escape로 닫는다. 지점 정보를 선택하면 목적지 화면으로 돌아온다.

## 정보 선택과 이동

카드나 전체 경로의 이동 가능한 지점을 누르면 상세 정보만 선택한다. 하단의 ‘이 경로로 이동’을 눌러 기존 게이트 진행을 호출한다. 선택한 경로는 테두리·체크·문구로 표시하며 색에만 의존하지 않는다.

NPC 리더가 있으면 ‘이 경로로 의견 내기’로 기존 팀 상의에 전달한다. 리더 자동 결정·철수 제안·귀환석·추격대·다른 파티 처리 규칙은 기존 동작을 사용한다. 시험 탐색은 같은 레이아웃을 쓰되 이동 버튼은 리더 안내로 표시하며 직접 이동시키지 않는다.

## 정찰과 그림

미확인 경로는 실제 종류를 숨기고 공통 장소 그림과 물음표를 표시한다. 정찰한 지점은 기존 `GateScout.shown` 결과와 확신도를 그대로 사용하고, 낮은 확신도는 별도로 구분한다.

전투·정예는 기존 괴수 원화를 **장소 유형을 나타내는 일러스트**로 사용한다. 실제 출현 괴수의 이름을 미리 공개하지 않는다. 카드에 ‘등장 괴수 미확인’ 등을 표시하며 실제 종류와 보상은 진입 후 확인한다. 시험의 장소 종류는 기존 훈련 안내대로 표시한다.

휴식·보물·사건·보스는 기존 승인 장면 원화를 사용한다. 새 이미지 생성·편집 없이 밝은 바탕판·대비·글자 크기와 배치로 가시성을 높인다.

## 구현과 검증

- `js/exploration_cards.js`: 기존 일반·시험 탐색 렌더러를 감싸 목적지 카드·상세 정보·전체 경로로 재배치. 선택 상태는 저장 데이터에 추가하지 않는다.
- `css/exploration_cards.css`: PC·태블릿·모바일·낮은 가로 화면 배치.
- `tools/exploration_cards_test.js`: 경로 1~4개, 미확인 정보 보호, 정찰 확신도, 선택/이동 분리, 시험 권한, 전체 경로 열고 닫기, 오래된 화면의 실행 차단과 화면 크기별 배치.
- `tools/smoke_test.js`: 탐색에서 카드 선택 후 이동 확인을 거쳐 실제 게이트 진행·팀 상의 검사.

그림 기준: [비주얼 스타일 기준](비주얼_스타일_기준.md). 승인 전 시안과 검토 이미지는 작업 임시 폴더에 보관한다.

### 확인 결과

- 320×568, 390×844, 844×390, 900×800, 1280×800, 1440×900에서 갈림길 1~4개, 총 24개 조합 통과.
- 정찰 확신도·미확인 정보 보호, 선택과 실제 진입 분리, 시험 리더 권한, 전체 경로 열기·닫기, 오래된 화면의 실행 차단 통과. 이동 버튼은 마우스를 올렸을 때도 글자 대비 4.5:1 이상.
- 전체 진행 검사 66/66 통과. 실제 게이트 끝까지 진행과 팀 상의 처리도 포함한다. 원격 의상 보정 합류 후 탐색 전용 검사 재통과.
- 별도 튜토리얼 자동검사의 ‘시험 첫 전투까지 가지 못함’은 기존 버전에서도 확인된 실패로 남아 있다. 탐색의 읽기 전용 시험 권한 검사와 구분한다.
