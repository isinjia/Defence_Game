# 괴수 다양성 점검

> 전투에서 마주치는 상대는 거의 다 괴수다. 괴수가 얼마나 다양하고, 서로 다르게 싸우는지 쟀다.
> 전투 제안(`전투_제안.md`: 예고·파괴·상태 이상)과 2차 제안(보스 패턴), 3차 제안(네임드 괴수)과 겹치지 않는 것만 다룬다.
> 기준 코드: `claude/happy-turing-czlfa3` v0.25. 조사 문서이며 코드는 고치지 않았다.

## 1. 지금 괴수 (`data.js` `MONSTERS`, `game.js` `makeMonster`)

| 항목 | 값 |
|---|---|
| 괴수 종류 | **20종** (등급대마다 3~6종) |
| 생김새 | 13종(짐승·슬라임·벌레떼·드론·골렘·유령·합창단·거미·비행체·용·눈·핵·군주) |
| 능력치 차이 | 체력 배율·공격 배율 두 숫자뿐 |
| 기술 | 기본 타격 + 같은 속성의 단일·전체 공격 스킬 최대 2개 |
| 행동 | 모든 괴수가 같은 적 AI. 대상은 도발 우선, 35%로 플레이어, 나머지 무작위(`pickTarget`) |
| 보스 | 같은 괴수의 체력 ×3.2, 공격 ×1.35 |

**등급별로 만날 수 있는 괴수** (등급 ±1에서 뽑음):

| 게이트 등급 | 후보 수 | 예 |
|---|---|---|
| F | 5 | 변이 들개, 산성 슬라임, 전기 날벌레떼, 망령 드론, 불꽃 쥐 |
| E~A | 각 7 | … |
| S | 8 | … |
| SS | 6 | 적룡 파편체, 폭풍 와이번, 강철 거신, 빙결 고룡, 심연 감시자, 태양의 잔해 |

- 게이트는 60% 확률로 게이트 속성과 같은 속성 괴수를 고른다(`makeMonster` `prefElem`). 등급대 후보 7종 중 같은 속성은 1~2종이라, **한 게이트 안에서는 거의 같은 괴수만** 나온다.
- 게이트 주제는 10가지(폐지하철역, 침수된 쇼핑몰, 버려진 병원, 고대 신전 …)인데 **나오는 괴수와 상관이 없다.** 지하철역에서 서리 늑대가 나와도 이상하지 않은 구조다.
- 괴수 이름은 다르지만 **싸우는 방식은 전부 같다**: 맞고, 때리고, 가끔 속성 기술.

## 2. 참고한 설계

- **적의 역할 삼각형**: 버티는 적(탱커)·때리는 적(딜러)·돕는 적(지원). 지원형이 탱커를 치료하면 무리 전체가 훨씬 단단해진다.
- **역할이 우선순위 판단을 만든다**: "누구부터 잡을까"가 전투의 핵심 결정이다(아군 침묵을 푸는 적부터? 때리는 적부터?).
- **늘 같은 조합은 지루하다**: 모든 적 무리가 탱·힐·딜 이상적 조합이면 금방 지루해진다. 조합을 바꿔 가며 써야 한다.
- **잡몹 원형**: 체력·공격 낮고 떼로 오는 무리형, 소환자가 죽을 때까지 계속 다시 나오는 소환물 등.
- **상용 RPG 예(Dragon Age II)**: 모든 적 무리에 공통 역할을 정의하고, 플레이어 쪽 대응(돌격형은 탱커 하나가 붙잡는다)을 함께 설계.

## 3. 제안 (우선순위 순)

### 1. 괴수 행동 유형 — 난이도 중
- 괴수마다 행동 유형 하나. 유형이 AI와 기술을 정한다.

| 유형 | 행동 | 플레이어가 할 판단 |
|---|---|---|
| 돌격형 | 체력 낮은 아군만 노림 | 탱커 도발, 약한 동료 보호 |
| 방패형 | 동료를 감싸 대신 맞음 | 관통·전체기로 뒤를 노릴지 |
| 치유형 | 다친 동료 회복 | 먼저 잡아야 함 |
| 소환형 | 졸개를 불러냄, 본체를 잡으면 졸개 소멸 | 본체 집중 |
| 무리형 | 약하지만 떼로, 수가 줄면 도주 | 전체기 |
| 자폭형 | 몇 차례 뒤 폭발(예고) | 그 전에 잡거나 방어 |
| 분열형 | 쓰러지면 작은 개체 둘로 | 화력 배분 |
| 흡수형 | 때릴 때마다 정신력·버프를 빼앗음 | 짧게 끝내기 |

- 지금 괴수 20종에 유형을 하나씩 붙이는 것만으로도 전투가 달라진다(예: 산성 슬라임 = 분열형, 망자의 합창단 = 치유형, 철갑 거미 여왕 = 소환형, 전기 날벌레떼 = 무리형, 골렘 잔해병 = 방패형).
- 전투 제안의 행동 예고와 짝을 이루면 "저 치유형부터 잡자"가 화면에서 읽힌다.

### 2. 게이트 주제별 괴수 구성 — 난이도 하
- 게이트 주제(10가지)마다 잘 나오는 괴수를 정한다: 폐지하철역(쥐·벌레떼·들개), 침수된 쇼핑몰(슬라임·세이렌), 버려진 병원(망령·합창단), 지하 데이터센터(드론·골렘), 고대 신전(감시자·거신), 에테르 숲(늑대·거미) 등.
- 게이트 이름만 봐도 무엇이 나올지 짐작되고, 괴수 도감(4차 제안)을 채우려고 특정 주제의 게이트를 찾아가게 된다.

### 3. 무리 구성 틀 — 난이도 하
- 구역마다 무작위로 섞지 말고 몇 가지 틀에서 고른다: "탱+딜", "치유+딜 둘", "소환형 단독", "무리형 떼", "방패+자폭". 같은 틀이 연달아 나오지 않게.
- 보스 구역은 보스 + 그 보스와 잘 맞는 부하(보스가 소환형이면 졸개, 치유형이면 방패형 호위).

### 4. 괴수 종류 늘리기 — 난이도 중(그림·데이터)
- 등급대마다 같은 속성이 1~2종뿐이라 반복이 심하다. 목표: 등급대마다 속성별 2종 이상 → 전체 40종 안팎.
- 그림은 지금 생김새 13종을 재사용하고 색·크기·장식(뿔, 갑각, 빛)만 바꾸면 비용이 낮다(`fx.js` `monster`).
- 헌터물 단골 괴수 중 아직 없는 것: 고블린·오크 같은 인간형 무리, 리자드맨, 언데드 기사, 키메라, 하피, 가고일, 미믹(3차 감정·저주와 연결), 도시형 괴이(엘리베이터·지하철 괴담, 4차 규칙 괴담과 연결).

### 5. 특수 괴수 — 난이도 하~중
- **보물 괴수**: 낮은 확률로 나오는 도망치는 괴수. 몇 턴 안에 잡으면 코어·유물을 많이 준다. 놓치면 사라진다.
- **변종**: 이름 앞에 "변종"이 붙은 강화 개체(속성이 둘이거나 유형이 둘). 드물게, 보상 많음.
- **떠도는 우두머리**: 지도 위 괴수 무리 중 하나가 우두머리를 거느린 큰 무리. 3차 네임드 괴수의 출발점이 된다.

### 6. 보스 고유 기술 — 난이도 중
- 지금 보스는 체력·공격만 크다. 보스가 되는 괴수마다 고유 기술 하나(용: 숨결 전체기 + 화상, 거미 여왕: 거미줄로 한 명 묶기, 세이렌: 노래로 아군 하나 혼란, 거신: 지진으로 전열 기절). 2차 제안의 보스 패턴(체력 구간별 변화)과 합치면 보스마다 다른 공략이 생긴다.

## 4. 추천 순서

2(주제별 구성) → 1(행동 유형) → 3(무리 틀) → 5(특수 괴수) → 6(보스 고유 기술) → 4(종류 늘리기)

- 2번은 데이터 표 하나라 가장 싸고, 게이트마다 개성이 생긴다.
- 1·3번이 핵심이다. 지금 괴수 20종을 그대로 두고 행동만 달라져도 "누구부터 잡을까"라는 판단이 매 구역 생긴다.
- 4번은 1~3이 들어가 괴수마다 개성이 생긴 뒤에 늘려야 늘린 보람이 있다.
