# 게이트 크로니클 용어집

프로젝트의 대화·기획·UI 검토에서 같은 대상을 같은 이름으로 부르기 위한 기준 문서다. 화면 용어와 게임 개념, 그림 구성 요소를 구분한다.

작성: 2026-11-13. **‘탐색’·‘월드맵’은 사용자가 확정한 정의**다. 나머지는 현재 코드와 문서를 기준으로 정리한 항목이며, 새 명칭을 사용자 확정 사항으로 취급하지 않는다.

## 1. 화면과 이동

| 용어 | 뜻 | 구분·사용 예 |
|---|---|---|
| **탐색** | **게이트에 들어간 뒤 길을 선택하는 화면** | ‘탐색의 경로 아이콘을 키운다.’ 전투·사건·휴식·보물·보스 지점과 분기 경로를 다룬다. 사용자 확정. |
| **월드맵** | **현재의 타일 기반 이동 화면** | ‘월드맵의 타일과 캐릭터 표시를 키운다.’ 도시·게이트의 위치와 월드 이동을 다룬다. 사용자 확정. |
| 타일 | 월드맵을 구성하는 개별 지형 칸 | 탐색의 원형 지점이나 경로와 구분한다. |
| 경로 | 탐색에서 지점 사이를 연결하는 길 | 다음에 어느 지점으로 진행할 수 있는지를 나타낸다. |
| 탐색 지점 | 탐색 경로 위의 개별 방문 지점 | 입구·전투·정예·사건·휴식·보물·보스 등. 코드의 `node`에 해당한다. |
| 층 | 게이트 내부 진행을 나누는 단위 | 한 층에 분기 경로와 여러 탐색 지점이 있다. |
| 전투 화면 | 적과 아군이 싸우며 행동·스킬을 선택하는 화면 | 전투 지점을 고르는 탐색 화면과 구분한다. |
| 사건 | 상황 설명과 선택에 따라 결과가 달라지는 콘텐츠 | 탐색과 월드맵 양쪽에서 발생할 수 있으므로 필요하면 ‘탐색 사건’·‘월드맵 사건’으로 구분한다. |
| 판정 | 위험이 있는 선택의 성공 여부를 능력치·확률·주사위 등으로 결정하는 절차 | 화면을 설명할 때는 ‘사건 판정창’처럼 맥락을 붙인다. |
| 각성자 등록 신청서 | 프롤로그 또는 직접 생성 후, 실기 시험 전에 신청인 정보와 각성 현황을 확인하는 창 | 신청서를 제출하면 시험장으로 진행한다. 시험 후 판정 결과 및 정보 탭 재열람과 구분한다. |
| 대화창 | 인물의 이름·대사·인물 그림을 표시하는 화면 요소 | 탐색 화면 위에 대화창이 떠 있어도 배경 화면은 탐색이다. |
| 컷신 | 장면 그림과 대사·자막 등으로 이야기를 연출하는 장면 | 일반 대화창·탐색 경로 화면 전체를 컷신이라고 부르지 않는다. |

## 2. 게이트와 파티

| 용어 | 뜻 | 구분·사용 예 |
|---|---|---|
| 게이트 | 월드맵에서 발견·진입해 내부를 공략하는 대상 | 게이트는 공략 대상, 탐색은 내부 경로 선택 화면이다. |
| 층 보스 | 해당 게이트 층의 마지막에 만나는 보스 | 마지막 층의 보스는 게이트 보스다. |
| 파티 | 함께 행동·공략하는 헌터들의 집단 | 화면에 보이는 초상 목록 자체와 구분한다. |
| 리더 | 파티의 경로·행동 결정을 주도하는 인물 | 플레이어가 항상 리더인 것은 아니다. 시험 등에서 리더의 결정과 플레이어 의견을 구분한다. |
| 동료 | 함께 행동하는 파티의 인물 | 모든 NPC가 동료인 것은 아니다. |
| NPC | 플레이어가 직접 조작하는 인물 외의 게임 내 인물 | 동료·도시의 인물 등 맥락에 따라 역할이 달라진다. |

## 3. 성장과 자원

| 용어 | 뜻 | 구분·사용 예 |
|---|---|---|
| 각성 등급 | 인물의 성장 등급 | 현재 F·E·D·C·B·A·S·SS 체계. 게이트에도 등급이 있으므로 ‘헌터 등급’·‘게이트 등급’으로 대상을 명시한다. |
| 성장 단계 | 같은 각성 등급 안의 초기·중기·후기 | 게이트의 층이나 탐색 진행 단계와 구분한다. |
| 돌파 | 다음 각성 등급으로 올라가기 위한 성장 행위 | 공식 등급의 재측정과 구분한다. |
| 공식 등급·재측정 | 관리국에 등록된 등급과 이를 갱신하는 절차 | 실제 성장 등급과 공식 등급이 항상 같다고 가정하지 않는다. |
| 체력 | 생존과 피해에 관련된 자원 | 코드의 `hp`. |
| 정신력 | 스킬 등에서 사용하는 자원 | 코드의 `mp`. 에테르와 구분한다. |
| 에테르 | 수련·성장 등에 사용하는 게임 자원 | 정신력 게이지와 구분한다. |
| 크레딧 | 게임 내 화폐 | 체력·정신력·에테르와 별도 자원이다. |

## 4. 그림과 UI 구성 요소

| 용어 | 뜻 | 구분·사용 예 |
|---|---|---|
| 아이콘 | 장소·행동·상태 등을 작은 기호로 나타낸 그림 | ‘탐색 지점 아이콘’처럼 대상을 붙인다. |
| 초상 | 얼굴 중심의 인물 표시 | 원형 초상과 상반신 일러스트는 표시 범위를 구분해서 요청한다. |
| 상반신 일러스트 | 얼굴·몸통·의상이 함께 보이는 인물 그림 | ‘대화창 상반신 일러스트의 어깨 폭’처럼 수정 부위를 명시한다. |
| 캐릭터 표시 | 지도 등에서 인물의 위치를 나타내는 표시 | ‘월드맵 캐릭터 표시’·‘탐색 리더 초상’으로 위치와 역할을 명시한다. |
| 의상 | 얼굴·헤어와 별도로 합성되는 복장 | 이미지 원화의 비율 문제와 합성 배율 문제를 구분한다. |
| 레이아웃 | 화면 요소의 위치·크기·간격·배치 구조 | 아이콘 확대와 화면 전체 배치 변경은 별도 항목으로 적는다. |

## 5. 문서 작성 규칙

- ‘지도’만으로 대상이 모호하면 **탐색** 또는 **월드맵**을 명시한다.
- ‘탐험’·‘탐사’가 기존 콘텐츠명이나 행동명에 쓰였더라도 탐색·월드맵의 동의어로 임의 치환하지 않는다. 대상이 불분명하면 맥락을 확인한다.
- 과거 문서·코드의 `map`, `explore`, ‘층 지도’ 등의 표현을 일괄 변경하지 않는다. 새 설명은 이 용어집을 기준으로 작성한다.
- 사용자 확정과 코드 기준 정리를 구분한다. 정의가 바뀌면 이 문서를 먼저 갱신하고 관련 문서에서는 링크로 참조한다.
- 개선 제안·시안 승인·구현 완료는 각각의 상태다. 용어 확정만으로 UI 개선안 전체가 승인된 것으로 처리하지 않는다.
