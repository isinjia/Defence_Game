# 월드맵 이동 시간

2026-11-13 사용자 요청: 약 2km 크기의 월드맵 타일 한 칸에 하루가 걸리는 이동을 합리적으로 조정한다. 이 문서는 월드맵의 타일 이동 기준이다.

## 기준

위·경도 간격이 약 2km인 현재 지도를 기준으로, SPD 10인 기본 각성자의 평지 이동은 칸당 15분(약 시속 8km), 정리된 국도는 7.5분, 산악은 30분으로 정한다. 산악·숲·장마·결빙·대각선의 기존 비용 차이를 유지한다. **목적지 선택에는 거리·SPD 제한이 없다.** 지형상 연결된 곳은 먼 거리라도 클릭해서 경로를 확인하고 출발할 수 있다. 바다·봉쇄 구역·제주 출입 자격 등 통행 제한은 유지한다.

도보의 기준 시간은 `max(7, 15 - 2 × log2(현재 SPD / 10))`분이다. 중간 SPD는 연속적으로 계산한다.

| SPD | 평지 한 칸 |
|---|---:|
| 10 | 15분 |
| 20 | 13분 |
| 40 | 11분 |
| 80 | 9분 |
| 160 이상 | 7분 |

국도 등 빠른 지형도 도보 한 칸은 7분 아래로 줄어들지 않는다. 산악 등 느린 지형의 비용은 유지하고, 대각선은 1.4배 시간이 든다. 장비 등으로 SPD가 바뀌면 다음 걸음과 경로 예상에 즉시 반영한다. **차량에는 이 SPD 공식을 적용하지 않는다.** 차량 운행은 차량 속도 기준이다. 차량의 ‘이동력 +N’과 선택 범위 테두리는 제거했다.

| 이동 조건 | 기본 한 칸의 실제 시간 |
|---|---:|
| 각성자 도보 · 평지 | 15분 |
| 각성자 도보 · 국도 | 7분 30초 |
| 각성자 도보 · 산악 | 30분 |
| 도보 · 평지 대각선 | 21분 |
| 자전거 · 평지 | 10분 |
| 오토바이 · 평지 | 5분 |
| 승용차 · 국도 | 약 1분 53초 |
| 파티 장갑차 · 평지 | 7분 30초 |

차량 시간은 정상 차량·평상 기후 기준이다. 대여·소유 차량 중 빠른 이동 계수를 사용하며, 소유 승용차·SUV의 기존 국도 보정과 파티 장갑차의 기존 이동 보정을 함께 적용한다. 고장·유지비 미납 차량은 사용할 수 없다. 이동수단 설명에도 변경한 효과를 표시한다.

## 누적과 표시

- 이동은 `player.dayFrac`에 소수 일수로 누적한다. 24시간이 차면 날짜를 하루 넘긴다. 평지 96칸 또는 국도 192칸이 SPD 10 기준 도보 하루다.
- 경로를 나누어 이동하거나 도중에 멈춰 저장·불러오기해도 소요 시간을 버리지 않는다. 기존 저장의 누적 시간도 보존한다.
- 짧은 이동을 최소 하루로 올리지 않는다. 지도 경로·마우스 안내·출발 창·이어서 이동·도착 알림은 분·시간·일을 사용한다. 표시는 분 단위 올림이며 실제 계산은 소수 시간을 유지한다.
- 예상 도착 날짜는 현재 누적 시간까지 포함한다. 월 경계를 넘으면 월 정산·계약 마감 안내를 표시한다.
- 경로 예측은 실제 걷기와 같은 지형·대각선·차량·파티 보정을 사용한다. 도중 기상·차량 상태가 바뀌거나 사건에 멈추면 남은 경로를 새로 계산한다.
- 기차·버스·선박·고속 이동망의 별도 운행 일정과 비용은 해당 교통 시스템의 규칙이다.

## 구현과 검증

`js/world_travel_time.js`에 이동 계수·차량·기간 표시·경로 시간·소수 시간 누적을 모았다. `js/world.js`의 기본 시간을 변경하고, 기존 `walkStep`의 이동·사건 처리를 사용한다.

`node tools/world_travel_time_test.js`는 실제 한 칸 이동과 예측의 일치, 도보·도로·산·대각선·차량·고장·파티 차량, 24시간 누적, 중간 저장·불러오기, 월 경계와 출발 창의 분 표시를 검사한다. `TRAVEL_TEST_URL`로 검사할 사이트를 지정할 수 있다.

### 검증 기록 (2026-11-13)

- 기본 도보·국도·산악·대각선·자전거·오토바이·승용차·파티 장갑차와 고장 차량에서 예측/실제 시간을 확인했다. 개인 차량의 국도 보정과 파티 장갑차 보정이 겹쳐 0분이 되던 문제도 보정하고 조합 검사를 통과했다.
- 실제 출발 버튼과 도착 알림, 분 표시, 중간 저장/불러오기, 24시간 누적, 월 경계 검사를 통과했다.
- 전체 연기 검사 65/66. 실패 1건은 레이드 검사 도중 외부 Google 글꼴의 CORS 로딩 실패였으며, 해당 검사에서 콘솔 오류 2건을 수집했다. 보조 튜토리얼 자동 진행은 기존 ‘시험 첫 전투까지 가지 못함’ 오류가 남아 있다. 병행 장기 모의 검사 중 보조 모바일 전투 검사 일부는 대기 시간 초과로 확인하지 못했다.
- `node tools/balance_sim.js 4 70` 전후 검사를 각각 실행했으나 양쪽 모두 10분 이상 결과를 반환하지 않아 중단했다. **등급 도달 나이·수명 손상·NPC S급 비율의 전후 비교는 미완료**이며, 이동 시간 검사로 장기 성장 균형까지 검증했다고 해석하지 않는다.

### 후속 수정: 선택 거리 제한 제거·도보 SPD 상한

사용자 확정: SPD 10에서 15분, SPD가 두 배가 될 때마다 2분 감소, 도보 최소 7분. 차량 속도에는 SPD를 반영하지 않는다.

전용 검사에서 SPD 5·10·20·40·80·160·320의 실제 도보 시간, 국도 최소 7분, 대각선 1.4배, 차량의 SPD 독립성을 확인했다. 부산처럼 기존 선택 범위 밖의 먼 목적지를 낮은/높은 SPD에서 동일하게 선택하고 출발 확인까지 여는 것을 검증했다. 바다 통행 제한·저장/불러오기·날짜 누적·월 경계·실제 도착 알림 검사도 통과했다.
