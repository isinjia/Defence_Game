# 얼굴·헤어 확장

- 추가 원화: 남녀 얼굴 각 10종(`face-*-18..27`), 헤어 각 10종(`hair-*-20..29`), 대응하는 뒷머리 각 10종(`hair-*-20..29-rear`). 얼굴 피부 마스크 20개도 함께 등록했다.
- 기존 성인 얼굴 10종과 신규 10종을 합쳐 성별별 성인 얼굴 20종, 헤어 30종을 선택한다. 유스 얼굴은 기존 15..17번을 유지한다.
- `PortraitParts.newLook()`이 만드는 `look3:` 시드만 확장 풀을 사용한다. 새 게임과 외형 바꾸기에 연결했다. 이전 저장 시드는 기존 얼굴 매핑과 헤어 20종 선택을 유지한다. 별도 저장 이전은 필요 없다.
- 확장 풀은 얼굴과 헤어를 독립적으로 추첨한다. 성별별 성인 얼굴 20 × 헤어 30의 600개 조합을 검사한다.
- 헤어의 `rearFile`/`rearRect`는 몸·옷 뒤에 그린다. 앞머리와 같은 머리 비율·의상별 위치를 적용한다. 기존 여성 앞머리의 턱·목 보호 분리는 유지한다.
- 등록 버전 3 얼굴은 `eyeY`·`eyeCenters`·`mouthY`를 기준으로 피부 마스크를 만든다. 원화의 턱을 재추정하지 않으며, 입술을 픽셀별로 제외해 밝은 점이 생기는 것을 피한다.
- 기존 머리 비율·옷깃·체형 보정은 유지한다.

검증: 기존 시드 2,400개 선택 결과 비교, 신규 얼굴 마스크 20개 재생성 일치, 성별별 600개 조합 선택, 새 카드·원형 초상 각 20개 렌더, 320px 생성 화면·외형 바꾸기·직접 설정 확인. 신규 원화는 게임 연결 전 미리보기와 수정 확인을 거쳐 배포 요청에 따라 적용했다.

배포 전 전체 연기 검사: 54/55 통과. 초상 관련 검사는 전부 통과했고 20년 진행도 완료했다. 연합 레이드 검사에서 ‘소집 공문 창 없음’이 발생해 해당 영역 코드는 수정하지 않고 기록했다. 별도 튜토리얼 자동조작 보조 검사는 첫 시험 전투까지 진입하지 못했다.
