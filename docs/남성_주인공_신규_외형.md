# 남성 주인공 신규 외형

2026-11-19 사용자 승인: 재제작한 머리·목·상체 연결을 기준으로 적용하고 커밋. 얼굴 3종·헤어 8종 모두 조합. NPC는 유지, 남성 주인공 체형은 보통 1개. 푸시·배포 승인은 포함하지 않는다.

## 적용

- `assets/portraits/player-male/`: 얼굴 3종, 헤어 8종, 복장 원화 3종. 총 72개 조합. 원본 좌표 1024×1536, 투명 무손실 WebP.
- `js/player_male_art.js`: 남성 주인공·생성 중인 남성의 시드에만 새 경로 적용. 여성·NPC·기존 NPC 시드 추첨은 기존 함수에 그대로 전달한다. 기존 남성 주인공 저장을 불러오면 체형은 보통으로 정규화한다.
- 외형 바꾸기는 얼굴·헤어·기본 복장을 시드별로 고정해 추첨한다. 각 파츠는 독립 해시를 쓴다.
- 생활복은 재킷, 코트 계열은 롱코트, 전투복은 헌터 전투복. 직업·장비 의상도 승인한 3종 범위에 맞춰 표시한다. 등록 전에는 3종 중 시드로 선택한다.
- 남성 피부색 선택은 유지한다. 의상의 목 피부 영역과 얼굴만 바꾸고 옷·헤어 색은 유지한다.
- 목 너비·어깨를 따로 변형하지 않는다. 승인한 상체 원화의 턱 아래를 보존하고 얼굴별 턱선·헤어 위치를 등록했다. 얼굴2는 너비 차이를 반영해 별도 배율을 쓴다.
- 큰 초상은 400×600 좌표, 기존 상반신 아이콘 크롭·이미지 준비·지도 래스터 경로를 그대로 이용한다.
