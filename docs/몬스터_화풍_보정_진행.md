# 몬스터 화풍 보정 진행 기록

## 2026-11-14 후속 시안 보관 — 게임 미적용

사용자 지시로 [시안 보관 폴더](몬스터_화풍_보정_시안/README.md)에 결과와 후속 수정 기록을 푸시한다.

- 적용 150종 유지. 남은 미적용 87종 중 시안 생성 50종, 미생성 37종.
- 이번 후속 생성 49종과 이전 얼어붙은 합창 시안 1종. [비교 미리보기 9장](몬스터_화풍_보정_시안/index.html), 개별 투명 PNG 50개 보관.
- 사방 여백 재보정 필요. 에테르 늑대군주·에테르 사슴은 원본 자세·체형 보존 추가 점검. 검토상 한계를 최종 승인으로 처리하지 않는다.
- 생성 도구 일일 한도(HTTP 429)로 재보정·추가 생성 중단. 다음 미생성 대상은 지하주차장 하이에나·천둥 기수·철근 골렘 순서.
- [재보정 목록](몬스터_화풍_보정_시안/재보정_대기.md), [미생성 37종](몬스터_화풍_보정_시안/remaining.txt), [검토 기록](몬스터_화풍_보정_시안/검토_및_재개.md).
- 게임 연결·원본/전투/확대 자산은 갱신하지 않는다. 스모크 테스트 미실행. 탐색 화면 수정 없음. 보관 푸시에 `[skip ci]`를 넣어 자동 배포를 건너뛴다.

아래는 이전 적용 작업의 기록이며, 아래 “남은 87종”은 **미적용 목록**이다.


2026-11-14 사용자 지시로 현재 생성된 묶음까지 마감하고 게임에 반영한다.

- 전체 237종 중 기존 보정 적용 67종 + 이번 적용 83종 = 누적 150종.
- 이번 적용: 메카 파괴자 시험본 1종, 승인된 추가 묶음 10종, 후속 묶음 72종.
- 미생성 87종은 기존 그림을 유지한다. 전체 보정 완료로 처리하지 않는다.
- 사용자 승인 방향: 가는 선택적 선, 큰 색면, 절제된 부드러운 명암. 원본의 종류·고유색·주요 소품을 유지하고 미세 표면 잡음과 강한 반사를 줄였다.
- 실제 생성 참조: 대상 원본 + `seoyun-suit.png` + `jin-unmasked.png` + `cut-36-ridge.webp`. 후속 묶음에는 사용자가 승인한 메카 파괴자 시험본을 화풍 참조로 추가했다.
- 원본 PNG를 보존하고 기존 자산 준비 도구로 전투용 256px·확대용 1024px 투명 WebP와 개체별 캐시 해시를 갱신한다.

## 검토 및 한계

- 원본과 보정본을 개체별·묶음별 미리보기로 직접 비교했다. 선·고유색·큰 실루엣과 주요 소품을 확인했다.
- 투명 PNG를 어두운 배경에 합성한 미리보기로 확인했다. 이미지 뷰어의 흰 후광처럼 보이는 현상은 실제 PNG의 배경과 구분했다.
- 바람길 요정벌레와 숲의 심판자는 원본 몸체가 대부분 손실되어 제작 명세와 남은 형태를 바탕으로 복원했다.
- 분지 열기쥐는 무리형을 유지하되 시안의 개체 수가 7마리로 바뀌었다. 심연 감시자는 촉수가 겹치는 부분이 있어 명세의 8개를 명확히 판독하기 어렵다.
- 개별 장식·소품 개수의 완전한 일치와 균일한 12% 여백은 보장하지 않는다. 전체 실루엣의 잘림 여부를 미리보기에서 확인했으며 원본 크롭은 하지 않았다.
- 실제 모바일 전투 검증은 하지 않았다. 사용자 지시에 따라 스모크 테스트는 실행하지 않는다.

## 마감 확인

- 갱신된 83종의 WebP 166개 디코딩·해상도·투명 배경 확인.
- 새 PNG의 해시와 연결 정보 일치 확인. 나머지 154종 연결 기록은 변경 없음.
- 빌드 성공. 스모크 테스트 미실행.
